# Stock Book AI 분석 — 전송 정책과 미리보기

기준일: 2026-10-20. 기준 main: `209b392f9127f45285aa44ba1041bf8ad61a5b17`.
이 문서는 Stock Book 전용 분석 경계다. 캐릭터 대화 응답 계약이나 PC·Android Shared Contract를 확정하는 문서가 아니다.

## 승인된 결정

사용자가 네 항목 권장안에 동의한 범위는 다음과 같다. 병합·배포 승인은 별도다.

| ID | 결정 |
| --- | --- |
| D-AI1 | 비공개 프로젝트 코드를 복사·공개하지 않는다. 공개 가능한 Stock Book 전용 CLI 어댑터를 독립 작성하고 사용자가 설치한 CLI를 사용한다. 캐릭터 원문·캡슐·에셋을 가져오지 않는다. |
| D-AI2 | 최초 외부 모델 전송 동의와 매 요청의 ‘보낼 자료 보기’를 적용한다. 네로와 아린은 각각 사용자가 선택해서 호출한다. 자동 후속 호출은 없다. |
| D-AI3 | 현재 선택 종목, 이미 수신한 시세, 해당 종목의 합산 보유 정보, 명시적으로 선택한 일지만 전달 대상으로 삼는다. |
| D-AI4 | 분석 결과는 앱 메모리에만 보관하고 종료 시 폐기한다. 포트폴리오·일지·백업·로그·localStorage·파일에 자동 저장하지 않는다. |

## 구현 단계와 이번 범위

1. **이번 PR: 전송 자료 미리보기.** 기존 AI 분석 영역에 ‘보낼 자료 보기’를 연결했다.
   외부 모델·CLI·신규 IPC를 호출하지 않으며 네로·아린 실행 버튼은 미연결 상태로 비활성화한다.
   동의 선택도 앱 메모리에만 유지하고 철회·종료 시 폐기한다. 체크만으로 실제 실행이 가능해지지 않는다.
2. 후속: 독립 CLI 어댑터, 네로 명시 실행·취소, 신뢰 경계 검사, 분석 결과 메모리 표시.
3. 후속: 사용자 선택 시에만 아린 설명. 네로 결과만으로 자동 호출하지 않는다.

`main.js`·`preload.js`는 이번 PR에서 변경하지 않는다. 후속 변경은 시스템룸 diff 검토 후 병합 대상으로 둔다.
이 PR은 CLI 실행·취소나 실제 외부 전송을 구현한 것으로 기록하지 않는다. 실제 분석 결과가 생성되지 않으므로
D-AI4의 분석 결과 생명주기는 후속 CLI 구현 시 별도로 검증해야 한다.

## 입력 미리보기

`src/analysis-ai/preview.js`는 입력에서 명시된 필드만 새 객체로 투영한다.
사용자 상태 전체를 직렬화하거나 계좌 객체를 전송하지 않는다.

| 필드 | 내용 |
| --- | --- |
| schemaVersion | `stockbook.analysis-input.v1` — 이 미리보기 형식 식별자 |
| capturedAt | 미리보기를 연 시각. 시세 수신 시각과 구분한다. |
| stock | 선택 종목의 stockCode·market·name·currency |
| quote | 이미 수신한 price·changePercent·receivedAt·source·currency. 미수신 값은 null |
| holdings | 종목·통화별 quantity·acquisitionCost·averageCost·marketValue·unrealizedProfit 합산 |
| journals | 체크한 일지의 종목 표시명·날짜·매수/매도 구분·이유·매수/매도/결과 메모만 |
| notes | 합산하지 못한 값 등 자료의 한계 |

- 일지는 기본 0건이다. 사용자가 고른 일지만 미리보기에 포함한다. 다른 종목 일지를 고르면 그 종목 표시명도 보인다.
- 선택 종목 외 보유 행, 계좌명·계좌번호·계좌 ID·브로커·인증정보·전체 거래·예수금·전체 포트폴리오는 포함하지 않는다.
  내부 assetId는 모델 입력에 넣지 않으며 존재하는 경우 로컬 보유 매칭에만 사용한다.
- 이번 구현은 현재 main의 레거시 종목 관계를 읽기만 한다. 새 영속 ID를 발급하거나 #47 마이그레이션·Shared Contract를 선행 구현하지 않는다.
  종목 코드가 같아도 알려진 시장 또는 assetId가 다르면 합산하지 않는다.
- 서로 다른 통화의 금액은 합산하지 않는다. 보유 원가의 통화를 확인할 수 없으면 수량만 표시하고 원가·평가금액은 null로 남긴다. 시세 통화로 보유 원가 통화를 추정하지 않는다.
  실제 수신 시세가 없으면 평균단가나 과거 보유 가격을 현재 시세처럼 사용하지 않는다.
- 0과 미확인을 구분하며 NaN/Infinity를 보내지 않는다. 불완전한 원가를 부분 합산한 수치를 전체 원가처럼 표시하지 않는다.
- 미리보기는 연 시점에 고정한다. 이후 실시간 가격·일지가 바뀌어도 자동으로 덮어쓰지 않는다. 다시 열면 새 자료를 캡처한다.
  일지 선택은 매번 초기화한다. 본문은 글자 수로 조용히 자르지 않는다.
- DOM에는 textContent로 표시한다. 일지 속 HTML·명령문을 실행하지 않는다.

## 후속 CLI 연결에서 지킬 경계

- 미리보기 열기·동의 체크·종목 선택만으로 모델을 호출하지 않는다. 실행 버튼의 명시적 사용자 요청이 필요하다.
- 렌더러의 동의 값만 신뢰하지 않는다. main에서 송신자·요청 ID·선택 종목·동의·검토한 스냅샷과 실제 전달 자료의 일치를 검증한다.
  검토 후 자료가 바뀌면 다시 미리보게 한다. 전체 state나 임의 IPC payload를 그대로 CLI에 넘기지 않는다.
- 일지 내용은 분석 자료이며 내부 지시를 실행하지 않는다. CLI 도구 사용·주문·계좌 변경·파일 조작은 허용하지 않는다.
- 분석 결과는 캐릭터 대화의 text/emotion/action과 분리한다. 확인된 자료·해석·불확실성을 구분하는 결과 스키마를 별도로 검토하고 연결한다.
- 실행 중 취소와 앱 종료는 해당 요청을 끝내야 한다. 취소 뒤 늦게 도착한 결과는 화면·메모리에 반영하지 않는다.
- 프롬프트·전송 자료·분석 결과를 진단 로그에 기록하지 않는다. 결과 저장·내보내기는 이번 승인 범위에 없다.

## 검증과 미검증

- `npm ci --ignore-scripts` 완료. 표준 `npm run test:setup`은 관리자 권한이 필요한 시스템 의존 설치에서 실패했다.
  이미 있는 시스템 라이브러리를 사용하고 Playwright Chromium만 `/tmp/stockbook-browsers`에 설치한 뒤 기존 검사를 그대로 실행했다.
- `PLAYWRIGHT_BROWSERS_PATH=/tmp/stockbook-browsers npm test` 통과: 기존 정적 검사, 새 검사 8건(단위/컨트롤러 7 + Chromium 실제 앱 1), 기존 스모크.
- 새 검사는 비허용 필드 제외·선택 일지·통화 분리·미수신/0·긴 일지 원문·스냅샷 고정·DOM 안전·동의/원문 비저장·닫기/재시작을 다룬다.
  Chromium에서는 미리보기 열기에 따른 새 외부 요청 0건과 다크/라이트 화면을 확인했다. 외부 요청은 차단한 시험이다.
- 실행 자료는 합성 fixture다. 실제 계좌·일지·API 키·모델을 사용하지 않았다.
- Windows Electron·설치본 패키징·실제 CLI 분석·실제 외부 전송은 미실행이다.
- 버전·CHANGELOG·워크플로·기존 검사 스크립트·main.js·preload.js는 변경하지 않는다. 자동 병합하지 않는다.
