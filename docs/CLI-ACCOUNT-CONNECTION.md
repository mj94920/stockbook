# CLI 로그인과 앱 계정 연결

2026-10-21 사용자 지시. AI Character와 StockBook에서 따를 로그인 운영 기준이다.
이 문서 추가는 StockBook 공개 저장소의 설계 기록이며, 인증 기능 구현이나 실제 로그인 실행이 아니다.
비공개 AI Character 저장소는 수정하거나 읽어 복사하지 않는다.

## 앱별 화면과 CLI 인증의 관계

두 앱은 각각 AI 계정 연결 화면을 제공한다. 화면이 별도라고 해서 재로그인이 항상 필요한 것은 아니다.
같은 PC·같은 OS 사용자에서 동일한 CLI와 인증 저장소를 사용하는 경우 로그인 상태를 공유할 수 있다.
공유 여부는 CLI 버전·실행 파일·실행 사용자·인증 저장소를 구현 시 검증한다. 확인 전에는 공유를 보장하지 않는다.
네로와 아린의 CLI 연결과 캐릭터 표현·분석 결과 계약은 별개다.

## 처리 순서

1. 앱이 사용할 Codex·Claude CLI 설치 여부와 로그인 상태를 확인한다.
2. 로그인됐음이 확인되면 해당 CLI를 ‘연결됨’으로 표시한다. 모델 호출로 연결을 시험하지 않는다.
3. 명확히 로그인되지 않았을 때만 공식 CLI 인증 절차를 시작한다. 앱 시작이나 상태 조회 실패 때문에 인증을 자동 재실행하지 않는다.
4. 앱 사이에 인증 토큰을 복사하지 않고 앱 전용 토큰 사본도 저장하지 않는다.
5. 로그인·로그아웃 절차가 끝나면 상태를 다시 조회한다. 명령의 종료 코드만으로 연결 상태를 확정하지 않는다.

상태 조회·인증·로그아웃 명령은 지원할 CLI 버전의 공식 절차를 확인한 뒤 정한다.
이 문서에서 확인하지 않은 명령이나 인증 파일 경로를 고정하지 않는다.

## 화면 상태

| 확인 결과 | 표시·처리 |
|---|---|
| CLI 미설치 | 미설치. 지원하는 설치 안내 제공 |
| 조회 중 | 확인 중. 이전 확인 결과와 구분 |
| 로그인 확인 성공 | 연결됨. 마지막 확인 시각 표시 |
| 로그인되지 않았음이 확인됨 | 로그인 필요. 공식 인증 절차 제공 |
| 타임아웃·권한·실행 오류·해석 불가 | 상태 확인 실패. 로그아웃으로 단정하거나 기존 인증을 지우지 않고 재확인 제공 |

‘연결됨’은 인증 확인 결과다. 모델 권한·사용량 한도·분석 실행 성공이나 데이터 전송 동의를 뜻하지 않는다.
오류 메시지·진단 로그에 토큰·인증 원문을 기록하지 않는다.

## 공유 로그아웃과 실행 환경

로그아웃 전에는 해당 CLI 계정을 공유하는 다른 앱과 터미널에도 영향을 줄 수 있음을 안내하고 확인받는다.
취소하면 로그아웃 명령을 실행하지 않는다. 확인 후 로그아웃해도 반드시 상태를 재조회한다.
다른 앱이나 터미널에서 상태를 바꿀 수 있으므로 캐시된 ‘연결됨’을 영구적인 사실로 취급하지 않는다.

격리 실행에서 HOME·설정 경로·인증 저장소가 달라지면 상태 확인 때와 다른 인증 환경이 될 수 있다.
특히 빈 임시 HOME을 사용하는 분석 실행은 기본 CLI 로그인 상태를 그대로 쓸 수 있다고 가정하지 않는다.
지원 CLI의 공식 인증 이용 방식과 격리 실행의 호환성을 확인한다. 이를 맞추기 위해 토큰을 복사하거나
파일 접근·도구 실행 격리를 조용히 해제하지 않는다. 호환되지 않으면 그 사실을 별도 표시하고 설계를 재검토한다.

## StockBook 분석 자료 전송과 분리

CLI 로그인과 D-AI2의 자료 전송 동의는 독립적이다. 로그인됐더라도 아래 조건을 생략하지 않는다.

- 최초 외부 전송 동의 확인과 매 요청 ‘보낼 자료 보기’를 거친다.
- 로그인 상태 조회·로그인 완료·미리보기 열기·동의 체크만으로 모델을 호출하거나 분석 자료를 전송하지 않는다.
- 네로 실행과 선택적 아린 설명은 각각 사용자가 선택한다. 로그인이나 앞선 결과로 자동 연쇄 호출하지 않는다.
- 실행 시점에 동의와 검토한 자료의 유효성을 별도로 검증한다.

미리보기 구현은 [PR #84](https://github.com/mj94920/stockbook/pull/84)에서 검토 중이다.
이 로그인 운영 지침은 #84의 구현·통화 결정·후속 CLI 실행·main/preload 변경을 일괄 승인하지 않는다.
계정 연결 화면과 어댑터는 공개 저장소용으로 독립 작성한다.
비공개 프로젝트의 코드·캡슐·에셋·인증자료는 복사하지 않는다.

## 구현 시 검증할 항목

- 로그인된 CLI가 있으면 두 앱이 재인증 없이 같은 상태를 확인하는지 실제 지원 OS/CLI별 검증.
- 미설치·미로그인·타임아웃·권한 오류·출력 변경을 구분하고 조회 실패 후 자동 로그인하지 않는지 확인.
- 로그인·로그아웃 후 재조회, 공유 로그아웃 확인 취소, 다른 앱/터미널에서 로그아웃한 경우 확인.
- 기본 인증 확인 환경과 격리 분석 실행 환경의 차이를 검증. 모델 호출 없이 확인 가능한 범위를 명시.
- 토큰 사본·인증 원문 로그가 생기지 않고, 연결 확인만으로 모델 실행이나 자료 전송이 없는지 확인.
- 로그인 상태와 무관하게 최초 동의·요청별 미리보기·각 캐릭터 명시 실행 조건을 유지하는지 확인.

현재 위 CLI 동작·앱 간 인증 공유·Windows 인증 저장소·격리 실행 호환성은 미검증이다.
이번 변경은 문서뿐이며 설치·인증·로그아웃·모델 호출·외부 자료 전송을 실행하지 않았다.
