# Desktop Main v2 구현 대기: 현재 화면과 승인 목업 차이

기준: 데스크톱 미팅룸에서 승인한 Desktop Main v2 목업과 구현 지시서. 최초 비교 대상은 `0180097e` 시점이며, 아래 2026-10-20 재검증 기록이 과거 조사보다 우선한다. 이슈·DOM·코드 기준점은 아래 최신 확인 기록에 따르며, 완료 전 코드의 동작이나 후속 구현 결과를 확정한 것은 아니다. 목업의 모든 숫자는 샘플이며, 실제 데이터 연결 여부는 후속 구현 시 다시 확인한다. 이 문서는 디자인 승인이나 작업 큐를 변경하지 않는다.

## 동시 표시 기준 보완 (2026-10-20)

사용자 지시에 따라 다음 구성이 앞선 AI Signal 카드/독립 일지 전환 설명보다 우선한다.

- 상단은 선택 종목 가격·차트 영역·5호가 영역이다. 차트 데이터가 없어도 영역과 자료 확인 경로를 제공한다. 실제 차트/규칙 엔진을 새로 만들지 않는다.
- 우측 하단을 작업 영역과 분석 영역으로 나눈다. 잔고·거래내역·투자일지 전환 중에도 분석 영역은 그대로 유지한다.
- 분석 영역의 AI 분석과 규칙 신호는 서로 다른 구역이다. AI는 `분석 데이터 없음`, 규칙은 `판정 대기`로 표시하고 각각 분석 상태/판정 조건을 펼쳐 확인할 수 있다. 임의 결과·점수·추천을 생성하지 않는다.
- 5호가는 기존 `fetchHoga` IPC를 사용해 수동 조회한다. 실패/미연결/종목 미선택 상태를 표시하고 가상 호가를 만들지 않는다. 종목 변경 전에 시작한 응답이 뒤늦게 오면 무시한다. 기존 독립 거래 화면의 로직은 변경하지 않는다.
- 전체 `npm test` 통과. 작업 화면 전환 중 분석 영역 표시, 실제 호가/조회 실패/미연결/오래된 응답, 상태 확인 흐름을 추가 검증했다. 최신 캡처는 아래 같은 파일 경로로 갱신했다.

## 전면 UI 재구성 (2026-10-20)

사용자 피드백에 따라 배치만 바꾼 PR #82와 로고 PR #80을 하나의 새 PR로 대체한다. 해당 PR들의 기존 화면을 승인 목업 적용 완료로 보지 않는다.

- 한 줄 헤더(승인 로고·종목 검색·기존 지수·연결/테마 상태), 64px 메뉴 레일, 40:60 종목/종합 패널, 우측 하단 작업 영역으로 재구성했다.
- 종합 패널은 실제 데이터가 있는 시장 시세·계좌별 보유·개인 목표/손절·일정과 AI Signal 준비 중으로 구성했다. 차트/이동평균·수급은 이번 범위에서 제외한다. 기존 기업분석/호가/뉴스 진입은 유지한다.
- 표는 기본 주요 열과 상세 열 전환을 제공한다. 기존 열의 데이터/편집 동작을 제거하지 않는다.
- 하단 잔고·거래내역·실현손익은 기존 DOM과 계산을 재사용한다. 예수금 탭은 `getCashBalance()`와 저장된 계좌 값을 표시한다. 통화별 합산, D+2, 동기화 상태 판정 등 신규 계약은 구현하지 않았다.
- 투자일지는 좌측 종목창/우측 종합을 유지한 하단 작성 영역과 접이식 섹션으로 구성했다. 입력 ID·저장/수정 기능을 유지하고 빠른 일지 진입에서 기존 초안을 덮어쓰지 않는다.
- 계좌 편집은 기존 드로어 동작을 유지한다. 계좌 목업의 신규 상태/계약을 전부 구현한 것으로 간주하지 않는다.
- 다크 기본값·테마 설정·릴리스 문자열·Electron 보안 설정·시세/계산 로직을 보존한다.
- 전체 `npm test` 통과. 신규 셸/열 전환/개인 목표/예수금 함수 재사용/일지 초안/기록 진입 회귀 검사를 추가했다. 1400×900 및 1024×768 배치 검사와 다크/라이트 캡처를 확인했다.
- 실제 실행 검토 캡처: [메인 라이트](design/desktop-main-v2-review/main-light.png), [메인 다크](design/desktop-main-v2-review/main-dark.png), [투자일지](design/desktop-main-v2-review/journal-light.png), [예수금](design/desktop-main-v2-review/cash-light.png). 검토용 데이터는 캡처 브라우저에만 넣었으며 앱 코드에는 하드코딩하지 않았다. Windows 설치/실계좌 검증은 미실시다.
