# StockBook 개발 기록

## 2026-11-07 · 빠른 매도 및 실현손익 수익률

- 일반·빠른 매도는 같은 평균단가 공식을 사용한다. 손익은 `(매도가 − 평균단가) × 매도 수량`, 수익률은 `(매도가 − 평균단가) ÷ 평균단가 × 100`이다. 기존과 같이 수수료·세금 차감 전 기준이다.
- 과거 매도는 저장된 수익률을 우선 표시한다. 값이 비어 있으면 거래에 기록된 매수단가를 사용한다. 기존 빠른 주문 표시가 있고 매도가·수량·총액·손익으로 당시 평균단가를 역산할 수 있는 건도 조회 시 계산한다. 나머지는 확인 불가로 표시하며 조회로 원본을 저장하지 않는다.
- 요약에 전체 매도 건수와 수익률 확인 건수를 함께 표시한다. 매도 건별 단순 평균에는 확인된 값만 포함하며 실제 0%도 포함한다.
- 가상 예시에서 평균단가 100원, 매도가 120원, 수량 4주는 두 경로 모두 +80원과 +20%다. 과거 빠른 매도 +20%, 실제 0%, 근거 부족 1건을 조회하면 전체 3건 중 2건으로 평균 +10%를 표시한다.
- 격리 작업 사본에서 `npm test`를 실행했다. 정적 검사, 단위·브라우저 테스트 96개, 스모크 검사를 통과했다. Playwright는 설치된 Chrome으로 실행했고, 매도 검증은 별도 브라우저 컨텍스트의 가상 기록을 사용했다.
