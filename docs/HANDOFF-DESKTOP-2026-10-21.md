## 화면 기준과 남은 문제

- 데스크톱 전용이다. 모바일 화면/하단 모바일 탐색을 PC에 이식하지 않는다.
- 좌측 종목창은 전체 높이 유지, 전체 비율 약 40:60. 우측 상단은 가격·차트·호가, 우측 하단은 작업 탭과 독립 분석 영역.
- 투자일지를 쓰면서 AI 분석과 규칙 신호를 함께 볼 수 있어야 한다. 각 영역의 부족한 데이터와 확인 흐름을 분리한다.
- #83의 차트는 데이터 없음 상태다. 5호가는 기존 IPC를 수동 조회한다. 실제 차트 엔진/일봉·규칙 엔진·수급 데이터는 연결되지 않았다. AI 모델도 main에는 연결되지 않았다.
- 사용자 로컬 실행에서 KIS/실시간/종목 호출은 정상으로 보였으나 사용자가 화면의 작은 글씨·큰 여백·낮은 정보 밀도를 지적했다. 디자인 완성을 선언하지 않는다.
- 예수금은 기존 getCashBalance(), 손익·수수료·세금·계좌 합산은 기존 함수를 재사용한다. 장부/통화/D+2 등 미정 정책을 UI에서 확정하지 않는다.
- Windows 창/설치/작업표시줄 아이콘은 기존 PNG/ICO 경로로 교체됐다. 큰 원본 에셋과 실제 앱의 테마 대응을 구분한다.

## 아린·네로: 개인용 CLI 구성

사용자 결정:

| 역할 | 실행 도구 | 책임 |
| --- | --- | --- |
| 네로 | Claude Code CLI | 시세·공시·보유·선택 투자일지를 대조해 분석 |
| 아린 | Codex CLI | 분석을 사용자 상황에 맞게 설명하고 선택지·후속 작업 제안 |
| 계산 엔진 | 기존/후속 결정적 계산 코드 | 손익·조건 충족·규칙 신호 |

- 최소한 네로·아린은 개인용으로 사용한다. 새 API 키 연결을 전제로 시작하지 않는다.
- 사용자가 `네로 분석`을 명시 실행한다. 결과에서 `아린에게 설명 요청`을 별도 선택한다. 매번 네로→아린을 자동 연속 호출하지 않는다.
- 기존 CLI 어댑터·모델 설정 재사용 가능성, Stock Book 자료의 입력/출력 계약, 기준 시각·결측·취소·시간 제한·결과 보관·실행 권한을 시스템룸이 검토한다.
- 이 방의 마지막 결정은 검토 전 CLI 실행 코드를 변경하지 않는 것이었다. 이후 별도 작업으로 열린 #84(미리보기), #86(동의/로그인 정책)을 반드시 먼저 읽어 중복 구현하지 않는다. 원격 브랜치 존재만으로 추가 실행 승인이나 모델 호출 완료를 추정하지 않는다.
- 비공개 캐릭터 프로젝트·토큰·캡슐·코드를 이 저장소로 복사하지 않는다. 어떤 자료가 CLI를 통해 모델 제공자에게 전송되는지와 로컬 CLI 로그인 재사용은 별개다. 실제 전송·로그인·로그아웃·모델 호출은 이관 작업에서 하지 않았다.

## 프록시 오류와 환경 이관

- 기본 셸에서 `HTTP_PROXY`/`HTTPS_PROXY`는 상속된 `http://proxy:8080`을 사용한다. Git 전용 프록시 설정 조회는 없음(exit 1).
- 최초 재현: 2026-10-15 18:34:50 KST. curl은 `Failed to connect to proxy port 8080 after 2 ms: Could not connect to server`, git ls-remote는 같은 유형의 fatal 오류(exit 128).
- 이번 재현: 2026-10-21 13:47:55 KST, `curl -I --connect-timeout 5 --max-time 8 https://github.com`:
  `curl: (7) Failed to connect to proxy port 8080 after 0 ms: Could not connect to server`.
- GitHub 연결 도구는 정상 조회됐다. 추가 네트워크 권한을 적용한 git fetch는 성공했다. 기본 샌드박스 접근과 런타임 자체 장애를 구분하며 모든 방/환경의 장애로 단정하지 않는다.
- 프록시/환경변수/인증 파일/네트워크 정책을 임의 변경하거나 직접 연결로 우회하지 않았다. 실행 환경 재시작·지원팀 신고도 실제 수행한 적은 없다.
- 새 환경도 실패하면 오류 전문·KST 발생 시각·일반 셸과 권한 적용 시 결과를 지원팀에 전달한다. 설명 예: “GitHub 연결 도구는 정상이나 기본 셸은 프록시 8080 연결 실패”. 인증 값은 첨부하지 않는다.
