# 투자 원칙 데이터

투자 원칙의 의미와 근거를 기록하는 카탈로그다. 원칙 자체의 승인과 자동 판정 산식·수치 기준의 확정을 구분한다.
이 디렉터리의 JSON은 설계·인계용 원칙 데이터이며 앱이 현재 읽어 실행하는 설정이나 Shared Contract가 아니다.

| 원칙 ID | 원칙 | 승인 상태 | 원칙 데이터 |
|---|---|---|---|
| `support_resistance_role_reversal` | 주요 가격대의 지지·저항과 역할 전환 | 사용자 승인, 2026-10-16 | [JSON](principles/support-resistance-role-reversal.json) |

## 주요 가격대의 지지·저항과 역할 전환

사용자가 과거 저점 반응 구간과 그 반대인 저항을 함께 원칙 데이터에 포함하도록 승인했다.
승인 범위는 다음의 원칙 정의와 증거 기록이다.

- 과거 반등·반락·거래 집중이 누적된 가격대를 구간으로 기록한다.
- 같은 구간도 현재 가격 위치와 접근 방향에 따라 지지 또는 저항 후보가 된다.
- 지지를 이탈한 뒤 아래에서 재시험하면 저항 전환을, 저항을 돌파한 뒤 위에서 재시험하면 지지 전환을 확인한다.
- 돌파·이탈 자체와 역할 전환의 확인을 구분한다. 한 번의 반응만으로 바닥·천장 확정을 보장하지 않는다.
- 가격 구간, 봉 주기·기준 시각, 과거 반응, 접근 방향, 관측 사건, 보강·반박 근거, 무효화 조건을 남긴다.
- 수급·거래대금은 가격 반응을 보강하거나 반박하는 근거로 연결하며 특정 주체의 의도를 단정하지 않는다.

원칙 데이터는 개별 종목의 가격이나 제공된 차트의 수동 표시를 자동 판정 정답으로 저장하지 않는다.
과거 사례를 기록할 때도 해당 시점까지 알 수 있었던 근거와 실제 확인 가능 시점을 구분한다.
후속 봉에서 확인된 저점을 이전 시점의 확정 신호로 소급하지 않고, 구간을 갱신해도 과거 판정의 근거를 보존한다.
기업행동에 따른 수정주가·수량 조정 여부가 불분명하면 비교 가능성을 먼저 확인한다.

## 자동 판정과 기존 기능의 경계

현재 앱의 기업분석 화면에는 `state.analysisChecks`에 저장하는 수동 매매 원칙 체크리스트가 있다.
이 카탈로그는 기존 체크 항목·점수·저장 키를 변경하지 않는다. 지지와 저항을 모두 확인했다는 이유만으로 매수 점수를 올리지 않는다.

자동 평가기는 [구조 개편 계획 §10](STRUCTURE-REVAMP-PLAN.md#10-50--rules-engine--signal-49-이후)과
[#50](https://github.com/mj94920/stockbook/issues/50)의 선행 단계·착수 승인에 따라 구현한다.
원칙 승인만으로 #29·#47·Contract·#49를 건너뛰거나 #50 엔진 구현을 시작하지 않는다.
Signal·Event의 최종 스키마, 저장소와 IPC는 이 JSON으로 확정하지 않는다.

아래 수치·계산 기준은 미정으로 남기며 JSON의 null을 0 또는 자동 기본값으로 처리하지 않는다.

- 가격 구간의 허용오차와 탐색 기간
- 최소 과거 반응 횟수와 같은 반응을 중복 계산하지 않는 분리 기준
- 장중 고가·저가 또는 종가 중 돌파·이탈 판단 기준
- 확인·재시험 기간과 무효화 기준

기준이 확정되고 입력 자료가 갖춰질 때까지 자동 판정은 실행하지 않는다.
기준·자료 부족을 조건 미충족으로 간주하지 않고 판단 불가로 표시하는 원칙을 유지한다.

## 후속 검증 요구

자동 평가기 구현 시 승인된 수치 기준으로 다음 상황을 검증한다. 이 문서에서는 테스트 기대 숫자를 정하지 않는다.

| 상황 | 확인할 불변조건 |
|---|---|
| 동일 구간에 위/아래에서 접근 | 접근 방향과 과거 역할을 보존하고 지지·저항 후보를 구분 |
| 저항 돌파 후 지지 재시험 | 돌파 사건과 재시험·지지 확인을 분리 |
| 지지 이탈 후 저항 재시험 | 이탈 사건과 재시험·저항 확인을 분리 |
| 장중만 이탈한 뒤 회복 | 선택된 장중/종가 판정 기준을 일관되게 적용 |
| 여러 봉이 한 번의 반응에 해당 | 인접 봉을 독립 반응으로 과다 계산하지 않음 |
| 뒤에 반등 봉이 추가됨 | 이전 시점 판정에 미래 정보가 유입되지 않음 |
| 구간 갱신 또는 기업행동 발생 | 당시 구간·조정 근거와 과거 판정을 보존 |
| 임계값 미정·자료 부족 | 임의 기본값으로 신호를 만들지 않고 판단 불가로 구분 |
