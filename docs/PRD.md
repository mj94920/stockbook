# 초기 PRD 및 후속 기획 메모 — 보관 안내

원문은 [개편 전 자료 보관함](archive/pre-revamp/PRD.md)으로 옮겼다. 본문은 변경하지 않았다.

이 문서는 초기 PWA·포터블 배포 설명과 이후 추가된 2차 기획 메모가 섞여 있다.
보관은 요구사항 폐기나 구현 완료를 뜻하지 않는다. 미반영 기획은 원문에서 계속 확인할 수 있다.
현행 플랫폼·빌드·개발 규칙은 [CLAUDE.md](../CLAUDE.md), 작업 순서는
[2차 구조 개편 계획](STRUCTURE-REVAMP-PLAN.md)을 따른다.
전체 구분은 [문서 안내](README.md)를 본다. Legacy PWA/TWA 복원 지시로 사용하지 않는다.
