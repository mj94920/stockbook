## 1. 제품 개요

### 제품명
StockBook — 나만의 주식 포트폴리오 관리 앱

### 한 줄 설명
국내·해외 주식 포트폴리오를 하나의 화면에서 관리하고, 매매 기록·투자일지·복리 목표 달성 여부를 추적하는 개인용 앱

### 플랫폼
| 플랫폼 | 방식 | 업데이트 |
|---|---|---|
| 데스크톱 (Windows) | Electron 포터블 exe | `npm run build` 후 exe 교체 |
| 모바일 (Android) | TWA + GitHub Pages PWA | `git push`만으로 자동 갱신 |

### 데이터 저장
- **데스크톱**: `%APPDATA%\StockBook\stockbook-data.json` (JSON 단일 파일)
- **모바일**: 브라우저 localStorage (서비스워커 network-first 전략)

## 2. 핵심 사용자 및 투자 원칙

- **사용자**: 개인 투자자 (국내 주식 중심, 해외 일부 병행)
- **매매 스타일**: 5일선·10일선 기반 단기 타이밍 + 20일·200일선 중장기 추세 필터
- **목표 수익률**: 월 4.5% 복리 (월별 달성 여부 추적)

## 3. 주요 기능 명세

### 3-1. 포트폴리오 탭

#### 포트폴리오 테이블
- 보유 종목 목록: 종목명, 평균단가, 수량, 현재가, 평가금액, 수익률, 섹터, 포지션
- 현재가 셀 하단 sub-text: **평균단가 대비** 손익 표시
  - 이익: 빨간색 `+N원 (+X.XX%)`
  - 손실: 파란색 `-N원 (-X.XX%)`
- 매도 버튼, 종목 편집, 목표가·손절가 설정

#### 시세 자동 조회
- **국내 종목(6자리 코드)**: 네이버 금융 모바일 API 우선 → 실패 시 Yahoo Finance `.KS`→`.KQ` 폴백
- **해외 종목**: Yahoo Finance v8 Chart API 직접 호출
- 저장 데이터: `currentPrice`, `prevClose`(전일종가), `openPrice`(당일 시가)
- 🔄 시세 새로고침 버튼 (전체 일괄), 개별 모달 내 자동 조회 버튼

#### 매수 등록 폼
- 종목명 선택 시 섹터·포지션 자동완성 + 현재가 자동 조회
- 티커 미등록 종목은 현재가 수동 입력 유지

#### 포트폴리오 바 차트
- 섹터별 비중 시각화

---

### 3-2. 잔고·예수금 탭

#### 총자산 관리
- 총자산(totalAsset) 수동 입력
- 포트폴리오 평가금액 + 예수금 자동 합산 표시

#### 예수금 탭
- 입금/출금 내역 등록 폼
- 잔액 자동 계산: 입금 − 출금 − 현금매수 + 현금매도

---

### 3-3. 거래기록 탭

- 매수/매도 등록 시 자동 생성 (수동 등록 폼 제거)
- 종목별 필터, 날짜순 정렬
- 🧹 고아 데이터 정리 버튼: 포트폴리오에 없는 종목의 잔존 기록 일괄 삭제

---

### 3-4. 투자일지 탭

- 매수 시 buy 타입 일지 자동 생성
- 매도 시 기존 buy 일지에 매도일·투자기간·수익률 자동 기입, 없으면 sell 타입 초안 생성
- 멘털 상태 기록 (원칙 지켰어 / 흔들렸네 / 고점에 팔았다 등)

---

### 3-5. 월복리 시뮬레이터 탭

#### 기본 계산
- 입력: 원금, 목표 월 수익률(%), 기간(개월), 월 추가납입, 시작일
- 출력: 월별 목표잔액, 최종 자산, 총 투입금, 수익, 누적수익률, 연환산수익률
- **입력값 영구 저장**: 앱 재시작 후 자동 복원·재계산 (`state.mcSettings`)

#### 월별 실적 추적 (시작일 입력 시 활성화)
| 열 | 내용 |
|---|---|
| 월 | 달력 기준 연월 (현재 달: 파란 배경 + ◀현재) |
| 목표잔액 | 복리 계산 목표값 |
| 실제잔액 | 스냅샷 or 현재 총자산 (클릭하여 수동 입력) |
| 실제수익률 | 전월 대비 실제 수익률 (초록/노랑/빨강) |
| 달성 | ✅ (실제 ≥ 목표) / ❌ (미달) / — (미입력) |

- **📌 이번 달 실적 기록** 버튼: 현재 총자산을 이번 달 스냅샷으로 저장
- **실제잔액 셀 클릭** → 전용 모달로 과거 달 금액 수동 입력 (0 입력 시 삭제)
- 시작일 없으면 기존 수동 체크(✅/—) 방식 유지

---

### 3-6. 물타기 계산기 탭

- 현재 보유 수량·단가 입력 → 추가 매수 후 평균단가 자동 계산
- 모바일 서브탭 스크롤 지원 (7개 탭 가로 스크롤)

---

### 3-7. 뉴스·공시 탭

#### 종목 검색
- 검색창에 종목명/코드 입력 → DART, 네이버 뉴스, Investing.com 직접 검색

#### 링크 그리드
- DART 전자공시 (사업보고서, 분기보고서, 주요사항보고서)
- 네이버 금융 (시황, 뉴스 통합)
- Investing.com (해외 종목, 거시경제)

#### 보유 종목별 바로가기 (하단 카드)
- 국내 종목: 📋DART · 💹네이버 금융
- 해외 종목: 📋DART · Inv.
- (제거된 항목: 📰뉴스 별도 버튼, KRX KIND 버튼)

## 6. 미결 과제 및 향후 계획

### 기술 부채
- Yahoo Finance CORS 정책 변경 시 Cloudflare Worker 프록시로 전환 필요
- 네이버 금융 API CORS 실환경 검증 (현재 동작 확인, 정책 변경 가능성 있음)

### 향후 고려 기능
- 데이터 저장 경로를 exe 위치 기준으로 변경 (완전 이식성 확보, Option B)
- 복리 시뮬레이터 "초기 자산 체크포인트" 기능 — 시작 시점 실제 잔액 설정
- 종목별 차트 연동 (네이버 금융 차트 iframe 또는 딥링크)
- 백업/복원 기능 (JSON 내보내기·가져오기)

### 2차 재편 방향 — 시장 → 기업 → ETF → 내 투자

StockBook의 정보 구조를 단순 시세·링크 모음이 아니라 다음 4계층으로 확장한다.

1. **시장(Market)** — Investing.com 등 외부 시장 데이터 소스를 활용해 지수·거시경제·시장 일정·시황을 제공한다.
2. **기업(Company)** — 버틀러(Butler)의 정보 구조를 참고해 국내 개별 종목의 실적·재무·밸류에이션·주주환원·IR·공시를 한 종목 프로필 안에서 연결한다.
3. **ETF** — FunETF의 탐색·비교 구조를 참고해 일반 주식과 별도의 ETF 데이터 모델 및 상세 화면을 제공한다.
4. **내 투자(My Investment)** — StockBook 고유 영역. 위 정보를 실제 보유종목·관심종목·매매기록·투자일지와 연결한다.

#### 기업 분석 강화
- 단순 PER/PBR 나열보다 **최근 분기·연도별 변화**를 우선 시각화한다.
- 실적, 재무제표, 밸류에이션, 재무건전성, 주주환원, 주요 공시, IR 정보를 종목 상세에서 통합한다.
- 외부 서비스 자체를 복제하기보다 StockBook의 보유/관심/매매 데이터와 연결되는 정보만 우선 도입한다.

#### 공시 자동 분류
DART 등에서 가져오는 공시를 제목 목록으로만 제공하지 않고 투자 의미에 따라 분류한다.

- 실적
- 배당
- 자사주
- 내부자·대주주
- 공급계약
- 투자·증설
- 자금조달
- IR

분류된 공시는 보유종목·관심종목 및 정보센터와 연결한다.

#### ETF 전용 정보 구조
ETF는 일반 기업 종목과 다른 상세 화면을 사용한다. 우선 검토 항목:

- 추종지수
- 총보수
- 순자산
- 분배율·분배주기
- 구성종목
- 섹터·국가 비중
- 환헤지 여부
- 과세 관련 정보
- 괴리율·추적오차
- 기간별 수익률

ETF 2개 이상을 선택해 핵심 지표를 나란히 비교하는 기능도 검토한다.

#### 설계 원칙
- Investing.com 계열은 **시장 데이터 소스** 역할을 유지한다.
- Butler는 **기업 데이터·공시 해석 구조**, FunETF는 **ETF 전용 데이터 모델·비교 UX**의 참고 대상으로 삼는다.
- StockBook의 차별점은 외부 서비스를 그대로 재현하는 것이 아니라, 모든 시장·기업·ETF 정보를 **사용자의 실제 포트폴리오와 투자 기록에 연결하는 것**이다.
- 매거진·콘텐츠 사업 등 개인 투자 워크스테이션과 직접 관계없는 기능은 범위에서 제외한다.

### 장기 구조 — '기록 앱'에서 '투자 의사결정 시스템'으로

기능을 더 붙이기보다 구조를 바꾼다. 버틀러·FunETF 는 **"이 종목이 어떤가"**를 알려주고, StockBook 은 **"이 종목이 지금 내 투자에서 어떤 의미인가"**를 알려준다. GitHub 에픽: #46

| 계층 | 하는 일 |
|------|---------|
| 데이터 | 외부 시세·DART·재무·ETF → Provider 어댑터 → 표준 데이터 → 시계열 저장 |
| 분석 | 지표 계산 → 투자 규칙 판정 → 이벤트(신호) 감지 |
| 개인 | 포트폴리오 → 거래 → 투자일지 → 매수 근거 → 결과 |
| 표현 | 시장센터 · 종목 상세 · ETF 상세 · 정보센터 · 종목 타임라인 · 알림 |

#### 6가지 축 (권장 순서)
0. **종목 통합 객체 (Asset)** — #47
   - 보유·거래·일지·관심·메모·공시·실적·원칙 판정이 모두 같은 종목 ID 에 붙는다. ETF 는 같은 Asset 아래 `etf` 타입.
   - 현재 거래·일지는 종목**명**으로만 연결돼 있어 가장 먼저 바로잡는다.
1. **데이터 수집층과 UI 분리 (Provider 어댑터)** — #48
   - UI 는 표준 함수만 호출한다. 출처(Investing.com·네이버·Yahoo·DART 등)가 막히면 어댑터 하나만 교체한다.
   - 공식 출처(KIS·OpenDART·KRX)를 우선한다.
2. **현재값이 아닌 변화를 저장 (시계열)** — #49
   - 일봉·수급·밸류에이션·분기 재무를 기록한다. SQLite(#29) 를 전제로 한다.
   - 이것이 있어야 "영업이익 3분기 연속 증가", "거래대금 20일 평균 대비 180%", "외국인 5일 연속 순매수", "PER 1년 평균 이하" 같은 판정이 가능하다.
3. **규칙 엔진** — #50
   - 투자원칙을 코드 곳곳이 아닌 데이터 규칙으로 관리한다. 예: 급락 −10% 경고, 5·10MA 골든크로스, 거래대금 급증, 손절가 도달, 공급계약 공시.
   - 데이터로 계산할 수 있는 판정은 **전부 규칙 엔진이 한다** (AI 가 차트를 보고 추측하지 않는다).
4. **종목 타임라인** — #51
   - 매수 → 실적발표 → 추가매수 → 공시 → 목표가 변경 → 일부매도 → 일지를 시간순 한 줄로 보여준다.
   - 몇 달 뒤에도 "왜 샀고, 무슨 일이 있었고, 왜 팔았는지" 복원된다.
   - 거래·일지만으로 된 MVP 는 Asset(0) 직후 가능하다.
5. **투자 판단과 결과 연결** — #52
   - 매수 근거(실적개선·기술적반등·저평가·수급·이벤트·장기성장)를 기록하고, 매도 시 결과를 자동으로 붙인다.
   - 근거별 승률, 물타기 성과, 원칙 위반 거래 손실률 같은 **내 투자 습관 통계**를 만든다.

#### 원칙
- 규칙 엔진의 출력(Signal)은 안정된 형식으로 유지한다. 나중에 캐릭터 에이전트가 차트를 읽지 않고 이 판정 결과만 받아 말할 수 있다.
- 사용자 기록을 건드리는 변경은 백업 → 마이그레이션 → 실패 시 롤백을 포함한다.
- 새 계층 코드는 `index.html` 에 쌓지 않고 별도 JS 파일로 시작한다(모듈 분리의 첫걸음).
