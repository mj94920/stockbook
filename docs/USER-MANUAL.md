# StockBook 사용 설명서

관심종목, 보유 잔고, 거래와 투자일지를 관리합니다. **매수·매도 버튼은 기록용이며 실제 주문은 나가지 않습니다.**

## 시작하기

[Windows 설치 파일](https://github.com/mj94920/stockbook/releases/latest)을 설치하고 실행하세요. API 연결은 나중에 해도 됩니다.

왼쪽 **종합**에서 종목을 선택하고, 오른쪽 아래 탭에서 작업합니다.

| 탭 | 용도 |
|---|---|
| 잔고 | 보유 수량·평균단가·평가손익 확인 |
| 매매 | 매수·매도 기록 |
| 계산기 | 복리·추가 매수 평균단가 계산 |
| 투자일지 | 투자 이유와 결과 기록 |
| 거래내역 | 기록 조회·CSV 내보내기 |
| 실현손익 | 매도한 거래의 손익 확인 |
| 예수금 | 계좌별 저장된 예수금 확인 |

## 관심종목 추가

1. **종합 → 관심종목 → ＋ 관심종목 추가**를 누릅니다.
2. 종목명·코드로 찾아 선택합니다. 목록이 없으면 시장을 골라 **선택 시장 종목 불러오기**를 누릅니다.
3. 직접 입력하려면 **목록에 없는 종목 직접 입력**에서 6자리 코드와 이름을 적습니다.

목록 위 필터는 등록된 종목을 찾는 용도입니다. **＋ 테마·그룹**으로 분류하고, 종목 행을 눌러 상세를 봅니다.

## 계좌와 시세 연결

- **계좌 → 계좌 추가:** 증권사·별칭을 입력하고 저장합니다.
- **설정 → API 연결 → 한국투자증권:** 본인의 APP Key·Secret과 필요한 계좌 정보를 입력합니다. 키는 다른 사람에게 공유하지 마세요.

계좌 등록만으로 증권사 자료가 조회되지는 않습니다. 가격이 비어 있으면 연결 상태와 마지막 조회 시각을 확인하세요.

## 거래 기록

1. 종목을 선택하고 **매매** 탭을 엽니다.
2. 계좌, 매수·매도, 현금·신용을 선택합니다.
3. 실제 거래 단가와 수량을 입력하고 **매수 기록** 또는 **매도 기록**을 누릅니다.
4. **잔고·거래내역**에서 반영 결과를 확인합니다.

예: 70,000원에 10주 매수했다면 단가 `70,000`, 수량 `10`을 입력합니다. 같은 거래를 두 번 기록하면 보유 수량도 중복 반영됩니다.

## 투자일지

**투자일지**에서 매수일·종목명·매도/매수를 입력하고, 투자 이유와 메모를 적어 **저장**합니다. 매매 기록으로 생성된 초안은 이어 작성할 수 있습니다.

일지 화면이 멈춘 것 같으면 같은 내용을 다시 저장하기 전에 목록에서 반영 여부를 확인하세요.

## 뉴스·설정

- **뉴스·시황:** 종목을 선택하고 **종목 뉴스 보기**를 누릅니다. 기사 검색은 받은 기사 안에서 찾는 기능입니다.
- **캘린더:** 시장 일정과 경제지표를 확인합니다.
- **설정 → 화면·테마:** 다크·라이트와 화면 밀도를 바꿉니다.

## 백업·복원

- **데이터 → 백업:** 내려받은 JSON 파일을 따로 보관합니다.
- **데이터 → 복원:** 백업 JSON을 선택합니다. **현재 기록을 덮어쓰므로 먼저 기존 자료를 백업하세요.**

다른 PC로 옮길 때도 백업·복원을 사용합니다. API 연결 설정은 따로 확인하세요.

## 알아둘 점

웹과 Windows 앱의 기록은 자동으로 동기화되지 않습니다. 시세·뉴스·계좌 연결은 Windows 앱을 이용하세요.

차트·AI·규칙에 **데이터 없음**이 나오면 해당 자료가 연결되지 않은 상태입니다. 거래·일지 등 기록 기능은 별도로 사용할 수 있습니다.
