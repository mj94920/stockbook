# StockBook Mobile 2.0 — Industry Icon Tile 디자인룸 지시서

작성일: 2026-10-11 (KST)

## 1. 승인 상태와 작업 목적

사용자가 승인한 것은 대표 업종 12종 시안의 **작은 라운드 사각형 타일 + 단일 업종 상징 + 절제된 3D 표현**이라는 스타일 방향이다. 기존 실사형 업종 이미지를 기준으로 삼지 않는다.

아래 수치 토큰은 이 방향을 일관되게 제작하기 위한 **제안 규격**이다. 최종 개별 에셋, 업종 분류, 전체 화면, 구현 범위까지 승인된 것으로 기록하지 않는다.

디자인룸은 이 스타일을 업종 아이콘 제작 기준으로 고정하고, 시스템 담당이 검토한 업종 목록에 따라 전체 세트를 확장한다. 현재 12종은 화풍 검토용이며 최종 분류체계가 아니다.

## 2. 필수 스타일

- 동일 크기의 rounded-square 타일 내부에 업종을 상징하는 단일 오브젝트를 배치한다.
- 실사가 아닌 단순화된 3D 픽토그램으로 통일한다. 형태 인식에 필요한 세부만 남긴다.
- 저채도 배경과 은은한 입체감을 사용한다. 업종명과 금융정보가 시각적 중심이다.
- 타일 배경색은 카테고리 식별용으로 고정한다. 상승·하락에 따라 변하지 않는다.
- 실사 사진, 대형 제품 이미지, 타일 없는 오브젝트 사진, 복합 장면, 과한 광택·그림자, 서로 다른 화풍은 사용하지 않는다.

## 3. 디자인 토큰 제안

모든 수치는 같은 기준 좌표계로 관리한다. 48dp 타일을 기준으로 비례 확대한다.

| 토큰 | 제안 값 | 적용 원칙 |
|---|---|---|
| tile.size.default | 48dp | 업종 목록 기본값 |
| tile.size.compact | 40dp | 정보 밀도가 높은 목록; 조작 영역은 별도 확보 |
| tile.cornerRadius | 타일 변의 25% | 48dp에서 12dp; 크기가 바뀌어도 비율 유지 |
| object.bounds | 가로·세로 각각 타일의 72% 이하 | 여백 최소 14%; 모든 형태를 억지로 같은 크기로 늘리지 않음 |
| object.opticalSize | 대표 칩 아이콘 대비 시각적 무게 ±10% | 가늘거나 긴 오브젝트는 광학 보정; 축소 화면에서 판단 |
| object.anchor | 타일 중앙 | 광학 보정은 각 축 ±3% 이내로 기록 |
| camera | 정면에 가까운 3/4 시점 | 업종별 임의 시점 변경 금지; 상징 인식 우선 |
| light.direction | 좌상단 → 우하단 | 전체 패밀리 동일 |
| material | 매트 또는 약한 반광 | 실사 질감·거울 반사·강한 금속광 금지 |
| shadow | 검정 10%, y 1dp, blur 2dp | 타일 내부의 부드러운 접지 그림자; 외부 드롭섀도 없음 |
| background.saturation | HSL 10~25% | 팔레트 범위 제약; 최종 색은 아래 고정 HEX 사용 |
| background.lightness | HSL 88~94% | 밝은 배경 기준; 최종 대비는 렌더 결과 검토 |
| tile.background | 단색 | 화면용 최종 에셋에 배경 그라데이션 없음 |
| tile.outside | 투명 | 라운드 모서리 밖은 실제 알파 투명 |

고정 배경 팔레트 제안: blueGray `#E5ECF2`, sage `#E7EEEA`, lavender `#EBE8F0`, sand `#F0EBE3`, tealGray `#E4EEED`, neutral `#ECECEC`. 새 업종은 이 팔레트에서 선택하고 자유롭게 새 색을 추가하지 않는다. 오브젝트와 배경이 구분되도록 내부 대비를 확인한다.

생성형 이미지의 프롬프트만으로 규격 충족을 주장하지 않는다. 최종 마스크·색·크기·그림자는 제작 과정에서 맞추고 확인한다. 승인된 시안의 은은한 질감을 유지하되 수치 제안과 차이가 생기면 검토 사항으로 기록한다.

## 4. 대표 모티프 12종

| 표시명 (검토용) | 단일 상징 | 단순화 기준 |
|---|---|---|
| 반도체 | 칩 | 몸체와 소수 핀; 회로 글자 없음 |
| 조선 | 선박 | 선체와 선실; LNG선 사진·갑판 장비 묘사 없음 |
| 항공우주 | 위성 | 본체와 태양광 패널 |
| 전력기기 | 변압기 | 본체와 최소 절연체 |
| 물류 | 컨테이너 | 컨테이너 하나; 지게차와 함께 묶지 않음 |
| 게임 | 게임패드 | 외곽과 주요 버튼만 |
| 식품 | 곡물 이삭 | 이삭 하나; 식품 정물 장면 없음 |
| 자동차 | 자동차 | 차체와 바퀴 중심 |
| 금융 | 은행 건물 | 지붕과 기둥 |
| 바이오·헬스케어 | DNA | 굵고 명료한 이중나선 |
| 에너지 | 풍력 터빈 | 대표 후보; 전체 에너지를 풍력으로 좁게 읽을 위험은 검토 |
| 건설 | 크레인 | 얇은 구조가 40dp에서 사라지지 않도록 단순화 |

테마는 업종과 별도 체계로 관리한다. 유사한 스타일을 쓰더라도 업종 분류나 키 매핑과 혼합하지 않는다.

## 5. 목록 적용 규격 제안

- 기본 타일 48dp, 타일과 텍스트 간격 12dp, 화면 좌우 여백 16dp.
- 업종명 16sp / medium, 상승·하락 종목 수 12sp / regular, 등락률 16sp / medium을 시작값으로 사용한다.
- 왼쪽은 타일, 가운데는 업종명과 종목 수, 오른쪽은 부호가 있는 등락률이다. 기본 행 높이는 최소 72dp이며 내용에 따라 늘어난다.
- 상승은 빨강, 하락은 파랑. 부호·문구도 함께 표시하고 색만으로 상태를 전달하지 않는다.
- 행 전체가 동일한 업종 진입 대상이며 최소 48dp 조작 영역을 제공한다. 타일과 행을 중복 포커스 대상으로 만들지 않는다.
- 360dp·글자 200%에서는 텍스트 높이를 고정하지 않는다. 등락률이 충돌하면 다음 줄로 재배치한다. 아이콘은 글자 확대와 함께 대형 이미지로 키우지 않는다.
- 수치는 예시로 명시한다. 공급원·산출 방식·기준 시각은 시스템 검토 후 정한다.

검토할 탐색 흐름: 시장 → 업종 탐색 → 업종 → 하위 산업/영위 사업과 관련 기업 → 종목 상세. 하위 단계 수를 임의로 고정하지 않는다.

## 6. 시스템 경계

확인 자료: `INDUSTRY_THEME_SYSTEM_PROPOSAL.md` (현재 상태: 설계 제안·구현 없음·저장소 미반영).

- 문서는 불변 `industryKey`를 제공하고 UI가 `industryKey → 아이콘`을 소유하는 구조를 제안한다. 이 문서가 계약 확정이나 Gate 통과를 대신하지 않는다.
- 표시명으로 에셋을 찾지 않는다. 시스템에서 확인된 키를 UI 매핑 표에 연결한다. 대표 12종을 위해 새 계약 키를 임의 발급하지 않는다.
- 알 수 없는 키는 동일 규격의 기본 타일로 표시하고, 제공된 업종명과 탐색 기능을 유지한다. 아이콘 미지원과 실제 미분류는 구분한다.
- 업종 키는 계층 경로를 담지 않으며 부모 관계는 시스템 데이터로 처리한다.
- 공개 데이터의 종목 참조는 제안서 기준 `(market, stockCode)`이며, 클라이언트 매핑으로 종목 상세에 연결한다. 아이콘 제작에서 `assetId` 규칙을 바꾸지 않는다.
- 테마의 `themeKey`와 업종의 `industryKey`는 구분한다. 자산은 UI 소유이며 공유 데이터 계약에 이미지·파일명·색상 토큰을 추가하지 않는다.
- 게이트 순서: #29 → #47 → Contract Gate → #48 → #49 → #50 → Android Gate. 이 작업은 디자인 산출물이며 구현 승인이 아니다.

## 7. 디자인룸 산출물과 확장 순서

1. 대표 12종을 위 토큰에 맞춰 정규화하고, 40dp·48dp 실제 크기 검토판과 시장 목록 적용 시안을 만든다.
2. 화풍 승인 상태를 유지하면서 수치 토큰과 축소 가독성을 검토한다. 개별 상징 수정이 필요하면 목록에 기록한다.
3. 시스템 담당이 확인한 진입 업종 목록과 키를 받은 뒤 전체 세트를 같은 패밀리로 확장한다. 30개·50개는 확장 가능성의 예시이며 확정 제작 수량이 아니다.
4. 최종 타일별 PNG(알파 포함) 1×·2×·3×와 고해상도 원본, UI 매핑 표, 토큰표, 변경 기록을 전달한다. 타일 안에는 글자를 넣지 않는다.
5. 전체 검토판뿐 아니라 실제 목록에서도 동일한 크기·광원·배경 채도·시각적 무게를 확인한다. 검토판을 잘라 만든 파일을 검수 없이 최종 에셋으로 사용하지 않는다.

완료 기준: 모든 타일의 외곽·모서리·광원·그림자가 일치하고, 40dp에서 업종을 알아볼 수 있으며, 업종명과 금융정보의 읽기를 방해하지 않는다. 실제 Android 접근성 검증과 최종 화면 승인은 별도로 남긴다.
