# StockBook 모바일 v0.3 — 명시 승인 목업 인계

이 묶음은 모바일 디자인룸에서 사용자가 **명시적으로 통과시킨 두 영역**만 추출한 1차 인계본이다. 전체 카드 제작 완료나 22개 화면 전체 승인을 의미하지 않는다. 기존 v0.2 자료는 보존하며, 아래 승인 범위에 한해 이 묶음을 최신 시각 기준으로 사용한다.

## 승인 범위와 근거

| ID | 승인 영역 | 사용자 승인 문구 | 미리보기 |
|---|---|---|---|
| HOME | 홈 통합본: 카드 순서·밀도·라이트 톤 | `통과` | [home.html](home.html) |
| NEWS | 시장의 뉴스·공시: 기사/공시 분류, 언론사 필터, 발행일순 피드 | `음 데이터를 어떻게 가져올 건지는 확실치 않아도 일단 합격` | [news-disclosures.html](news-disclosures.html) |

대화의 `다음`만으로 완전 승인을 추정하지 않았다. 최근 제작한 시황·경제일정·종목 목록·종합·사업 통합 수정본은 이번 묶음에서 제외했다. 과거 단품 시안의 승인 대응표는 별도 정리 전이므로 포함하지 않는다.

## 열어보기

저장소를 내려받은 뒤 이 폴더의 `home.html` 또는 `news-disclosures.html`을 브라우저에서 연다. 언론사 필터, 일반 기사/공시 전환, 필터 결과 건수, 빈 결과 복구, 홈 판정 근거 열기는 로컬에서 시연된다. 기사 클릭은 외부 원문 링크다. Lucide 아이콘 표시는 고정 버전 CDN을 사용하며 네트워크가 없으면 텍스트로 조작할 수 있다.

- `source/`: 승인 통합본에서 해당 영역만 추출한 HTML/CSS 및 뉴스 시연 로직.
- 루트 HTML 두 개: 독립 실행용 문서 래퍼를 붙인 미리보기.
- `preview.css`, `preview.js`: 인계용 래퍼와 두 승인 영역 사이의 탐색만 담당.
- `manifest.json`: 원본 파일명, 원본 SHA-256, 추출본 SHA-256, 승인 근거.

미승인 화면이 섞인 전체 통합 HTML은 업로드하지 않았다. 경계 밖 버튼은 승인 인계 범위 밖이라는 안내만 표시한다. 이는 원래 연결 설계의 삭제가 아니다. 구현룸은 아래 목적지 목록을 참고한다.

## 카드 구성과 연결 목적지

| 영역 | 순서 | 카드/조작 | 원래 연결 목적지 |
|---|---:|---|---|
| 홈 | 1 | 총자산: 보유주식 + 예수금 | 자산 상세 모달 |
| 홈 | 2 | 보유·관심종목 목록 | 종목 목록 / 선택 종목 상세 |
| 홈 | 3 | 시장 지수 | 시장 |
| 홈 | 4 | 투자 신호: 쉬운 설명 + 판정 근거 | 선택 종목 상세 |
| 홈 | 5 | 주요 일정 | 시장의 경제일정 |
| 홈 | 6 | 작성 중인 투자일지 | 일지 목록 |
| 뉴스·공시 | 1 | 일반 기사 / 공시 선택 | 같은 피드 내부 전환 |
| 뉴스·공시 | 2 | 언론사 필터 / 적용 / 전체 선택 | 일반 기사 피드 갱신 |
| 뉴스·공시 | 3 | 발행일 최신순 기사 카드 | 해당 언론사 원문 |
| 뉴스·공시 | 4 | 문서형 공시 목록 | 개별 공시 원문: 현재 가상 시연 |

언론사는 연합뉴스·연합인포맥스·매일경제·블로터·지디넷코리아를 참고한다. 언론사별 섹션이나 고정 순서를 만들지 않는다. 수치·기사 목록은 검토용 예시이고 최신 정보가 아니다.

## 디자인 구현룸 인계 원칙

사용자는 승인 목업을 먼저 GitHub에 보관하고, 디자인 구현룸의 코드 작업과 남은 디자인 검수를 이어가도록 요청했다. 이 PR은 그 시각 자료 인계이며 저장소의 Android/Shared Contract 게이트를 변경하지 않는다. 현재 단계에서 허용된 코드 작업의 범위는 구현룸이 `AGENTS.md`, `CLAUDE.md §8`과 해당 단계 이슈를 대조해 정한다.

- `index.html`, `splash.html` 등 PC 앱에 모바일 레이아웃을 반영하지 않는다.
- 이 PR은 `android/`, `shared/`, 실행 앱 코드·워크플로·버전·데이터 계약을 변경하지 않는다.
- 라이트 톤, 둥근 카드, 진한 제목/본문, 내용에 맞춘 카드 높이를 유지한다. 다크 모드는 별도 검수 대상이다.
- 하단 도구는 홈 / 시장 / 종목 / 자산관리 / 일지. 홈 상단 발견 진입과 하단 도구 바로 위 설정·인증 위치를 유지한다. 스크롤 고정 여부는 미정이다.
- 해외투자 UI를 추가하지 않는다. 총자산에는 예수금을 포함한다.
- 기업 로고의 정확한 확보·적용과 브랜드/로고 배치 확정은 후속 작업이다. 임의 이니셜 로고를 확정 에셋으로 사용하지 않는다.
- HTML의 하드코딩 색과 DOM 기반 시연 코드는 디자인 원본이다. 제품 구현에서는 해당 플랫폼의 토큰·컴포넌트로 옮기며 원본 HTML을 앱 코드로 재사용하지 않는다.

## 미확정 경계

- 뉴스 수집 방식, 제공 범위, 이미지/본문 사용 범위, 원문 표시·연결 정책, 공시 제공원과 식별자는 미확정이다. 샘플 링크나 사진 포함은 데이터 수집/재배포 방식의 승인이 아니다.
- 홈 신호의 값과 골든크로스 예시는 규칙 엔진 결과가 아니다. `규칙 판정 · 투자 권유 아님` 고지는 유지하고 실제 정의는 Contract/규칙 엔진을 따른다.
- 예수금 세부(당일/정산 예정), CSV, 취소·정정 화면은 이번 묶음에 없다. 후속 인계 시 `임시 · 계약 미확정` 표기를 유지한다.
- DC-1은 `{ settled, amount, pending } + asOf` 조건부 승인. `basis`는 기존 의미를 유지하며 결제일 미확인을 체결일 결제 또는 d0=d2로 확정하지 않는다. compatibility 규칙은 별도다.
- DC-2는 원 이벤트 참조 `void` + 신규 정정 이벤트, `correctionOf` 연결. 원 거래 재작성/물리 삭제 및 연결 일지 자동 삭제를 하지 않는다. `ledger_revision`은 #64 v3 범위다.
