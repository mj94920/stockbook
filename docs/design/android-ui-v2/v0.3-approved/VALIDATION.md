- 뉴스 JSON 파싱 및 실행 JavaScript 문법 검사.

- 저장소 `npm test` 통과: 기존 PC 앱 정적 검사 및 브라우저 초기화 스모크.
- 앱 코드·워크플로·버전·기존 시안 변경 없음. 새 인계 디렉터리만 추가.

## 한계

- 초기 `npm run test:setup`은 OS 패키지 설치 권한 제약으로 실패. 검사 스크립트를 바꾸지 않고 `npx playwright install chromium`으로 headless browser를 확보해 위 검사를 수행했다.
- 실행 환경에 한글 시스템 글꼴이 없어 스크린샷에 대체 글리프가 나타났다. 이 환경의 이미지로 한글 글꼴 품질·줄바꿈 최종 통과를 주장하지 않으며 검수용 PNG를 인계본에 포함하지 않았다.
- 아이콘 CDN은 브라우저 검사에서 차단했다. 텍스트 조작을 검사했고, 외부 원문 페이지 자체를 열어 유효성/내용을 검증하지 않았다.
- Android 실기기, 글자 200%, 스크린리더, 실제 Provider/저장/규칙 엔진은 검증하지 않았다. 디자인 승인은 데이터 계약·실제 구현 검증과 별개다.
