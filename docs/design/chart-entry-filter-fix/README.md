# 일봉 진입 신호의 전체 수식 복원

## 문제와 변경

기존 차트는 사용자가 전달한 큰형님 수식 중 일목·226일선·BB 공통 가격 조건만
표시하고 있어 동일 기간의 삼성전자 신호가 17개였다.
전체 수식의 거래량·실제 거래대금·양봉·2.5% 상승·직전 226일선 하락 조건을 복원했다.
원본 수식에 없는 쿨다운, 연속 신호 첫 봉만 표시, 평소 대비 증가율은 추가하지 않았다.

- 가격 계산은 entryPriceSeries에 분리해 회귀 비교에만 사용한다.
- 차트는 entrySignalSeries의 전체 조건만 사용한다.
- 상승폭: C >= C(1)*1.025 또는 C >= O*1.025. O<C는 별도 필수.
- 장기선: MA226(3)>MA226(2)>MA226(1). 현재 MA 기울기는 요구하지 않는다.
- 완전한 이력 최소 229봉. 이력 미충족은 null이다.
- 거래대금은 실제 KRW 정수만 허용한다. C*V 추정 없음.
- 기존 KIS 조회값과 일봉의 날짜·거래량이 일치하는 금액만 사용한다.
- 알려진 필터가 탈락하면 false, 나머지를 통과했지만 대금이 없으면 null/판정 대기다.
- 거래대금 수신·실패·불일치 및 지표 설정 변경은 신호 캐시를 무효화한다.
- 상세/종합 차트 모두 같은 계산을 쓰며 주·월·년에는 추가하지 않았다.
- 삭제·복원·기간 이동·기존 이평/BB 설정 동작을 유지한다.

## 거래량·거래대금 단위

현재 기본값은 이전 사용자 지정 기준을 유지한 70,000주·5,000억원이다.
지표 설정에서 최소 수량(주), 금액, 금액 단위(억원/백만원)를 명시하고 조절할 수 있다.
이는 키움 원본 수식 V/amount 단위가 확정됐다는 의미가 아니다.
첨부 파일의 거래량은 주이고, 거래대금 수치는 백만원으로 환산했을 때
600일 모두 가격 저가~고가 범위와 일관됨을 별도 검증했다.
원본 수식 내부 단위는 별도 확인이 필요하다.
이 삼성전자 사례에서는 5,000억원과 5,000백만원 둘 다 모든 가격 후보가 통과하므로
두 단위가 동일한 두 날짜를 만든다. 이 결과를 다른 종목의 단위 확정 근거로 쓰지 않는다.

## 재현 데이터와 결과

사용자가 제공한 CDT/XLS 600개 일봉(2024-05-21 ~ 2026-11-06)을 사용했다.
CDT 레코드를 읽어 XLS의 날짜·OHLC·거래량·거래대금·미결제약정과 전부 일치함을 확인했다.
test/fixtures/samsung-kiwoom-signals.json은 해당 공개 시세 값에서 작성했다.
amountKRW는 파일의 백만원 수치를 원으로 변환한 값이다.
파일은 테스트 전용이며 제품의 시세 공급원/개인 계좌 데이터로 넣지 않았다.

## 남은 한계

KIS 실제 거래대금 수신은 기존 최근 최대 100거래일 범위다.
그 이전 봉은 다른 조건을 만족하더라도 대금 미수신이면 판정 대기다.
이번 수정은 과거 거래대금 대량 수집·키움 파일 가져오기 UI를 추가하지 않는다.
실제 Windows 앱·KIS 인증 연결·네이버/키움 가격 조정 기준 일치는 미검증이다.
원격 push·병합·배포·워크플로·버전 변경은 하지 않았다.
