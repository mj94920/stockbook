fix(chart): 세력 입장 규모 조건과 신호 가독성 보완

가격 조건만으로 반복 표시하던 세력 입장에 사용자가 추가한 작은형님·큰형님 조건을 적용한다. 작은형님은 거래량 2,000주·amount 150, 큰형님은 70,000주·amount 5,000과 과거 3·2·1봉 전 226일선의 연속 하락 조건을 사용한다. 둘 다 양봉과 전일 종가 또는 당일 시가 대비 2.5% 상승이 필요하다.

사용자가 amount를 억원으로 확정해 작은형님은 150억원, 큰형님은 5,000억원 기준으로 고정한다. 이전 단위 선택값은 계산에 영향을 주지 않으며 단위 선택 UI와 미확인 안내를 제거한다. 거래대금은 기존 KIS 조회에서 일자/거래량이 맞는 값만 사용한다. 미수신·불일치 날짜는 비워 두며 최근 최대 100거래일 조회 범위를 확대하지 않는다.

작은형님은 보라색 화살표, 큰형님은 금색 별로 표시하며 동시 충족 시 큰형님을 우선한다. 신저가 마름모·RSI 원과 색·모양을 구분하고 신호 크기를 CSS 픽셀로 유지해 가로세로 확대·높이 조절 시 납작해지지 않게 한다. 신호별 Del/숨김/실행 취소/복원·봉 정보·주기별 설정을 유지한다. 기존 공통 entry 숨김은 두 신호 숨김으로 읽는다.

검증: 전체 npm test 94개·정적·스모크 통과와 합성 자료/모의 IPC를 이용한 운영 HTML의 경계값·미수신·고정 금액 환산·두 신호 우선순위·날짜 정렬·확대/높이·밝고 어두운 배경 대비 검사. HTS 전체 수치 일치, 이번 변경의 Windows/NSIS 실기는 미확인이다. 합성 화면을 실수신 증거로 취급하지 않는다. main/preload/API/워크플로/버전/계좌·저장 구조 변경은 없다.
