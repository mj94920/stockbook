# 작은형님·큰형님 조건과 신호 표시

2026-10-29 KST. PR #94 병합 이후 사용자 추가 조건을 반영한다. 기존 가격 조건만의 초록 ▲를 작은형님·큰형님으로 나누고, SVG 확대 비율에 따라 납작해지던 기호의 크기를 CSS 픽셀로 유지한다.

## 계산

공통 가격식은 [기존 수식](../chart-entry/README.md)의 A/B(9·26·52, 과거 25봉), 종가 단순 226일선, BB(20/2) 세 OR 그룹 그대로다. `entrySignalSeries`는 이 가격 조건 계산용으로 유지하고 실제 표시에는 `entryTierSeries`의 추가 조건을 적용한다.

| 조건 | 작은형님 | 큰형님 |
| --- | --- | --- |
| 공통 가격식 | 모두 충족 | 모두 충족 |
| `avg(V,1)` | 2,000주 이상 | 70,000주 이상 |
| `amount` | 150 이상 | 5,000 이상 |
| 양봉 | `O < C` | `O < C` |
| 상승률 | `C >= C(1)*1.025` 또는 `C >= O*1.025` | 동일 |
| 226일선 기울기 | 추가하지 않음 | `avg(C(3),226) > avg(C(2),226) > avg(C(1),226)` |
| 최소 가격 이력 | 226봉 | 229봉 |

기울기는 현재값을 포함하지 않은 과거 3·2·1봉 전의 단순 226일선 비교다. 거래량은 해당 일봉 값이다. 원식에 없는 첫 봉만 표시·거래 주체 추정·그 밖의 조건은 추가하지 않는다.

## amount 단위는 미확인

사용자는 원본 단위를 모른다고 응답했다. 지표 이름만으로 단위를 추론하지 않는다. 최초값은 **확인 필요 · 규모 판정 보류**이며 새 신호를 표시하지 않는다. `지표 설정 → 세력 입장 → 수식의 amount 단위`에서 선택한 해석에 한해서 계산한다.

| 선택한 해석 | 작은형님 150 | 큰형님 5,000 |
| --- | --- | --- |
| 백만원 | 1억 5천만원 | 50억원 |
| 억원 | 150억원 | 5,000억원 |

선택은 원본 단위 확인이나 HTS 일치 증거가 아니다. 기준값 150·5,000은 사용자 식 그대로이며 실수신 원 금액과 비교할 때만 환산한다. 설정은 기존 주기별 저장에 포함하며 주기 초기화 시 미선택으로 복귀한다. 축소 일봉은 같은 단위 설정을 읽고 다른 창의 저장 변경도 반영한다. 일·주·월·년 지표 분리는 유지한다.

## 실제 금액 범위

기존 KIS 일별 거래대금의 날짜와 가격 일봉 거래량이 정확히 맞는 값만 사용한다. 최근 최대 100거래일 한 번의 조회 범위를 확대하지 않는다. 미수신·실패·거래량 불일치 날짜는 판정 보류다. 종가×거래량이나 합성 금액을 운영 차트에 대입하지 않는다. 가격 차트는 부가 조회를 기다리지 않고 표시하며 단위·금액 수신 봉 수·판정 보류 수를 안내한다. 수급 fallback은 거래대금 대용이 아니다.

## 표시

- 작은형님: 고가 위 **보라색 아래 화살표**, 상세 14×16px·축소 10×12px.
- 큰형님: 고가 위 **금색 별**, 외접 반지름 8px. 두 조건이 맞으면 표시 중인 큰형님 하나를 우선한다. 큰형님을 숨기면 충족한 작은형님을 볼 수 있다.
- 신저가: 저가 아래 하늘색 **마름모** 10×10px.
- RSI: 고가 위 주황색 **원** 10×10px. 입장 신호와 동시에 발생하면 위로 분리한다.

배경색 1.5px 테두리를 두며 표시 신호에 필요한 가격 위아래 여백을 확보한다. 표시 가격 범위가 달라져도 십자선·그리기 좌표의 역변환은 같은 축을 사용한다. 밝은 테마에서는 더 진한 색으로 바꾸고 실제 SVG 배경 대비 3:1 이상을 검사한다. 새로운 테마 버튼은 추가하지 않는다. 신호별 선택·손바닥 커서·Del·실행 취소·복원·범례와 봉 정보가 연결된다. 옛 `entry` 숨김 설정은 두 새 신호 숨김으로 해석한다.

## 검증과 남은 확인

`verify.cjs`와 [결과](result.json)는 운영 HTML에 **합성 OHLCV·합성 KIS 형식 금액·모의 IPC**를 제공한 화면 검사다. 백만원 해석은 테스트 입력이며 원본 단위 확인이 아니다. [다크](dark-wide.png) · [라이트](light-wide.png) · [좁은 창](dark-tablet.png). 인증된 실거래대금이나 Windows 실기 증거로 취급하지 않는다.

전체 `npm test` 94개·정적 검사·기존 스모크를 통과했다. 자동 검사는 두 규모 경계·서로 다른 amount 환산·양봉·상승률 양쪽 분기·과거 226일선 하락·미수신 보류·미래 봉 배제·신호 중복 우선순위·삭제/복원·주기 분리·단위 저장과 축소 적용·가로세로 비율·테마 대비·가격 높이 변경을 확인한다. [전체 검사 로그](npm-test.txt)를 따른다.

원본 amount 단위, 원본 HTS 전체 날짜·수치 대조, 이번 변경의 Windows Electron 실기와 새 NSIS 설치본 검사는 아직 확인하지 않았다. 월봉 피보나치·BinaryWaveMACD의 암호화 수식은 계속 보류한다. 병합·배포는 별도다.
