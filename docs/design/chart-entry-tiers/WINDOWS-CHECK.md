# Windows 실기 체크 · 2026-10-30 예정

사용자는 2026-10-29 모바일 환경에서 작업을 계속하도록 요청했고, 데스크톱 실기는 다음 날로 미뤘다. 이 파일의 준비·브라우저 검사는 Windows 통과 기록이 아니다. 병합·배포는 실기 결과와 별도 승인 뒤 진행한다.

## 실행

앱을 종료한 뒤 기존 PowerShell 작업 폴더에서 실행한다. 작업 파일 변경이 있으면 임의로 지우거나 강제로 전환하지 않는다.

```powershell
cd "C:\Users\mj949\OneDrive\Documents\GitHub\stockbook"
git status --short --branch
git fetch origin
git switch codex/chart-signal-visibility
git pull --ff-only origin codex/chart-signal-visibility
git log -1 --oneline
npm start
```

검수 결과에 `git log`로 확인한 SHA를 남긴다. 기존 설치본에는 이 브랜치의 변경이 아직 없으므로 설치본과 소스 실행을 혼동하지 않는다.

## 확인

1. 서로 다른 종목을 검색해 상세 일봉을 연다. 지표 설정과 범례의 기준이 **작은형님 150억원·큰형님 5,000억원**, 거래량은 각각 **2,000주·70,000주**인지 확인한다. 단위 선택은 없어야 한다.
2. 거래대금의 출처·수신 봉 수와 판정 보류 안내를 확인한다. 최근 최대 100거래일 밖·미수신·거래량 불일치 날짜에 신호가 없는 것은 정상이다. 실제 조건 충족 여부를 모르는 상태에서 신호가 없다는 이유만으로 실패 처리하지 않는다.
3. 조건을 충족한 봉은 작은형님 보라색 화살표·큰형님 금색 별로 보이고, 같은 봉의 두 신호는 큰형님 하나를 우선한다. 신저가 마름모·RSI 원과 구분되는지 확인한다. 화면 예시는 합성 자료인 [미리보기](preview.html)를 참고한다.
4. 창 크기·가로 확대/축소·가격 구간 높이를 바꿔도 기호가 납작해지거나 차트 밖으로 잘리지 않는지 확인한다. 신호를 선택해 Del → 실행 취소 → 지표 표시에서 숨김/복원을 확인한다. 큰형님을 숨기면 같은 봉에서 충족한 작은형님을 볼 수 있다.
5. 마우스 또는 터치로 신호를 누르면 날짜·봉 정보·형님 이름이 표시되는지 확인한다. 터치 정보는 손을 떼어도 남고 차트 밖을 누르면 닫혀야 한다. 마우스는 차트 밖으로 이동하면 기존처럼 닫힌다. 차트 그리기·휠 이동·드래그 확대가 계속 작동해야 한다.
6. 주·월·연봉으로 바꾸면 두 형님 신호가 없어야 한다. 주봉 OBV·월봉 이평·연봉 일반 거래량의 기존 구성이 유지되는지 확인한다.

필요할 때만 원본 HTS의 **종목·날짜·시장/가격 원자료·거래량·거래대금**을 함께 비교한다. 공급자 OHLCV 차이가 확인된 전례가 있으므로 기호 개수만으로 전체 수치 일치를 주장하지 않는다.
