# 투자자별 일별 순매수 연결

2026-10-28 KST. 사용자가 거래대금·상세 검색의 Windows 통과를 확인한 뒤 외국인·기관·개인의 수급 연결을 요청했다. `codex/chart-trading-value`의 후속 작업이다.

기본 표시는 **일별 순매수(주)**다. 외국인 분홍·기관 노랑·개인 남색의 세 선을 같은 0 기준과 축으로 비교한다. 상세의 표시 선택에서 **수신 자료 누적**으로 바꿀 수 있다. 누적은 첫 수신일 직전 0을 기준으로 받은 행만 더하며, 보유량·보유비율·매집량을 뜻하지 않는다. 세 주체의 합이 0이 아니더라도 값을 보정하지 않고, 개인을 나머지 수량으로 역산하지 않는다.

## 데이터 범위

- KIS 공식 [함수 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/domestic_stock/domestic_stock_functions.py)의 `inquire_investor`, [응답 필드 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_investor/chk_inquire_investor.py)를 확인했다. 고정 경로 `/uapi/domestic-stock/v1/quotations/inquire-investor`, TR `FHKST01010900`, 시장 `J`(KRX), 선택한 국내 6자리 코드로 한 번 조회한다. 외국인은 공급자 분류상 외국인+기타 외국인이다. 공식 설명에 따르면 당일 자료는 장 종료 후 제공된다.
- `stck_bsop_date`, `frgn_ntby_qty`, `orgn_ntby_qty`, `prsn_ntby_qty`를 사용한다. 거래대금 필드나 보유율을 주식 수량으로 변환하지 않는다. 양수·음수·0과 제공된 세 주체를 그대로 유지한다. 빈 필드를 0으로 채우지 않는다.
- 조회 기간 파라미터나 페이지 반복을 추가하지 않는다. **API가 한 번에 제공한 날짜만** 표시하며 응답 안전 상한은 100행이다. 과거 100일이 항상 제공된다는 뜻이 아니다. 실제 수신 시작·끝·행 수·KRX·단위·조회 시각을 표시한다.
- 이 API는 통상 응답에 종목코드가 없다. 검증한 요청 코드와 고정 목적지를 결과 메타데이터에 묶으며, 응답에 종목 식별자가 있는 경우 불일치를 거부한다. 날짜 오류·중복·미래 날짜·정수가 아닌 수량·안전 정수 초과·누적 과정의 범위 초과·세 주체 누락·실패 응답은 거부한다.
- 세 선은 **가격 차트와 별도의 일별 날짜 축**이다. 주·월봉으로 바꾸거나 가격 차트를 이동해도 수신 수급의 일자를 주·월 값으로 가장하지 않는다. 없는 날짜를 생성하지 않는다. 연봉은 기존 캔들·1/5/10년 이평만 표시하며 수급을 요청하지 않는다.
- 실제 보유량·보유비율·100% 분할·A/D 추정은 이번 범위에 없다. 다른 종목이나 오류에 삼성전자 보존 자료를 붙이지 않는다.

## 로딩과 조작

가격 차트 표시를 기다리게 하지 않고 거래대금과도 별개로 조회한다. 기존 KIS 인증은 메인 프로세스에서만 재사용한다. 앱·알려진 상세 창의 메인 프레임과 국내 6자리 코드만 허용한다. 60초·최대 20종목 메모리 캐시/요청 공유, 인증 포함 8초 제한과 중단, 렌더러 9초 제한을 사용한다. 실패/잘못된 자료는 성공으로 캐시하지 않는다. 새 DB·자동 수집·주기적 갱신은 없다.

상세에서는 정상 수신 시 수급 구간을 연다. **수급 다시 조회**, 일별/누적 선택, 일별 수량 표, Del 숨김·지표 표시에서 복원, 높이 조절을 지원한다. 종합에서는 수신된 수급 요약을 접힌 상태로 추가하고 선택 시 세 선을 펼친다. 작은 창에서 거래대금과 동시에 펼치면 가격·거래량 공간을 남기고 수급 영역에 내부 스크롤을 적용한다. 창이나 표시 방식 변경은 가격 봉·확대·이동·그린 선을 바꾸지 않는다.

검사는 날짜·수량·세 주체 보존·누적 안전성·캐시·요청 중 공유·인증 없음·중단/재시도·IPC 송신자·가격 선표시·종목 변경 후 지연 응답 무시·오종목 메타데이터 거부·일별/누적 전환·숨김/복원·크기 조절·작은 화면 동시 표시를 포함한다. 기존 거래대금·검색·차트 회귀 검사도 함께 실행한다. 인증된 KIS 수급 실수신·Windows Electron/NSIS·HTS 수치 대조는 이 검사에 포함되지 않는다. 병합·배포하지 않는다.

Windows에서는 KIS 연결 후 서로 다른 종목의 수급 구간을 열고, 표시된 **같은 날짜·KRX 기준**의 외국인/기관/개인 순매수 수량을 HTS와 비교한다. 장중 당일 값이 없어도 0으로 만들지 않는지, 기존 날짜의 음수 수량이 보존되는지, 수급 조회 실패 시 가격 차트가 유지되는지도 확인한다.
