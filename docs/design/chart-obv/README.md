# 주기별 차트 구성

2026-10-28 사용자가 다시 제공한 일·주·월·년 이미지에 맞춰 지표 목록·설정·하단 구간을 분리했다. 종합 축소 차트와 상세가 같은 구성을 사용한다.

연봉 이평은 사용자가 새 이미지의 1·3·5·6·10년으로 최종 확인했다. 주봉 RSI도 14·30으로 확인했다. RSI 평활 방식은 이미지에 없으므로 단순/Wilder를 직접 선택하기 전에는 RSI 신호를 표시하지 않는다. 일봉 이미지의 실제 보유수량·BinaryWaveMACD와 월봉 피보나치 미확인 산식을 현재 순매수·일반 MACD·이평 구름으로 바꿔 표시하지 않는다. 바코드는 사용자 지시대로 제외한다. 이 차트가 키움 원본을 전부 재현했다고 주장하지 않는다.

이평·조건과 표시 유형은 주기별로 저장한다. 주봉 기본 유형은 매물대이며 나머지는 기본 캔들이다. 매물대는 표시 범위 일봉의 고저 범위에 거래량을 나눠 추정한 분포이고 실제 가격별 체결 자료가 아니다. 이전 공통 유형 저장값을 다른 주기에 강제 적용하지 않는다. 기존에 저장한 주기별 이평·조건은 유지한다. 새 기본값은 `지표 설정 → 주기 기본값 → 적용` 또는 해당 주기의 `차트 설정 초기화`로 적용한다. 초기화해도 선·메모·계좌 자료는 유지한다.

## OBV

주봉 상세의 OBV 구간을 펼친다. 종합 주봉에서는 가격 아래에 표시한다. 기본 시그널은 9주 단순평균이며 지표 설정에서 기간(1~500봉)과 단순/지수를 바꾼다. 다른 주기의 지표 목록·설정에는 OBV를 넣지 않는다.

직전 주봉보다 종가가 오르면 해당 주 거래량을 더하고 내리면 빼며 보합은 유지한다. 첫 수신 종가를 0으로 두므로 전체 상장 이력의 절대 OBV와 같다고 주장하지 않는다. 첫 부분 집계의 거래량은 시작값에 더하지 않는다. 시그널은 기간이 충분할 때부터 표시하고 지수평균은 최초 단순평균에 `2/(기간+1)`을 적용한다. 원본 HTS 시그널 평균 방식/초기값은 미확인이다.

봉 정보·가격과 같은 날짜 정렬·높이 조절·Del 숨김·복원·주기별 설정 저장을 지원한다. 전체 수신 이력에서 계산하므로 확대·이동으로 누적 시작점이 바뀌지 않는다.

## 신호

일봉 신저가는 `lowest(C(1),Period)>C`로 직전 40봉 종가 최저값보다 현재 종가가 엄격히 낮을 때 파랑 ▼를 표시한다. 같은 값에는 뜨지 않고 이전 N봉이 모두 필요하다. 주봉·월봉·연봉에는 이 신호가 없다.

RSI는 일봉·주봉에서 각각 설정한다. 이전 RSI가 하단값 이상이고 이번 RSI가 그 아래인 봉에만 주황 ●를 표시한다. N개 종가 변화 이후부터 계산하며 단순은 최근 N개 상승/하락 변화 평균, Wilder는 최초 단순평균 뒤 1/N 평활이다. 상승/하락 변화 모두 0이면 RSI 50, 하락만 0이면 100, 상승만 0이면 0이다. 키움 평활·동률 처리와의 수치 대조는 별도다. 월봉·연봉에는 이 신호를 넣지 않는다.

## 검증 범위

운영 HTML에 보존 삼성전자 OHLCV와 모의 IPC만 제공한다. Windows Electron/NSIS와 키움 수치 대조는 별도다. `verify.cjs`, `result.json`, 네 주기 PNG 및 종합 주봉 PNG로 실제 표시 구간이 서로 다른지 확인한다. RSI 14/30의 Wilder 선택은 검사용이며 복원된 키움 평활 방식으로 주장하지 않는다. 840×768에서는 설정 본문만 스크롤하고 닫기/적용 버튼을 유지한다.

수정 후 전체 `npm test` 89개·정적 검사·기존 스모크를 통과했다. 주기별 지표 목록/설정/유형 저장, 일봉만 부가 조회하는지, 종합 주봉의 가격·OBV 비율과 높이 조절, 연봉 일반 거래량 및 기존 날짜/구름/뉴스 연결 회귀를 검사했다. `test/news-reader.browser.test.cjs`의 예전 주봉 매매세 215개 기대는 OBV 215개 입력·두 선과 매매세 없음으로 수정했다. 검사 스크립트/워크플로는 변경하지 않았다.
