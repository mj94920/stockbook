# OBV·시그널

상세 차트의 `OBV` 구간을 펼친다. 기본 시그널은 9봉 단순평균이다. `지표 설정`에서 기간(1~500봉)과 단순/지수 방식을 바꾼다. 선택한 일·주·월봉으로 계산하며 연봉은 기존 기본 형태를 유지한다. 종합 축소 차트에는 추가하지 않는다.

종가가 직전 봉보다 오르면 해당 봉 거래량을 더하고, 내리면 빼며, 같으면 유지한다. 첫 수신 종가를 0으로 두므로 전체 상장 이력의 절대 OBV와 같다고 주장하지 않는다. 주·월의 첫 부분 집계 거래량도 이 시작값에 더하지 않는다. 시그널 단순평균은 전체 기간이 있을 때부터 표시하며 지수평균은 그 첫 단순평균을 초기값으로 `2/(기간+1)`을 적용한다. 원본 HTS 시그널 평균 방식과 초기값은 미확인이다.

받은 전체 이력에서 계산하고 보이는 구간만 잘라낸다. 휠은 이동, 축척·드래그는 확대/축소이며 가격과 같은 날짜에 정렬한다. 봉에 대면 OBV·시그널 값이 나오고, 구간을 선택한 뒤 Del로 숨기거나 지표 표시·복원으로 되돌릴 수 있다. 경계선으로 높이를 조절한다. 설정은 봉 주기별로 저장되고 초기화 시 9봉 단순으로 복귀한다.

보존 삼성전자 가격·거래량과 운영 HTML을 사용한 브라우저 화면 검사이며 Windows Electron/NSIS와 키움 수치 대조는 별도다. 실제 투자자별 순매수·보유량을 계산하는 지표가 아니다.

## 신저가·RSI 신호

`지표 설정 → 봉 신호`에 조건을 입력한다. 원본의 Period/LPercent는 아직 받지 못했으므로 기본값은 비어 있고 신호도 뜨지 않는다. 신저가는 직전 N봉 종가의 최저값보다 현재 종가가 엄격히 낮을 때 파랑 ▼로 표시한다. 같은 값은 신호가 아니다. 현재 봉과 이전 N봉을 섞지 않으며 N개 이전 종가가 모두 필요하다.

RSI는 기간·하단값·단순/Wilder 방식을 함께 선택한다. 이전 RSI가 하단값 이상이고 이번 RSI가 그 아래인 봉에 주황 ●가 뜬다. 계속 과매도인 모든 봉을 칠하는 방식이 아니다. N개의 종가 변화 이후부터 계산하고 초기에는 빈칸으로 둔다. 단순은 최근 N개 상승·하락 변화의 평균, Wilder는 최초 N개 단순평균 뒤 평활계수 1/N이다. 상승/하락 변화가 모두 0이면 RSI 50, 하락만 0이면 100, 상승만 0이면 0을 사용한다. 키움의 RSI 평활 방식·동률 처리와 일치하는지는 별도 대조가 필요하다.

같은 날짜의 봉에 신호를 표시하며 확대·이동해도 계산 이력은 유지한다. 신호 선택 → Del, 지표 표시/복원, 봉 주기별 저장과 설정 초기화를 지원한다. 초기화하면 조건은 다시 비어 있게 된다. 연봉·종합 축소에는 추가하지 않는다.

검증 결과: 전체 `npm test` 86개와 정적/기존 스모크 통과. `verify.cjs`는 운영 HTML에 보존 OHLCV만 제공하고 일·주·월 OBV와 조건 신호 예시를 화면으로 확인한다. 예시의 신저가 10봉·RSI 14/30 Wilder는 검사용 입력이며 앱 기본값이나 복원된 원본 설정이 아니다. 840×768에서는 조건 본문만 스크롤하고 닫기/적용 버튼을 유지한다. `result.json`과 PNG는 이 검증 결과다.
