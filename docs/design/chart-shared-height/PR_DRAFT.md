# fix(chart): 잔고 기준 차트 높이를 모든 작업 탭에서 유지

Head: `codex/chart-shared-workspace-height`

종합 화면에서 매매·예수금·투자일지 탭으로 바꿀 때 아래 패널의 내용이나 탭별 저장값 때문에 차트 크기가 바뀌던 문제를 수정합니다. 잔고를 기준으로 높이를 잡고, 사용자가 조절한 공통 비율을 모든 작업 탭에서 유지합니다. 긴 작업 내용은 내부에서 스크롤합니다.

기존 저장값은 잔고의 값만 이전하고, 초기화 후 재실행에도 이전 값이 되살아나지 않게 합니다. 전체 154개 검사·스모크·서식 검사 통과. 일곱 탭의 차트·캔들·거래량 크기, 조절·복원·초기화 및 내부 스크롤을 모의 자료로 검증했습니다. Windows 실기는 미검증입니다.

기준 커밋은 `a35c9acdf19726c590de355d7ec038aaa3d6cbf1`입니다. 선행 브랜치의 main 반영 상태와 충돌을 확인한 뒤 검토합니다. 병합·배포 승인은 별도입니다.
