# 종합 차트 높이를 작업 탭 사이에서 유지

기준 커밋: `a35c9acdf19726c590de355d7ec038aaa3d6cbf1`

## 사용자 동작

- 기본 크기는 잔고 탭의 레이아웃을 기준으로 잡는다.
- 차트와 아래 작업 패널 사이 구분선을 드래그하거나 방향키로 높이를 조절한다.
- 잔고·매매·계산기·투자일지·거래내역·실현손익·예수금 탭을 바꿔도 같은 창 크기에서는 차트 전체와 캔들·거래량 구간의 크기가 유지된다.
- 긴 작업 내용은 아래 패널 안에서 스크롤한다. 투자일지에도 별도 차트 높이를 적용하지 않는다.
- 조절한 비율은 재실행 후에도 복원된다. 구분선을 더블클릭하거나 Enter를 누르면 잔고 기준 기본 크기로 돌아간다.
- 창 자체의 크기가 바뀌면 공통 비율과 최소 작업 공간을 적용한다. 좁은 화면에서는 기존 반응형 배치를 사용한다. 상세 차트의 지표별 크기 조절과는 별개다.

## 구현 경계

기존에는 기본 CSS가 탭 내용의 높이로 작업 공간을 잡았고, 높이 저장도 탭별로 달랐다. 이제 기본 상태부터 명시적인 공통 분할을 적용한다. 잔고 레이아웃을 측정할 때 표시 속성과 MDI 열림 상태만 잠시 변경하고 동기적으로 복원한다. 애플리케이션 탭 전환 함수나 자료 수집·폼 렌더 함수를 호출하지 않는다.

새 저장 키는 `stockbook:workspace:heights:v2`의 `chartRatio`다. 기존 v1에서 유효한 `pf` 값만 이전한다. 다른 탭의 값은 선택하지 않으며 원본 v1 자료는 남겨 둔다. 초기화는 명시적인 null로 기록해 재실행 시 예전 잔고 값이 다시 살아나지 않게 한다. 데이터·계좌·거래·투자일지 저장에는 변경이 없다.

## 검증

- 일곱 작업 탭에서 기본 크기와 조절한 크기를 각각 비교한다. 차트 전체·캔들·거래량의 가로·세로 오차는 2px 미만이다.
- 긴 예수금 자료와 투자일지의 내부 스크롤을 확인한다.
- 조절값 재실행 복원, 투자일지에서 초기화, 모든 탭의 초기화 결과를 확인한다.
- v1 잔고 값 우선 이전, 다른 탭만 있는 v1 무시, 초기화 후 재실행 보존을 확인한다.
- 기존 드래그·지표 구간 정렬·창 크기 변경·작은 화면 최소 높이 검사를 유지한다. 기존의 '탭별 높이 복원' 기대는 사용자 요청에 맞춰 '공통 높이 유지'로 바꿨다.

명령: `npm test`, `npm run format:check`.
