# 차트 도구 선택 유지와 정보창 표시

기준 커밋: `c96f474c3017b722fa2d6484d769c1f6f785f09a`

- 추세선·수평선·수직선·분할선·봉중심선·도형·펜·텍스트를 한 번 사용해도 도구 선택을 유지한다.
- 같은 도구 버튼을 다시 누르거나 Esc, 확대 조절 선택으로 그리기 도구를 해제한다. 차트 설정 초기화도 도구를 해제한다.
- 그리기 도구 선택 중에는 캔들·보조지표 위의 떠다니는 정보창을 숨긴다. 이미 떠 있는 창도 선택 즉시 숨긴다. 십자선과 축 안내, 종합 화면의 고정 봉 정보는 유지한다.
- 도구를 해제하면 평소의 정보창·그린 객체 선택/편집으로 돌아간다.
- 조회 범위 변경 등으로 같은 차트를 다시 구성해도 선택을 유지한다. 상태는 차트 호스트별 메모리에만 저장하며 앱 재시작을 넘어 저장하지 않는다. 종합·상세 차트의 도구 선택은 각각 독립적이다.

## 검증

12개 그리기 도구를 각각 한 번 선택해 2회 연속 사용하고, 버튼 선택 표시·캔들/거래량 위 정보창 숨김·다시 누른 후 정보창 복귀를 확인한다. 조회 범위 변경 후 유지와 Esc 해제도 확인한다. 종합 차트의 연속 그리기·삭제·해제를 검사한다.

기존 검사 중 자동 해제를 전제로 하던 입력 흐름에는 명시적인 도구 해제를 넣었다. 기존 테스트의 assert 호출 415개는 모두 보존했고, 현재 440개다. 첫 검사에서는 기존 자동 해제 전제의 정보창 검사 2개와 추가한 종합 차트 검사의 잘못된 선택 핸들 대기 1개가 실패했다. 정보창 검사에 도구 해제를 명시하고, 종합 차트에서는 선택 전 선 자체를 클릭하도록 검사 입력을 수정했다.

검사 명령: `npm test`, `npm run format:check`.

전체 152개 검사·스모크·서식 검사 통과. 모의 IPC·브라우저 검증이며 Windows 실기 검증은 미실행이다. 기존 코드 정리·조건검색 브랜치 위의 변경이며 병합·배포 승인은 별도다.
