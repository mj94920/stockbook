feat(chart): 과거 거래대금 수동 추가 조회

최근 100거래일 밖에서는 거래대금 조건을 판정할 수 없던 일봉에 수동 과거 조회를 추가한다. 상세 거래대금 구간과 종합 차트 도구의 버튼으로 현재 받은 일봉 이력 최대 1,000봉까지 조회하고, 받은 금액으로 작은형님·큰형님 신호를 다시 계산한다.

페이지별 100행·추가 요청 최대 10회·전체 45초를 제한하고 날짜 구간을 엄격히 과거로 이동한다. 기존 최근 자료를 재사용하며 부분 수신·실패·취소에도 받은 값은 유지한다. 날짜/거래량이 맞지 않는 금액은 계속 비워 두고 수신·일치·판정 보류 수를 표시한다. 종목/기간 전환·지연 응답·같은 작업의 중복 구독을 처리하며 가격 조작을 막지 않는다.

기존 KIS 인증·고정 경로·KRX/D/원주가를 유지한다. IPC는 알려진 앱/차트 메인 프레임과 유효한 국내 코드·날짜 범위만 허용한다. 범위별 메모리 캐시 외 저장·자동 폴링·계좌 변경은 없다. 페이지의 100행 검증은 유지하고 결합 결과만 최대 1,000행으로 분리한다.

검증: 전체 npm test 105개·정적·스모크 통과 및 합성 자료/모의 IPC의 다중 페이지·부분 실패·취소·기간 전환·신호 재계산·축소 높이 비율·오프라인 미리보기. 인증된 KIS 과거 실수신과 Windows/NSIS는 아직 미실행이다. 실제 1,000봉 제공이나 HTS 수치 일치를 보장하지 않는다.

의존: #95. 해당 검수 브랜치 8101626030db89834e7e0b2ece19ed9c10023ac2에서 분기했으며 #95를 수정하지 않는다. #95 병합 후 main과 동기화해 이 후속 변경만 검토한다. #95와 이 작업 모두 데스크톱 실기는 2026-10-30 대기다.
