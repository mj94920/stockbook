## 확인할 사항

1. KIS가 연결된 종목의 상세 일봉을 열고 최근 수신 봉 수를 확인한다. 자동으로 과거 추가 요청이 시작되지 않아야 한다.
2. `거래대금 → 과거 거래대금 불러오기`를 누르고 수신 범위·요청 횟수·일치/보류 수가 갱신되는지 확인한다. 가격 확대·이동·그리기는 계속 사용할 수 있어야 한다.
3. 100거래일보다 오래된 실제 완료 일봉에서 날짜·KRX 거래량·거래대금을 확인한다. 공급자가 제공하지 않거나 거래량이 다른 날짜는 판정 보류가 정상이다. 모든 날짜에 신호가 생겨야 하는 것은 아니다.
4. 조회 도중 취소하고, 받은 금액이 유지되며 후속 묶음이 더 시작되지 않는지 확인한다. 이미 메인에서 시작된 한 묶음은 제한 시간 내 끝날 수 있다.
5. 조회 도중 종목·기간을 바꿔 늦은 응답이 현재 종목을 덮지 않는지 확인한다. 같은 종목의 기간 변경은 받은 과거 자료를 유지해야 한다. 다시 버튼을 누르면 이어받을 수 있다.
6. 종합 일봉의 `차트 도구`에서도 버튼이 작동하며 작은 창의 가격·거래량 높이 비율이 유지되는지 확인한다. 주·월·연봉에는 조회 도구가 나오지 않아야 한다.
7. 실제 과거 수신 날짜 중 조건에 맞는 작은형님 150억원·큰형님 5,000억원 표시를 확인한다. 원본 HTS와 비교할 때는 종목·날짜·시장·OHLCV·거래대금을 함께 기록한다.

결과: SHA / 종목 / 요청 범위 / 수신·일치·보류 수 / 통과·실패 항목을 남긴다. API 키·토큰·계좌 잔액은 기록하지 않는다. 테스트 완료 전 병합·배포하지 않는다.
