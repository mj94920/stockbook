feat(chart): 거래대금 표시와 상세 차트 종목 검색 추가

기존 차트는 실제 금액을 받지 못해 거래대금 구간이 비어 있었다. 가격 차트 표시 후 기존 KIS 인증으로 최근 최대 100일 금액을 별도 조회하고, 날짜와 거래량이 일치한 값만 종합·상세에 연결한다. 거래대금 300억 미만 막대는 숨기고 300·500·1,000·3,000·5,000억·1조 구간별 색을 적용한다. 막대 높이는 거래량이며 봉 정보에는 실제 금액을 표시한다.

일자가 빠지거나 거래량이 다르면 금액을 비워 둔다. 주·월은 해당 집계봉의 모든 일자 금액이 있어야 합산한다. 인증·네트워크·형식 오류가 가격 차트 표시를 막지 않으며 상세에서 다시 조회할 수 있다. 거래대금 구간의 숨김·복원·크기 조절을 지원하고, 작은 종합 창에서는 가격 공간을 남기도록 높이를 제한한다. 연봉·다른 지표 산식·가격/거래량 원자료는 유지한다.

메인 프로세스의 고정 KIS 시세 경로를 1회 추가 조회하며 앱·차트 메인 프레임/국내 6자리 코드만 허용한다. 기존 KIS 토큰을 재사용하고 렌더러에 인증을 보내지 않는다. 60초·20종목 캐시와 요청 중 공유, 전체 8초 제한을 적용한다. 새 DB·자동 수집·조회 페이지 반복은 없다.

상세 창 상단에서 이름·코드를 검색해 해당 창만 선택 종목으로 고정할 수 있다. 기존 종목 목록/캐시와 코드별 기본 정보를 재사용하고, 주기·조회 범위·지표 설정을 유지한다. 종합 화면의 선택과 관심목록은 변경하지 않으며 따라가기를 다시 켜면 종합의 최신 종목으로 복귀한다. 검색/선택 IPC는 상세 창 메인 프레임으로 제한하고 지연 응답·닫힌 창·따라가기 복귀 후 선택을 거부한다.

검증: 전체 npm test(정적·68개 Node/브라우저·기존 스모크), 합성 KIS 응답과 보존 가격으로 상세·주·월 집계·종합 라이트 화면 검사. 검사 스크립트나 워크플로는 변경하지 않았으며 npm test에 새 검사 파일을 추가했다. docs/design/chart-trading-value/README.md와 result.json에 출처·조건·제약을 기록했다.

사용자 Windows 화면에서 앞선 KIS 표시(거래량 일치 99일 / 불일치 1일 제외)는 확인했다. HTS 원 단위 대조와 이번 검색 기능의 Windows Electron/NSIS는 미실행이다. 미리보기의 거래대금은 합성 값이며 화면에도 실수신이 아님을 표시한다. 병합·배포는 별도다.
