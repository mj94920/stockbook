feat(chart): 거래대금·수급과 상세 보조지표 연결

실제 거래대금과 투자자별 순매수가 비어 있던 차트에 공급자 자료를 연결하고, 상세 창에서 종목 검색·OBV·조건 신호를 사용할 수 있게 한다.

- 기존 KIS 인증으로 일별 거래대금·거래량을 받아 날짜/거래량이 일치하는 값만 연결한다. 300·500·1,000·3,000·5,000억·1조별 색과 거래량 높이를 사용하고, 일부 날짜만 받은 주·월은 금액을 비워 둔다.
- 외국인·기관·개인이 보고한 일별 순매수 수량과 수신 자료 누적을 별도 일별 축으로 표시한다. KIS 실패 시 선택 종목의 네이버 자료를 한 번 보완 조회하고 출처·제공 기간·실패 코드를 구분한다. 보유량·보유율·개인 잔여량을 추정하지 않는다.
- 상세 창에서 이름/6자리 코드 검색으로 종목을 독립 고정한다. 주기·범위·지표 설정은 유지하며 종합 화면 선택과 관심목록은 변경하지 않는다.
- 상세 일·주·월봉에 OBV와 기본 9봉 단순 시그널을 추가한다. 기간/단순·지수 선택, 봉 정보, 날짜 정렬, 높이 조절, 삭제·복원과 주기별 설정 저장을 지원한다.
- 사용자 식 `lowest(C(1),Period)>C`, `Crossdown(RSI(Period),LPercent)`의 신저가·RSI 하향 돌파 신호를 추가한다. 원본 조건값·RSI 평활 방식 미확인으로 기본 미설정이며 입력한 조건만 표시한다. 단순/Wilder를 선택할 수 있다. 초기화 시 조건을 비운다.

네트워크는 메인 프로세스의 고정 경로와 제한된 코드/메인 프레임 IPC만 사용한다. 가격은 먼저 표시하며 부가 조회가 실패해도 가격을 유지한다. 보완 호스트에 KIS 키/토큰을 보내지 않는다. 새 DB·자동 수집·요청 페이지 반복·설치 권한 변경은 없다. 연봉의 기존 캔들/1·5·10년선과 미확인 월봉 피보나치·암호화 지표는 유지한다.

검증: 전체 npm test(정적·86개 Node/브라우저·기존 스모크), 보존 OHLCV와 모의 IPC를 이용한 운영 HTML의 일·주·월 OBV/조건 신호·설정/이동/복원/작은 창 검사. 네이버 수급은 포스코DX·삼성전자 실제 HTTPS 응답의 5일 수량/날짜를 별도 확인했다. 사용자가 Windows 거래대금 표시·상세 검색·수급 보완 표시를 확인했다. 이번 OBV·신호의 Windows/NSIS와 HTS 수치 대조, 인증된 KIS 수급 실수신 원인 확인은 미실행이다.
