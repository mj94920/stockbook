feat(chart): 거래대금·수급과 상세 보조지표 연결

실제 거래대금과 투자자별 순매수가 비어 있던 차트에 공급자 자료를 연결하고, 상세 창에서 종목 검색·OBV·조건 신호를 사용할 수 있게 한다.

- 기존 KIS 인증으로 일별 거래대금·거래량을 받아 날짜/거래량이 일치하는 값만 연결한다. 일봉에서 300·500·1,000·3,000·5,000억·1조별 색과 거래량 높이를 사용하고 날짜/거래량이 맞지 않는 금액은 비워 둔다.
- 외국인·기관·개인이 보고한 일별 순매수 수량과 수신 자료 누적을 별도 일별 축으로 표시한다. KIS 실패 시 선택 종목의 네이버 자료를 한 번 보완 조회하고 출처·제공 기간·실패 코드를 구분한다. 보유량·보유율·개인 잔여량을 추정하지 않는다.
- 상세 창에서 이름/6자리 코드 검색으로 종목을 독립 고정한다. 주기·범위·지표 설정은 유지하며 종합 화면 선택과 관심목록은 변경하지 않는다.
- 주봉에만 OBV와 기본 9주 단순 시그널을 추가한다. 기간/단순·지수 선택, 봉 정보, 날짜 정렬, 높이 조절, 삭제·복원과 주기별 설정 저장을 지원한다.
- 사용자 식 `lowest(C(1),Period)>C`, `Crossdown(RSI(Period),LPercent)`의 신저가·RSI 하향 돌파 신호를 추가한다. 신저가는 일봉 40봉, RSI는 일·주봉 14/30을 기본값으로 사용한다. RSI 평활 방식은 미확인으로 단순/Wilder 선택 전에는 RSI 신호를 표시하지 않는다. 초기화 시 이 값과 미선택 방식으로 복귀하며 저장한 사용자 설정은 유지한다.

일봉에는 사용자가 확정한 구름/226일선/BB 상단의 가격 조건 세 개로 세력 입장 표시를 추가한다. 최소 226개 일봉에서 25봉 전 구름을 참조하고 전체 이력을 계산한 뒤 화면 구간을 자른다. 거래량·금액·양봉·등락·기울기 조건은 추가하지 않으며 부가 조회가 늦어져도 표시한다. 숨김·복원·봉 정보·종합/상세를 지원하고 다른 주기에는 넣지 않는다.

네트워크는 메인 프로세스의 고정 경로와 제한된 코드/메인 프레임 IPC만 사용한다. 가격은 먼저 표시하며 부가 조회가 실패해도 가격을 유지한다. 보완 호스트에 KIS 키/토큰을 보내지 않는다. 새 DB·자동 수집·요청 페이지 반복·설치 권한 변경은 없다. 주기별 표시/설정/유형을 분리하고 일봉 거래대금·순매수를 주·월·년으로 복제하지 않는다. 사용자 최신 이미지에 맞춰 일봉 장기 이평 450·350, 연봉 1·3·5·6·10년선과 일반 거래량을 기본으로 사용한다. 월봉 피보나치·BinaryWaveMACD는 원식 미확인으로 구현 보류한다. 피보나치는 사용자가 원식 암호화와 설정값만 확보 가능함을 재확인했으며 같은 원식 제출을 다시 요청하지 않는다.

검증: 전체 npm test(정적·92개 Node/브라우저·기존 스모크), 보존 OHLCV와 모의 IPC를 이용한 운영 HTML의 네 주기의 지표 목록·주봉 OBV·일/주 조건 신호·설정/이동/복원/작은 창 검사. 네이버 수급은 포스코DX·삼성전자 실제 HTTPS 응답의 5일 수량/날짜를 별도 확인했다. 사용자가 Windows 거래대금 표시·상세 검색·수급 보완 표시를 확인했다. 주기별 지표 분리와 일봉 세력 입장까지 사용자 Windows 실기를 통과했다(기능 코드 ab025ea5e6bab96b4ba2e79908bec4add7afeb3a). 새 NSIS 설치본 검증과 전체 HTS 수치 대조, 이 환경에서 인증된 KIS 수급 실수신 원인 확인은 미실행이다. 아모레퍼시픽 2025-06-20 네이버 실제 수신 자료에서 신호가 발생했지만 사용자 HTS의 OHLCV와는 달랐다.
