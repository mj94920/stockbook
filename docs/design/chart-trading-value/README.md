# 실제 거래대금 연결

2026-10-28 KST. PR #92 병합 뒤 main에서 시작한 `codex/chart-trading-value` 작업이다. 사용자 Windows 검사에서 기존 차트 조작·높이 조절 통과를 확인했고, 다음 항목으로 거래대금 연결을 선택받았다.

가격 차트를 먼저 표시한 뒤 기존 KIS 연결로 일별 거래대금을 별도 조회한다. 정상 수신 시 종합·상세 하단에 독립 구간이 열리며, 봉 정보에도 원 단위 금액을 표시한다. 조회가 실패해도 가격·그리기·이동은 계속 사용할 수 있다. 상세의 **거래대금 다시 조회**로 재시도한다. 거래대금 구간은 접기·Del 숨김·지표 표시에서 복원·높이 조절과 기본값 복원을 지원한다.

## 표시 기준

| 수신 거래대금 | 다크 모드 색 |
| --- | --- |
| 300억 미만 | 막대 숨김, 봉 정보에는 실제 금액 유지 |
| 300억 이상 | 파랑 |
| 500억 이상 | 연두 |
| 1,000억 이상 | 주황 |
| 3,000억 이상 | 빨강 |
| 5,000억 이상 | 연보라 |
| 1조 이상 | 흰색 |

색상은 거래대금, 막대 높이는 거래량이다. 라이트 모드는 대비색을 사용한다. 기존 거래량·매매세 구간은 별도로 유지한다.

## 수신 범위와 연결 조건

- KIS 공식 [기간별 시세 함수](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/domestic_stock/domestic_stock_functions.py)의 `inquire_daily_itemchartprice` 및 [필드명 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/chk_inquire_daily_itemchartprice.py)를 확인했다. 거래일 `stck_bsop_date`, 거래대금 `acml_tr_pbmn`, 거래량 `acml_vol`을 사용한다.
- 고정 HTTPS 경로 `/uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice`, TR `FHKST03010100`, KRX `J`, 일봉 `D`, 원주가 `1`을 요청한다. 인증은 기존 메인 프로세스의 KIS 토큰 함수를 재사용하며 렌더러로 키를 전달하지 않는다. 국내 6자리 코드만 허용하고 앱·차트 창의 메인 프레임만 IPC를 호출할 수 있다.
- **최근 최대 100거래일, 한 번의 추가 조회**다. KST 오늘까지 지난 366일을 요청하며 API 반환 상한 100개를 넘기거나 자동 페이지 조회하지 않는다. 성공 자료는 60초·최대 20종목 메모리 캐시로 공유한다. 소스 전체 이력이나 DB 저장·자동 갱신을 추가하지 않았다.
- 원 단위 비음수 안전 정수만 수락한다. 응답의 종목코드·거래일·중복·범위·행 수를 검사한다. 잘못된 자료나 오류 문자열로 차트를 만들지 않는다.
- 거래대금은 일봉의 **날짜와 거래량이 정확히 일치할 때만** 연결한다. 장중 조회 시점 차이나 KRX/통합 시장의 범위 차이로 거래량이 다르면 해당 일자는 제외하고 수를 안내한다. 일봉 가격과 거래량은 수정하지 않는다.
- 주봉·월봉은 해당 집계봉의 모든 수신 거래일에 금액이 있어야 합산한다. 일부 날짜만 받은 합계를 전체 거래대금처럼 표시하지 않는다. 이력 시작 이전이 불명확한 첫 주·월도 비운다. 현재 주·월은 일봉 수신 범위까지의 금액이며 완성된 기간 금액을 뜻하지 않는다. 연봉은 기존 캔들·1/5/10년 이평만 유지한다.
- KIS 인증이 없거나 조회에 실패하거나 금액을 받지 못한 날짜는 미수신이다. 종가×거래량, 삼성전자 보존 자료, 임의 금액으로 보충하지 않는다. 메인 요청은 인증을 포함해 8초, 렌더러 보조 응답은 9초로 제한하며 차트 표시를 기다리게 하지 않는다.

## 검증과 한계

[미리보기](preview.html)는 **삼성전자 보존 가격 + 합성 KIS 형식 금액**이며 화면에도 모의·실수신 아님을 표시한다. [상세](detail-mock.png) · [종합 라이트](compact-mock.png) · [검증 결과](result.json). 인증된 KIS 응답을 받은 증거가 아니다.

전체 `npm test`는 새 거래대금 검사도 포함해 실행한다. 금액 경계·잘못된 종목/날짜/금액·캐시·타임아웃/중단·인증 없음·IPC 송신자·부분 집계·가격 선표시·지연 응답 무시·숨김/복원·높이/축척 보존을 검사한다. 실행 결과는 [로그](npm-test.txt)를 따른다. 병합·배포하지 않는다.

Windows에서 KIS 연결 후 서로 다른 종목의 최근 완료 일봉을 선택해 HTS의 같은 날짜 KRX 거래량·거래대금과 비교해야 한다. 특히 원 단위 금액·300억 경계·100일 이전 빈칸·주/월 부분 집계·조회 실패 후 가격 차트 유지 여부는 실제 계정으로 확인이 남았다. 이 환경에는 사용자 Windows의 KIS 인증이 없어 실수신 검사는 미실행이다.


## 상세 창 종목 검색 · 2026-10-28 후속

상세 창 상단의 **종목명·6자리 코드** 입력칸에서 검색한다. 종목명은 기존 KOSPI·KOSDAQ·ETF 목록/캐시를 재사용하며 관심종목 등록과 관계없다. 이름 목록에 없는 종목은 6자리 코드로 기본 정보를 확인할 수 있다. 목록을 못 받거나 코드가 유효하지 않으면 기존 차트를 유지한다. 최대 20개 결과에서 클릭·터치·↑↓/Enter로 선택하고 Esc로 검색 목록만 닫는다. 한글 조합 중에는 검색하지 않으며 과거 검색 결과가 최신 입력을 덮지 않는다.

선택한 종목은 **상세 창만 고정**하며 봉 주기·조회 기간·해당 주기의 지표 설정을 유지한다. 종합 화면의 선택·관심·보유 목록은 변경하지 않는다. 다시 **선택 종목 따라가기**를 고르면 종합의 최신 종목과 보기 조건으로 돌아온다. 서버의 선택 처리도 이전 응답·창 종료·따라가기 복귀 후 늦은 응답을 무시한다. 새 검색/선택 IPC는 알려진 상세 창의 메인 프레임에서만 허용하고, 이름은 공급자 목록이나 코드 조회 결과에서 가져온다.

[검색 화면](detail-search-mock.png)은 모의 응답이다. 검색 공급자·IPC·실제 상세 HTML/모의 IPC에서 키보드·터치·실패·지연 응답·따라가기 복귀를 검사했다. 사용자 제공 Windows 포스코DX 화면에서는 앞선 KIS 금액 표시와 ‘거래량 일치 99일 / 불일치 1일 제외’ 안내가 보였다. 해당 화면은 원 단위 HTS 대조나 이번 검색 기능의 Windows 통과를 뜻하지 않는다.
