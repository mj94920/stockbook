# 종합 화면의 호가·기업정보 조회 연결

기준 main: `c30b07805e6033da0944a8f016f467a1440e55e7`. 기존 PR #92는 병합 완료되어, 후속 브랜치 `codex/context-tabs-20261107`에서 작업한다.

## 변경

호가 탭은 종전에는 조회 버튼을 눌러야 요청했다. 이제 탭 진입 및 활성 탭에서 선택 종목 변경 시 기존 KIS 호가 IPC를 호출한다. 자동 요청 중 같은 탭을 다시 눌러도 중복 요청하지 않으며, 조회 버튼으로 재조회할 수 있다. 새 요청 때 이전 호가를 지우고, 다른 종목의 늦은 응답은 버린다. 국내 종목만 지원하며 조회 시각과 자동 갱신이 아님을 표시한다. 지속 폴링이나 실주문은 추가하지 않았다.

기업정보 탭은 시세 요약만 보이던 영역 아래에 기업·재무정보를 연결했다. 기존 `fetchStockDetail`, `fetchNaverFinance` IPC를 재사용하며 메인 프로세스·인증·외부 URL 정책은 변경하지 않는다.

- 업종·상장일·시가총액 제공값·상장주식수, PER/PBR/EPS/BPS/ROE/영업이익률/배당 지표.
- 제공사가 실제치(`isConsensus=N`)로 표시한 최근 세 개 연간 기간의 매출·영업이익·순이익 등. 예상치는 제외한다.
- 단위는 제공값을 보존한다. 시가총액의 원 단위 등을 추측해 변환하지 않는다. 재무표에서 단위가 없으면 미제공으로 표시한다. 0·음수는 없는 값으로 바꾸지 않는다.
- 종목 변경 시 기존 내용을 지우고 늦은 응답을 무시한다. 실패·일부 자료 미수신·연결 필요·해외 종목 미지원 상태와 재조회 버튼을 제공한다.
- 성공한 기업/연간 자료는 최대 20종목·5분 동안 메모리에만 보관한다. 명시적 새로고침은 캐시를 무효화한다. 종목 변경 시 오래된 요청이 현재 화면을 덮지 않는다. 각 조회는 12초로 대기를 제한한다.

신규 표시 로직은 `src/desktop/company-info.js`에 두고 Windows 패키징 목록과 미리보기 빌더에 포함했다. 원격 내용은 DOM의 textContent로 표시해 실행 가능한 HTML로 삽입하지 않는다. 계좌·장부·차트 수식·저장 형식·버전은 수정하지 않았다.

## 검증

최신 main에서 정적 검사, Node/브라우저 검사 **94개**, 전체 스모크 통과. Node 22.23.3 / Playwright 1.56.0 / 시스템 Chromium 154. 모의 IPC를 사용하는 자동 검사이며 실제 Windows나 현재 외부 서버 응답을 검증한 결과는 아니다.

- 호가 탭 클릭 시 조회 버튼 없이 호출, 활성 탭의 종목 변경 시 새 요청, 이전 종목 지연 응답 무시.
- 기업정보/재무표의 인라인 표시, 0·음수 보존, 예상 연도 제외, 원격 HTML 문자열의 텍스트 처리.
- 최근 조회 재사용, 강제 갱신 실패 시 이전 값 제거, 기업정보·호가의 대기 제한과 재시도.
- 국내/해외 및 연결 없음 구분, 최신 main의 거래대금·수급·OBV·기존 차트 조작 검사 유지.

`docs/design/news-chart-workspace/preview.html`은 최신 main 소스와 새 표시 모듈을 포함하도록 재생성했다. 이 자료의 기존 뉴스/차트 스냅샷은 실제 기업정보 수신 확인을 대신하지 않는다.

## 검사 스크립트 변경과 검토

`scripts/smoke.mjs`의 호가 지연 응답 검사는 선택 변경 후 조회 대기를 기대하던 부분을 새 자동 조회 흐름에 맞췄다. 이전 종목과 새 종목의 resolve를 분리하여 이전 응답이 표시되지 않고 새 종목 조회가 진행 중인지 확인한다. 기존 실제 데이터·미연결·실패 검사는 유지했다. 검사를 제거하거나 느슨하게 통과시키지 않았다.

AGENTS.md/CLAUDE.md에 따라 사람이 검사 변경을 검토하고 `tests-approved` 라벨을 부여해야 CI가 PR의 검사 스크립트를 사용한다. 라벨을 자동 부여하지 않으며 CI 통과나 병합 승인을 주장하지 않는다.

## 나중에 할 사용자 확인

1. 새 소스를 받아 앱을 다시 실행한다. 호가 탭을 열어 자동 수신과 선택 종목 변경을 확인한다.
2. 기업정보 탭에서 기업 지표·연간 재무표·조회 시각과 새로고침을 확인한다.
3. 다른 종목을 빠르게 선택해 이전 종목 자료가 남지 않는지 확인한다.

사용자는 실기 확인을 나중에 하기로 했다. Windows Electron/NSIS 및 실제 KIS·네이버 서버의 현재 수신 검증은 미실행으로 남긴다. 병합·배포는 별도 승인 전 수행하지 않는다.
