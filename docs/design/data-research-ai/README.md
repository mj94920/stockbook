# 자료 확인에서 사용자 판단으로 이어지는 PC 디자인 개편

사용자가 정리한 제품 방향(2026-11-07)에 맞춰 기존 AI·리서치 구현의 화면을 개편했다. 기능 추가보다 **자료 수집 → 기업 리서치 → AI 검토 → 사용자 판단 기록**의 연결을 명확히 한다.

## 화면 변경

- 기업 리서치를 최대 1180px의 넓은 작업 화면으로 구성했다. 기존 닫기·오버레이·종목 선택 경로를 재사용한다.
- 상단에 선택 종목, 시세·뉴스 수집 범위, 수집 시각, 자료 상태를 둔다. 재무 공시 기간은 시세·뉴스 조회 범위와 분리한다.
- 왼쪽 출처 분류로 기업정보·업종·재무·시세·뉴스를 골라 읽는다. 각 자료에 원문 링크·기준일·수집 시각·범위와 단위를 표시한다. 수신 여부와 기준일/단위/마지막 봉 확인 필요를 구분한다. 수신을 최신성·완전성 검증 완료로 표시하지 않는다.
- 리서치의 **이 종목 AI 검토**가 선택 종목과 수집 기간을 전달한다. 모델을 자동 실행하지 않는다. 기간이 달라지면 수집 범위 차이를 표시한다.
- 종합 화면 AI는 자료 상태 → 주기·모델 선호·수집 범위 → 명시적 분석 요청 순서로 배치한다. HOME 연결 영역·버튼·설정 안내를 제거했다. 분석 가능 여부만 일반 상태로 표시하며, 연결이 준비되지 않았을 때는 실행하지 않는다.
- AI 응답은 현재 판단, 사용 근거, 향후 시나리오, 해석/가설, 위험과 자료 한계, 앞으로의 대응 계획, 사용자 질문, 판단 기록 진입 순서다. 시나리오는 상승·횡보·하락 각각의 성립 조건·전망·무효화 조건을 갖춘다. 근거 부족 또는 가격 전망과 무관한 원칙 복기에서는 판단 유보 하나로 범위와 필요한 자료를 명시한다. 대응 계획은 보유자·미보유자·공통 대상을 구분하고 행동·실행 조건·이유·위험·무효화·재검토 조건을 필수로 받는다. AI 문장을 사용자 투자일지에 자동 기입하지 않는다.
- 짧은 규칙 신호 영역보다 AI 검토에 내부 공간을 더 배분한다. 종합 화면의 차트·매매 배치와 높이 조절, 차트 지표·계산식은 수정하지 않았다.
- 기존 디자인 토큰, 라이트/다크, 얇은 경계와 표 중심 구성을 사용한다. 큰 요약 카드나 가상의 신뢰도 점수를 추가하지 않는다.

## 미리보기

[preview.html](preview.html)을 내려받아 브라우저로 열 수 있다. 실제 index.html과 현재 CSS/클라이언트를 한 파일로 묶었다. 휴대폰·세로로 긴 화면에서는 내부 작업 화면을 1600×1000으로 고정한 뒤 전체를 비율에 맞춰 축소한다. 확대하여 읽을 수 있으며 PC의 패널 높이를 휴대폰 세로 길이로 늘리지 않는다. PC 크기에서는 창 크기를 그대로 사용한다. 생성: `node docs/design/data-research-ai/build-preview.cjs`.

하단의 미리보기 전용 버튼으로 리서치, AI 미연결, 응답 형식 예시, 테마를 전환한다. 예시 데이터·가상 IPC를 사용하며 외부 자료 요청과 실제 모델 호출은 없다. 회사명·시장 식별 외 재무 숫자와 뉴스 문장은 디자인용 예시다. 차트는 저장소에 보존된 삼성전자 2026-10-22 스냅샷으로, 실시간이 아니다. 다른 종목에 이 예시를 재사용하지 않는다. 원문 링크 클릭은 브라우저의 외부 페이지 이동이다.

## 범위와 남은 연결

기반은 `codex/stock-ai-home`의 `61b074ae0a5005c4bb5a6ed0124f7d819bd74774`다. 해당 브랜치의 업종·리서치·AI 분석 규칙 구현에 의존한다. 이 디자인이 main이나 설치된 EXE에 반영됐다는 뜻은 아니다. HOME 어댑터·인증·수집기·정책·IPC·증권 주문은 변경하지 않았다. 별도 작업인 #97의 호가/기업정보 변경도 이 브랜치에 합치지 않았다.

사용자 후속 지시에 따라 HOME 사용을 제품의 필수 전제로 두지 않는다. 화면의 HOME 연결 행·버튼, HOME 전용 설정 설명, 모델 선택의 HOME 명칭을 제거했다. 자료 수집과 리서치는 AI 연결 없이도 이용할 수 있다. `checkConnection()`은 기존 `aiStatus` 계약으로 분석 가능 여부만 확인하며, 공급자의 HOME 관련 미설정 메시지를 그대로 노출하지 않는다.

현재 기반 브랜치의 실행 백엔드는 여전히 기존 어댑터 계약이다. 이번 수정은 다른 연결 서비스를 새로 구현하거나 실제 AI 호출 성공을 의미하지 않는다. HOME을 포함한 선택적 연결 방식과 모델 라우팅은 별도 구현·검증 대상이다. 실제 모델 호출·Windows 검수는 미실행이다.

운영자 공통 데이터 서버, 서비스별 제공·재배포 권한과 비용은 미확정이다. 운영자 API 키를 EXE에 넣거나 사용자에게 여러 키를 새로 발급받게 하는 흐름을 추가하지 않았다. 공급 주기·정규 단위·갱신 기한은 자료 계약이 확정돼야 하므로 UI에서 임의의 정상/실시간 판정을 만들지 않는다.

다음 실기 순서는 선택적 AI 연결 방식 확정 → 한 종목 자료의 기간·단위·출처 대조 → 실제 AI 응답 확인 → 사용자 판단 기록 → Windows 검수다. 노션 원문은 읽거나 수정하지 않았다.

## 검증

- `npm test`: 정적 검사, 단위·브라우저 110개, 스모크 통과. 검사 스크립트·워크플로·버전은 변경하지 않았다.
- 추가 검사는 기준일/단위 누락, 0 값 보존, 출처 필터, 1600·1024px 가로 넘침, AI 미연결 실행 방지, 선택 종목·기간 전달, 범위 변경 안내, 자동 모델 호출 없음, 결과와 사용자 기록 진입을 확인한다.
- 독립 HTML을 로컬 HTTP로 열어 Chromium에서 라이트/다크, 1600×1000·1024×768, AI 미연결 및 가상 응답 화면 확인. 페이지 오류 0, 자동 외부 요청 0, 1024px 리서치 본문 가로 넘침 없음.
- 브라우저 자동화는 가상 IPC다. Windows/NSIS·실제 HOME·실제 모델·운영 데이터 계약의 검증을 대체하지 않는다. 병합·배포 미실행.

`node --test test/design-preview.browser.test.cjs`의 별도 회귀 검사 1개에서 412×915 및 모바일 데스크톱 보기와 유사한 980×2120 뷰포트를 확인했다. 내장 차트는 가상 IPC 준비 후 다시 표시하며, 다운로드한 한 파일 안의 스냅샷으로 렌더링한다. Android `content://` 열기는 이 환경에서 직접 실행하지 못했으며 Chromium 로컬 HTTP로 검증했다. 앱 본체의 차트/매매 배치는 이번 미리보기 수정에 포함하지 않는다.

## 앞으로의 대응까지 포함하는 분석 계약

`src/ai/policy.js`의 응답 스키마와 검증기에 `scenarios`, 대응 계획의 `audience/action/trigger/invalidation`을 추가했다. 현재 요약·선택지만 있는 이전 응답은 새 계약에 맞지 않아 검증에서 거부된다. 모든 시나리오/계획은 실제 수신한 근거 ID를 참조해야 하고 공백인 실행·무효화 조건은 허용하지 않는다. 세 방향은 중복 없이 모두 받거나 명시적 판단 유보 하나로 받는다.

모델 프롬프트에는 근거 없는 목표가·확률·가격선 생성 금지, 모르는 보유 여부·평단·비중 가정 금지, 원칙 복기에서 다음 행동 제시를 명시했다. 구조 검증은 문장의 경제적 타당성이나 예측 정확도를 보장하지 않는다. 실제 데이터와 모델로 조건의 타당성을 검수하는 작업은 남아 있다. 미리보기는 자료 부족에 따른 판단 유보와 구체적인 자료 보완 계획을 보여 주는 가상 응답이다.
