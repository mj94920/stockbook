# 자료 확인에서 사용자 판단으로 이어지는 PC 디자인 개편

사용자가 정리한 제품 방향(2026-11-07)에 맞춰 기존 AI·리서치 구현의 화면을 개편했다. 기능 추가보다 **자료 수집 → 기업 리서치 → HOME AI 검토 → 사용자 판단 기록**의 연결을 명확히 한다.

## 화면 변경

- 기업 리서치를 최대 1180px의 넓은 작업 화면으로 구성했다. 기존 닫기·오버레이·종목 선택 경로를 재사용한다.
- 상단에 선택 종목, 시세·뉴스 수집 범위, 수집 시각, 자료 상태를 둔다. 재무 공시 기간은 시세·뉴스 조회 범위와 분리한다.
- 왼쪽 출처 분류로 기업정보·업종·재무·시세·뉴스를 골라 읽는다. 각 자료에 원문 링크·기준일·수집 시각·범위와 단위를 표시한다. 수신 여부와 기준일/단위/마지막 봉 확인 필요를 구분한다. 수신을 최신성·완전성 검증 완료로 표시하지 않는다.
- 리서치의 **이 종목 AI 검토**가 선택 종목과 수집 기간을 전달한다. 모델을 자동 실행하지 않는다. 기간이 달라지면 수집 범위 차이를 표시한다.
- 종합 화면 AI는 HOME 상태 → 자료 상태 → 주기·모델 선호·수집 범위 → 명시적 분석 요청 순서로 배치한다. 확인되지 않은 HOME 연결에서는 실행을 비활성화한다.
- AI 응답은 해석 요약, 사용 근거, 해석/가설, 위험과 자료 한계, 선택지·이유·위험·재검토 조건, 사용자 질문, 판단 기록 진입 순서다. AI 문장을 사용자 투자일지에 자동 기입하지 않는다.
- 짧은 규칙 신호 영역보다 AI 검토에 내부 공간을 더 배분한다. 종합 화면의 차트·매매 배치와 높이 조절, 차트 지표·계산식은 수정하지 않았다.
- 기존 디자인 토큰, 라이트/다크, 얇은 경계와 표 중심 구성을 사용한다. 큰 요약 카드나 가상의 신뢰도 점수를 추가하지 않는다.

## 범위와 남은 연결

기반은 `codex/stock-ai-home`의 `61b074ae0a5005c4bb5a6ed0124f7d819bd74774`다. 해당 브랜치의 업종·리서치·AI 분석 규칙 구현에 의존한다. 이 디자인이 main이나 설치된 EXE에 반영됐다는 뜻은 아니다. HOME 어댑터·인증·수집기·정책·IPC·증권 주문은 변경하지 않았다. 별도 작업인 #97의 호가/기업정보 변경도 이 브랜치에 합치지 않았다.

HOME 상태 조회는 기존 StockBook 포트를 사용한다. 현재 main.js의 HOME 바인딩이 없는 상태를 StockBook의 연동 경로 미등록으로 표시한다. 사용자 HOME에 Claude가 없거나 재로그인이 필요하다고 판단하지 않는다. 모델 선호는 기존 요청 필드이며 실제 라우팅·사용량은 HOME 연동 후 확인해야 한다.

최신 HOME 기준은 사용자 PC의 `C:\Users\mj949\I-Character-Project-home-github-stable-20261101`, `dev/home-unified-20261103`이다. 이 환경에는 해당 폴더가 없다. 실제 HOME·모델 호출·Windows 검수는 미실행이다.

운영자 공통 데이터 서버, 서비스별 제공·재배포 권한과 비용은 미확정이다. 운영자 API 키를 EXE에 넣거나 사용자에게 여러 키를 새로 발급받게 하는 흐름을 추가하지 않았다. 공급 주기·정규 단위·갱신 기한은 자료 계약이 확정돼야 하므로 UI에서 임의의 정상/실시간 판정을 만들지 않는다.

다음 실기 순서는 최신 HOME 계약 확인 → 한 종목 자료의 기간·단위·출처 대조 → 실제 AI 응답 확인 → 사용자 판단 기록 → Windows 검수다. 노션 원문은 읽거나 수정하지 않았다.

## 검증

- `npm test`: 정적 검사, 단위·브라우저 109개, 스모크 통과. 검사 스크립트·워크플로·버전은 변경하지 않았다.
- 추가 검사는 기준일/단위 누락, 0 값 보존, 출처 필터, 1600·1024px 가로 넘침, HOME 미연결 실행 방지, 선택 종목·기간 전달, 범위 변경 안내, 자동 모델 호출 없음, 결과와 사용자 기록 진입을 확인한다.
- 독립 HTML을 로컬 HTTP로 열어 Chromium에서 라이트/다크, 1600×1000·1024×768, HOME 미연결 및 가상 응답 화면 확인. 페이지 오류 0, 자동 외부 요청 0, 1024px 리서치 본문 가로 넘침 없음.
- 브라우저 자동화는 가상 IPC다. Windows/NSIS·실제 HOME·실제 모델·운영 데이터 계약의 검증을 대체하지 않는다. 병합·배포 미실행.
