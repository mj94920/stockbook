# 추가 지표 제안 — 적용 전 검토

사용자가 선택하기 전에는 아래 지표를 자동 추가하지 않는다. 가격·이동평균·구름·BB, 거래량·추정 매매세, 실제 수급 비교의 기본 구성을 유지한다.

| 후보 | 목적 | 필요한 데이터 | 제안 |
|---|---|---|---|
| RSI(14) | 최근 상승·하락 강도, 과매도 진입 신호 확인 | 종가 | 첫 번째 후보. 기간·기준선은 사용자 설정, 영웅문 RSI 평활 방식 대조 필요 |
| ATR(14) | 하루 변동폭 파악, 추세선·손절 거리 판단 보조 | 고가·저가·전일 종가 | 두 번째 후보. 가격과 같은 단위이며 방향·매집을 판단하지 않음 |
| OBV | 종가 상승/하락일의 거래량 누적 방향 | 종가·거래량 | 선택 후보. 실제 투자자 보유량이 아니며 기존 A/D와 중복될 수 있음 |
| 일반 MACD(12,26,9) | 추세 변화와 모멘텀 비교 | 종가 | 선택 후보. 암호화된 BinaryWaveMACD와 동일하지 않음 |

처음부터 모두 표시하지 않는다. RSI와 ATR을 우선 후보로 보고, 거래량 누적을 더 보고 싶을 때 OBV, 추세 비교가 필요할 때 일반 MACD를 선택하는 안이다.

투자자별 누적 순매수는 실제 제공된 외국인·기관·개인 구분을 유지한다. OBV나 A/D를 실제 세력 보유량·보유율로 바꾸어 이름 붙이지 않는다. 새 지표만으로 특정 주체의 매집 완료나 미래 가격을 단정하지 않는다.

VWAP은 봉별 가격평균에 거래량을 곱한 대용값으로 표시하지 않는다. 필요한 거래대금·체결 데이터와 기준 세션을 확인한 뒤 별도 검토한다.
