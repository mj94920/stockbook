# 투자자별 누적 순매수 실험

기존 독립 차트 실험에 외국인·기관·개인 3개 누적 순매수선을 추가했다. 제품 저장소 코드·계좌·키는 변경하지 않았다.

- 출처: https://m.stock.naver.com/api/stock/005930/integration 의 dealTrendInfos
- 원본 응답: investor-integration.json, 사용 스냅샷: investor-snapshot.json
- 기간: 2026-10-15 ~ 2026-10-21, 5거래일. 제공되지 않은 날짜는 생성하지 않는다.
- foreignerPureBuyQuant / organPureBuyQuant / individualPureBuyQuant 제공값을 각각 사용한다. 개인을 차액으로 추정하지 않는다.
- 날짜 오름차순 정렬, 시작일 직전 0에서 각 일의 순매수 주식 수를 합산한다. 첫날 순매수도 포함한다.
- 외국인 -1,275,121주 / 기관 -1,546,172주 / 개인 +2,316,914주.
- 기타 투자자 등이 있어 세 주체의 합계가 0이 아닐 수 있다.
- 보유량·보유율·외국인소진율과 다르다. 자동 실시간 업데이트가 없는 스냅샷이다.
- 상단 160봉과 기간이 달라 이 영역은 독립적인 5거래일 확대축을 사용하고 이를 화면에 명시한다.
- 기존 A/D 추정선과 별도 영역이다.

실행: node /workspace/chart-experiment/verify-styled.cjs
검증: 음수/콤마 수량 파싱, 잘못된/누락된 수량 거절, 중복 날짜 거절, 역순 입력 정렬, 독립적인 누적 예제, 실제 5일 합계, 3선·15개 점 표시, 다크/라이트, 기존 지표 회귀 및 브라우저 오류 0건.
화면: investors-dark.png / investors-light.png / joined-chart-dark.png

향후 과제: 장기 수급 데이터 수신, 거래소·조정주가 기준 대조, 제품 IPC 연결. 현재 5일을 20/60일 자료로 확대했다고 주장하지 않는다.

원본 색상 대응(사용자 확인): 기관=노랑, 외국인=분홍, 개인=남색. 데이터 분류 및 계산은 변경하지 않았다.
