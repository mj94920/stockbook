# 디자인룸 전달: StockBook 확장 차트 독립 실험본

2026-10-22 KST. GitHub 보존 브랜치: `codex/chart-proof-20261022`. 디자인룸 검토와 이후 제품 연결에 참고하기 위한 독립 실험본이다. StockBook 제품 코드나 계좌 인증 연결을 포함하지 않는다. 저장소에서 이 폴더 전체를 받으면 다른 작업 환경에서도 실행할 수 있다.

## 먼저 볼 자료

- joined-chart-dark.png / joined-chart-light.png: 가격 차트와 보조영역
- investors-dark.png / investors-light.png: 실제 외국인·기관·개인 순매수 누적
- styled-chart.html: 실행 진입점
- USER-FORMULAS.md: 사용자 제공 수식·색상·미구현 신호 인계

## 화면 실행

압축을 푼 폴더(stockbook-chart-proof)에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행하고 로컬 브라우저로 styled-chart.html을 연다. HTML을 파일로 직접 여는 방식은 JSON 읽기가 차단될 수 있다. 실행 중 외부 데이터 공급자에 접속하지 않고 동봉된 JSON을 읽는다. 이 주소는 내부 실행용이며 외부 공유 링크가 아니다.

## 자동 검증

Node.js가 설치된 환경에서:

```sh
npm install --ignore-scripts
npx playwright install chromium
npm run verify
```

이미 시스템 Chromium을 사용하는 환경이면 `CHART_CHROMIUM_PATH=/usr/bin/chromium npm run verify`로 실행할 수 있다. Playwright 브라우저 다운로드에는 해당 CDN 접속 허용이 필요하다. 보존된 결과는 Node 24 / Playwright 1.56.0 / Linux 시스템 Chromium 검증이며 Windows Electron 검증이 아니다.

## 구현 범위

- 실제 수신 삼성전자 일봉 1,000개 중 최근 160봉. long-candles.json.
- 종가 단순 이동평균 5/10/20/60/120/200/350/480, 5·10일 사이 구름.
- BB 상한선: 40일 종가 단순평균 + 모집단 표준편차×1.9, 오른쪽 25봉 이동. 키움 함수와 수치 대조 미완료.
- 거래량·매매 압력은 같은 칸에 겹쳐 표시. 거래량 색은 직전20일 평균 대비 구분하는 실험 기준.
- 매매 압력: V×(2C−H−L)/(H−L), H=L이면 0. 실제 주체별 체결량이 아님.
- A/D: 위 압력을 수신 시작일부터 누적. 실제 세력 보유량이 아님.
- 거래대금: 칸과 범례만 구현. 날짜별 실제 금액 막대는 미구현. 종가×거래량으로 대체하지 않음.
- 실제 수급 5거래일(2026-10-15~21)만 별도 확대축에 표시. 외국인=분홍, 기관=노랑, 개인=남색. 첫날 직전0에서 누적하며 개인도 제공값 그대로 사용.
- 투자자별 순매수는 보유량/보유율이 아님. 상단160봉과 하단5일의 축을 하나로 간주하면 안 됨.
- MACD, 실제 외국인/기관 보유량, 제공된 신저가/과매도/세력입장 신호는 아직 구현하지 않음.

## 연결 시 주의

데이터는 2026-10-22에 저장한 공개 시세 스냅샷이며 자동 갱신되지 않는다. 마지막 일봉은 장중 미완성이다. 공급자 응답 간 OHLC 차이가 관찰됐으므로 거래소·수정주가·갱신 기준 검증이 남아 있다. 네트워크 수신/파싱과 렌더링 실험은 성공했지만, 제품의 Electron IPC와 저장 기능에 연결한 결과가 아니다.

수식1~3 기준선 비교는 최근600봉 기준, 가격=종가·방법=단순을 가정했다. 오른쪽 빈25봉에 그린BB는 과거 계산선의 이동이며 미래가격 예측이 아니다.

제품 연결은 이 실험 코드를 참고하되 별도 검증해야 한다. 보존·전달은 디자인 승인, 병합 또는 릴리스를 뜻하지 않는다.
