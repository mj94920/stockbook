## 가격·호가 신뢰 경계

기존 `_renderSimulatedHoga`는 실호가를 받지 못했을 때 현재가 주변 가격과 무작위 잔량을 만들었다.
이번에는 생성 코드를 제거하고 ‘호가 미수신’을 표시한다. 이 호출 이름은 기존 경로 호환을 위해 남긴다.
실제 수신한 종합 호가를 선택하면 작은 거래 기록 창에 가격을 전달한다.
종목 변경 시 이전 종목의 단가·수량은 초기화하며, 늦게 도착한 이전 종목 호가는 적용하지 않는다.
현재가를 빈 단가에 채우는 기존 동작과 실제 거래 기록 계산·저장 함수는 유지한다.

## 후속 화면 검토 반영 (2026-10-21)

종합 상단의 중복 작업 버튼과 선택 종목 바로가기 줄을 제거하고, 하단에 잔고·매매·계산기·투자일지·거래내역·실현손익·예수금 공통 탭을 제공한다. 탭을 오가도 거래 입력과 일지 초안을 보존한다.
종목명·가격을 한 줄로 압축하고 상단 시세·차트 영역을 낮춰 하단 작업 영역을 넓혔다.
잔고 요약은 큰 카드 대신 항목명과 금액을 정렬한 2줄 표로 바꿨다. 숫자는 15px이며 총자산·예수금 설정 동선을 유지한다. 세부 지표는 접어서 볼 수 있고 갱신 시 펼침 상태를 유지한다. 예수금·실현손익 요약도 표 중심으로 정리했다. 이 표 중심 구성에 사용자 긍정 확인을 받았으며 제품 전체의 최종 승인으로 확대 해석하지 않는다.
뉴스에서는 왼쪽 종목 목록을 좁히고 목록·상세를 1024px에서도 나란히 배치한다. 종목 전환 시 검색창·안내문·조회 대상이 함께 바뀐다.

후속 검증은 Node 22.23.3, Playwright 1.56.0과 시스템 Chromium 154에서 수행했다. Playwright 번들 브라우저 다운로드는 도메인 정책으로 차단되어 저장소 밖의 실행 설정으로 시스템 Chromium을 선택했다. 테스트 본문·단정은 유지하고, 새 탭 탐색·입력 보존·계산 결과·뉴스 종목 문맥 및 배치 회귀를 추가했다.
