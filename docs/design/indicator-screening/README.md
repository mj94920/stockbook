# 지표별 계산식을 사용하는 조건검색

사용자 결정: 각 지표를 고유 계산식으로 계산한 뒤 조건을 판정한다. RSI는 보편적인 Wilder 평균을 기본으로 사용하고 봉 주기와 지표 기간을 조정할 수 있어야 한다. 일목균형표를 검색에 포함하되 우물·산과 별개로 취급한다.

## 사용하는 방법

종합 화면 전종목 검색창 옆 **조건검색** → 대상 목록과 봉 주기 선택 → 지표·판정·기간/기준값 지정 → AND/OR 조합 → 검색 실행. 기본 결과는 충족 종목만 표시하며 전체·판정 불가 결과도 선택해 볼 수 있다. 결과에서 차트 또는 기업 리서치로 이동한다. 검색은 버튼을 눌렀을 때만 실행한다. HOME·AI 연결은 필요하지 않다.

대상은 관심종목 또는 이미 불러온 KOSPI·KOSDAQ 목록의 중복 제거된 6자리 코드다. 코드가 숫자 6자리가 아닌 종목은 현재 일봉 공급자 계약에 맞지 않아 제외한다. 전시장 종목 목록을 자동 확보하거나 전 종목을 실시간 감시하는 서비스가 아니다. 한 번에 최대 3,000종목, 자료 요청은 동시 2개이며 종목 사이에 150ms 간격을 둔다. 중단하면 추가 요청과 늦은 결과 반영을 멈춘다. 이미 진행 중인 IPC의 원격 요청 자체를 취소했다고 표시하지 않는다.

## 계산과 판정

| 지표 | 계산 계약 | 조정 항목·판정 |
|---|---|---|
| 단순이평 | 차트의 `series.average` | 단기/장기 봉수, 상향/하향 돌파, 현재 위/아래 |
| RSI | 차트의 `series.rsiSeries`, 최초 N등락 단순평균으로 초기화 후 Wilder 평활 | 기본 14봉·50, 기간/기준선 변경, 상향/하향 돌파·현재 위/아래 |
| 일목균형표 | `series.ichimokuSeries`, 고저 중간값 전환/기준선, 선행 A/B | 기본 9·26·52와 선행 이동 26봉, 각 기간 변경, 아래→양운 내부 진입/양운 상단 돌파/현재 양운 |
| BB 상단 | 차트와 공유하는 `series.bbUpperSeries`, 종가 평균 + 배수×모집단 표준편차 | 기본 40봉·1.9배·표시 이동 25봉, 기간/배수/이동 변경, 상향/하향 돌파·현재 위/아래. 현재 차트 계약에 맞춰 일봉만 지원 |
| 봉 거래량 | 선택한 봉의 실제 일봉 거래량 합계 | N주 이상 |
| 봉 거래대금 | 차트의 `series.tradingValues`, KIS KRX 원화 실제 거래대금만 일자·거래량을 대조하여 합산 | N원 이상. 하나라도 누락·거래량 불일치이면 합계를 추정하지 않음 |

상향 돌파는 직전 값 ≤ 직전 기준값, 현재 값 > 현재 기준값이다. 현재 위에 있다는 판정과 구분한다. 하향도 대칭이다. RSI의 손실만 0이면 100, 이익만 0이면 0, 양쪽 0이면 50이며, 이력 부족 구간을 0으로 채우지 않는다. 주·월·연봉은 원본 일봉을 해당 주기로 먼저 집계한 뒤 지표를 계산한다. 화면의 지표 기간은 선택한 봉의 개수다. 초기 수신 봉의 일부 이력과 연봉 차트의 부분 시작 이평 처리 차이는 `historyStartPartial` 및 집계/계산 함수 계약에 남긴다.

일목의 전환선·기준선은 해당 N봉의 (최고가+최저가)/2다. 선행 A는 두 선의 평균, 선행 B는 지정 기간의 고저 중간값이다. 인덱스 i의 표시 구름은 i−선행이동 봉의 A/B다. 양운은 A>B이며 동일하면 양운으로 판정하지 않는다. 내부 진입은 직전 종가<직전 구름 하단, 현재 구름 하단≤종가≤상단, 현재 양운이다. 상단 돌파는 직전 종가≤직전 상단, 현재 종가>현재 상단, 현재 양운이다. 표시 위치만 이동하며 미래 가격을 참조하지 않는다.

**일목은 기존 차트의 MA 두 선 사이 색칠 구름과 다르다. 우물·산 지표를 일목으로 대체하거나 계산을 섞지 않았다.** 일목 계산 함수를 공유 지표 모듈에 독립 추가했고 현재 검색에서 사용한다. 기존 MA 구름 표시와 사용자 진입 신호 수식은 변경하지 않았다. 우물·산은 별도 수식·판정 확정 전까지 미제공이다. DI·MACD도 기간·평활·초기값과 돌파 규칙 확정이 필요하므로 선택 가능한 항목으로 넣지 않았다.

## 자료 상태와 결과

- 완성 봉 기본: 공급자가 마지막 일봉 완성을 명시하지 않으면 직전 봉을 사용한다. 주·월·연봉의 마지막 집계는 미확정으로 취급하므로 직전 그룹을 사용한다. 시계로 장 마감·주말·월말을 추측하지 않는다.
- 최신 봉: 미확정일 수 있음을 결과에 표시한다. 일자와 수집 시각은 종목마다 표시하며, 오래된 결과를 오늘 충족한 종목으로 바꾸지 않는다. 공급자가 수집 시각을 주지 않으면 미제공으로 표시한다. 이력·누락 상태로 최신성 보장을 대신하지 않는다.
- 결과는 충족/미충족/판정 불가로 구분한다. AND는 미충족이 있으면 미충족, 그 외 누락이 있으면 판정 불가다. OR는 충족이 있으면 충족, 그 외 누락이 있으면 판정 불가다. 조건별 미수신 상태는 OR가 충족하더라도 보존한다.
- 실제 값·직전 값·기준값, 사람이 읽을 수 있는 수식·기간·판정, 기준일·주기를 제공한다. 계산 버전 ID는 엔진 결과에 남기며 화면에서 코드나 JSON을 읽게 하지 않는다.
- 엔진은 후보 판정만 한다. AI 분석이나 자동 주문, 사용자 판단 기록을 실행하지 않는다. 앱 버전·보안 설정·IPC·운영 서버·배포 계약은 변경하지 않았다.

## 미리보기와 검증

[preview.html](preview.html)은 실제 앱 renderer와 보존 삼성전자 스냅샷으로 만든 독립 HTML이다. 실행 `node docs/design/indicator-screening/build-preview.cjs`. 공통 오프라인 미리보기 빌더를 재사용하며 2026-10-22 자료이고 실시간/현재 추천이 아니다. 휴대폰에서는 1600×1000 내부 PC 화면을 비율대로 축소한다. 자료가 없는 종목을 삼성전자 스냅샷으로 대체하지 않는다.

- 한 테스트에 잘못 들어간 SMA+일목 판정 입력 때문에 추가 검사 1개가 실패했다. 테스트 구간 삭제는 자동 승인 검토에서 거부됐고 실행되지 않았다. 잘못된 입력이 거부되는 음성 검사와 유효 일목 입력의 경계 검사를 모두 유지하는 방식으로 수정 후 통과했다.
- Windows/NSIS, 실제 KIS 거래대금·대규모 시장 목록의 공급자 부하·요청 제한 검수는 미실행이다. 자동화 검사는 가상 IPC이며 실제 공급자 서비스 품질을 검증한 것이 아니다. 병합·배포 미실행.
