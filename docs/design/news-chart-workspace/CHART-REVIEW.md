2026-10-23 KST. 설계·확인 목록이며 새 지표 구현이나 설정 확정이 아니다. 현재 차트 표시·원본 수식·보존 자료를 유지한다.

## 데스크톱에서 함께 확인할 것

| 주기 | 확인 자료 |

- 사용자 대응인 “5일선=1주선, 20일선=3주선=1월선”을 그대로 기록한다. 달력 환산식 또는 집계봉 이평의 수치 동등성으로 확정하지 않는다.
- BB 원식은 `shift(BBandsUp(period,D1),midPeriod-1)`이다. 표시 초안은 상한선을 25봉 이동한다. 영웅문 함수와 수치 일치는 별도 확인한다.
- 음양음은 월봉 전용이다. 원식이 없는 BinaryWaveMACD를 일반 MACD로 바꾸지 않는다.
- 실제 보유량과 누적 순매수는 다르다. 현재 5일 순매수의 이름을 보유량으로 바꾸지 않는다. 거래대금 미수신 시 종가×거래량으로 대체하지 않는다.
- 선의 역할이 있으므로 임의로 기간·색·굵기를 바꾸거나 삭제하지 않는다. 점·짧은 터닝포인트 표시도 전환 조건과 최종 표현을 확인한 뒤 적용한다.
- A/D와 임의의 20/60·60/120/200일 거래량 평균은 추가하지 않는다.

## 상태 분리 방향 — 코드 미적용

현재 `context.period`는 `1m/3m/6m/1y` 조회 범위다. 이를 봉 주기로 해석하지 않는다.

향후 `barCycle`(일/주/월), `viewRange`(조회 범위), `indicatorCycle`(지표 적용 주기)을 구분하고, 상세 창 따라가기/고정 문맥에도 세 값을 명시하는 방향으로 검토한다. 기존 period의 호환·이관 방식은 최종 계약을 정한 뒤 결정한다. 주기별 지표 구성을 분리해 월봉 전용 음양음이 일봉에 섞이지 않게 한다.

집계 구현 전에 다음 계약이 필요하다.

- 거래소·시간대·거래일 달력·주/월 경계. 휴장일이나 없는 거래일을 가격 0으로 채우지 않는다.
- 같은 가격 조정 기준으로 시가=첫 거래일, 고가=최댓값, 저가=최솟값, 종가=마지막 거래일을 묶는 기준.
- 실제 거래량·실제 거래대금의 합산 단위와 누락 시 처리. 미수신 거래대금은 미수신으로 유지한다.
- 수정주가·기업행사 반영, 마지막 장중/주중/월중 봉의 미완성 표시·재조회 정책.
- 지표별 선행 이력 길이와 데이터 부족 표시. 일봉 1,000개만으로 모든 장기 주봉·월봉 지표를 검증할 수 없다.

기존 KIS 인증을 활용한 별도 일봉 공급 경로를 검토해야 한다. 현재가·호가·WebSocket 가격을 일봉 이력으로 간주하지 않는다. 실시간 일봉 연결이나 Provider 계약을 완료한 문서가 아니다.
