# 데스크톱 원본 대조와 봉 주기 설계 메모

2026-10-23 KST. 사용자 확인에 따라 주봉·월봉의 캔들 집계와 이평선을 구현했다. 확인되지 않은 피보나치 기준선과 추가 지표는 아래 대기로 남긴다.

## 데스크톱에서 함께 확인할 것

| 주기 | 확인 자료 |
| --- | --- |
| 일봉 | 이평의 가격·계산 방법·기간·색·굵기, 5/10 구름 설정, BB(40, 1.9, midPeriod 26)의 값 대조, 거래대금 함수와 단위·원자료, 외국인/기관 실제 보유량 공급 경로, BinaryWaveMACD 12·26/시그널9 원식 |
| 주봉 | 종가·단순 4·12·24·46·73주 확인·구현. 산·우물은 기존 두 MA, 1·4주 확인·구현. OBV Signal 9의 신호선 계산 방식·영웅문 수치 대조는 대기 |

| 추가 신호 | 신저가의 Period, RSI의 Period/LPercent·평활법, 세력 입장 수식의 amount 단위·Crossup 경계 처리, 암호화된 바닥선의 식별 가능한 설정 |

- 사용자 대응인 “5일선=1주선, 20일선=3주선=1월선”을 그대로 기록한다. 달력 환산식 또는 집계봉 이평의 수치 동등성으로 확정하지 않는다.
- BB 원식은 `shift(BBandsUp(period,D1),midPeriod-1)`이다. 표시 초안은 상한선을 25봉 이동한다. 영웅문 함수와 수치 일치는 별도 확인한다.
- 하단 음양음(거래량·매매세)은 유지 요청을 반영해 기존 OHLCV 추정 표시를 주기별 집계봉에 재사용한다. 암호화된 원식의 재현이나 실제 체결 매수/매도량이 아니다. 바코드 지표는 제외한다. 원식이 없는 BinaryWaveMACD를 일반 MACD로 바꾸지 않는다.
- 실제 보유량과 누적 순매수는 다르다. 현재 5일 순매수의 이름을 보유량으로 바꾸지 않는다. 거래대금 미수신 시 종가×거래량으로 대체하지 않는다.
- 선의 역할이 있으므로 임의로 기간·색·굵기를 바꾸거나 삭제하지 않는다. 점·짧은 터닝포인트 표시도 전환 조건과 최종 표현을 확인한 뒤 적용한다.
- A/D와 임의의 20/60·60/120/200일 거래량 평균은 추가하지 않는다.

## 구현된 주기·조회 범위 분리

`barCycle`은 `day/week/month`, `viewRange`는 `1m/3m/6m/1y/all`이다. 기존 `period`는 `viewRange`의 호환 별칭으로 유지하며 두 값이 다르면 거부한다. `indicatorCycle`도 전달·검증하고, 현재는 선택 봉과 같은 주기만 지원한다. 상세 창 따라가기·고정은 세 값을 함께 유지한다.

- `src/chart/series.js`에서 보존 일봉을 집계한다. 주는 월요일~일요일, 월은 달력 월이다. 입력은 공급자의 KRX 거래일 문자열이며 시각을 임의 변환하지 않는다. 휴장일이나 없는 거래일을 0으로 채우지 않는다.
- 시가는 첫 수신 거래일, 고가는 최댓값, 저가는 최솟값, 종가는 마지막 수신 거래일, 거래량은 수신값 합계다. 공급된 수정 여부·기업행사 조정 기준을 새로 바꾸지 않는다. 미수신 거래대금은 미수신으로 둔다.
- 이평은 조회 범위를 자르기 전에 전체 집계봉 종가로 계산한다. 기간만큼 이력이 없으면 선을 만들지 않는다. 첫 집계봉은 그 이전 이력이 없어 완성 여부를 모르므로 이평의 입력에서 제외한다. 마지막 주/월은 완성 확인 전까지 미완성으로 표시한다.
- 기존 일봉 22/66/132/260개 범위를 유지한다. 주/월 조회 범위는 마지막 거래일에서 달력 개월을 빼서 정하고, 전체는 받은 자료 전부다. 범위 경계의 집계봉도 전체 수신 자료로 계산한다.
- 기존 삼성전자 보존 일봉 1,000개 → 주봉 215개·월봉 50개다. 이 보존 자료는 다른 종목에 재사용하지 않는다. 2026-10-26 사용자 요청에 따라 Windows 앱에 관심 등록 없는 종목 선택과 네이버 일봉 조회를 연결했다. 별도 60초 캐시를 사용하며 자동 갱신은 아니다. 투자자별 순매수는 기존 별도 5거래일 축을 유지한다.
- 주봉은 이평 4·12·24·46·73, 산·우물 1·4로 각각 계산한다. 일봉 BB 설정을 주/월로 옮겨 적용하지 않는다. 월봉 이평 구름·미확인 피보나치 기준선·바코드를 추가하지 않는다.
