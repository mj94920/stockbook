# 상세 차트 직접 조작

2026-10-27 KST. 사용자는 상세 창에서 개월 수·주기·지표 조건을 직접 바꾸고 이동·확대·십자선·봉 정보·도구를 사용할 수 있어야 한다고 요청했다. 연봉은 기본 캔들과 이평 1·5·10, 월봉 음양음은 크기 왜곡 수정도 요청했다. 미병합 PR #92 범위에서 반영했다.

## 사용

- 상세 창 상단에서 일·주·월·연봉과 1·3·6개월·1년·전체를 선택한다. 직접 보기 조건을 바꾸면 이 창을 고정한다. **선택 종목 따라가기**를 다시 선택하면 종합 화면의 종목·주기·범위로 돌아간다.
- **지표 설정**에서 종가 단순 이평 기간, 일/주 산·우물 기간, 일봉 BB 기간·배수·이동량을 바꾼다. 조건은 주기별로 이 PC에 저장한다. 미확인 월봉 피보나치를 이평 구름으로 바꾸지 않는다.
- **확대 조절**에서 빈 차트를 왼쪽으로 끌면 축소, 오른쪽으로 끌면 확대한다. 휠·가로 스크롤은 이동만, +/−·축척 막대는 확대/축소만 한다. 확대/축소 중 이동 막대의 위치 비율을 유지한다. 터치는 한 손가락 드래그와 두 손가락 핀치로 확대/축소하며 가로 이동에는 이동 막대를 사용한다. **최신**은 마지막 수신 봉으로 돌아간다.
- 봉 위에 마우스를 올리거나 터치하면 십자선·날짜·가격과 해당 봉의 OHLC·직전 봉 대비·거래량·이평 값을 본다. 주/월/연봉에서는 해당 집계봉 정보다. 미래 BB 표시 공간에는 실제 가격 정보를 만들지 않는다.
- 추세선·수평/수직선·3/4등분·봉중심선(고저/몸통)·사각형·원/타원·삼각형·화살표·펜·텍스트를 그린다. 선과 끝점을 끌어 수정하며 선택 삭제·실행 취소·전체 지우기를 지원한다. Esc는 진행 중 그리기를 취소한다.
- **저장/불러오기**는 해당 종목·주기의 그림을 이 PC에 보존한다. 가격·날짜(봉 구간)에 고정하므로 이동·확대·크기 변경 때 같은 위치에 대응한다. 계좌 데이터나 거래 내역을 수정하지 않는다.

## 연봉과 월봉 음양음

연봉은 기본 캔들과 종가 단순 1·5·10년 이평만 표시한다. 연봉 전용 endpoint 응답이 없어 기존 고정 HTTPS 일봉 경로에서 최대 3,000일을 받아 달력 연도로 집계한다. 거래량·추정 매매세·수급·BB·구름을 연봉에 추가하지 않는다. 첫 수신 연도는 이전 기간 OHLC가 부족할 수 있다. 연봉 이평은 알려진 각 연도 말/현재 종가를 사용하며 10년 미만 종목에 10년선 값을 만들지 않는다. 전체 범위는 받은 이력 전부이며 상장 이후 전체 이력이라는 뜻이 아니다. 분봉은 이번 범위에서 제외한다.

월봉의 음양음은 기존 OHLCV 추정 계산을 유지한다. 상세는 80px, 종합은 64px 패널로 고정하고 바깥/안쪽 막대를 같은 봉 중심에 둔다. 각 바깥 막대 폭은 가격 봉 간격 안에서 최대 24 CSS px, 안쪽은 그 폭의 65%다. 창 너비를 바꿔도 세로 높이가 같이 늘어나지 않으며 안쪽 막대는 바깥 막대 높이를 넘지 않는다. 원래 암호화 지표와 수치 일치를 의미하지 않는다.

정수 가격 원자료 중 고가/저가가 시가·종가를 1원 이내로 벗어나는 행만 표시 경계를 정규화하고 건수를 표시한다. 더 큰 불일치는 계속 거부한다. 거래량 0·OHLC 미제공 행을 임의 가격으로 채우지 않는다. 가격 조정 기준·마지막 봉 완성은 여전히 미확인이다.

## 로딩 지연 후속 수정 (2026-10-27)

- 기존 `httpsGet`의 소켓 무응답 제한만으로는 연결 준비·계속 조금씩 오는 응답의 총 대기 시간을 제한하지 못했다. 차트 공급자에 12초 총 제한과 AbortSignal을 추가했다. 메인 HTTPS 헬퍼는 신호를 실제 요청에 전달하며, 중단된 응답의 오류도 처리한다. 다른 API의 제한·보안 설정은 변경하지 않는다.

- 렌더러는 종목·1,000/3,000일 이력별로 최대 20개·60초 메모리 캐시와 진행 중 요청을 공유한다. 같은 종목의 기간 및 일/주/월 전환에 반복 IPC를 줄이며 연봉 3,000일은 별도로 유지한다. 실패 자료를 캐시하거나 실제 조회 실패를 보존 자료로 대체하지 않는다. 앱 종료 후 영속 캐시는 없다.

## 2026-10-27 드래그 유지 중 Space 축소

사용자가 기존 주기 변경·축척·좌우 이동 기능의 반영을 확인하여 해당 동작은 변경하지 않았다. 추가 요청인 드래그 유지 중 Space 축소만 보완했다. **확대 조절에서 마우스 버튼을 누른 상태로 Space를 누를 때마다 표시 봉 수를 약 1.4배 늘려 한 단계 축소**한다. 드래그의 기준 위치와 표시 봉 수를 새 축척으로 갱신하여, 이어서 마우스를 움직여도 이전 축척으로 되돌아가지 않는다. Space 키 자동 반복은 무시하고, 수신 이력 전부를 표시 중이면 더 축소할 수 없음을 안내한다. 마우스를 놓은 뒤 메모 입력창의 Space는 일반 공백으로 동작한다.

최종 정적 검사·44개 Node/브라우저 검사·전체 스모크 통과. 실제 포인터를 누른 상태에서 Space 2회 → 표시 봉 수 증가 → 마우스 계속 이동 → 기준 유지 → 버튼 놓기, 메모 공백 입력을 브라우저에서 검증했다. Windows의 새 Space 조작 검증은 미실행이다. 기존 조작이 반영됐다는 사용자 답변을 새 Space 기능 검증으로 대체하지 않는다.

## 2026-10-27 단축키

- **Del**: 지표 이름 또는 가격 차트의 선/구름을 선택한 뒤 누르면 해당 표시를 지운다. 이평선·BB·산/우물 구름·거래량/매매세 묶음·실제 연결된 투자자 순매수를 선택할 수 있다. 종합에서는 **차트 도구** 안의 지표 이름도 선택할 수 있다. 직접 그린 선·도형도 선택 후 Del로 지운다.
- **지표 복원 / 실행 취소**로 되돌린다. 봉·원자료·지표 기간 설정을 삭제하지 않는다. 지표 표시 상태는 이 PC의 종목·주기별로 저장하며, 그림 저장/불러오기와는 별개다. 숨긴 이평·BB·구름은 가격 축 범위와 봉 정보에서도 제외한다.
- **Esc**: 가장 위의 모달/패널 하나부터 닫는다. 관심종목 추가, 그룹 입력, 계좌/API/분석/일정 패널과 기존 모달에 적용한다. 종합 차트 도구와 상세의 보조 패널도 접는다. 그리기 진행 중에는 먼저 해당 작업을 취소한다. 기본 종합 화면은 유지하고 다른 작업 화면에서는 홈으로 돌아간다.
- 입력칸·편집 영역의 Del, 조합 중 키 입력, Ctrl/Alt/Meta 조합키는 지표 삭제로 처리하지 않는다. 모달에 포커스가 있는 동안 뒤 차트의 선택을 지우지 않는다. Esc로 입력 모달을 닫아도 저장·확정 동작을 실행하지 않는다.
- 기존 종합 십자선/도구와 드래그 유지 중 Space 축소를 보존했다. 같은 Esc가 설정 모달과 일정·MDI 패널을 한 번에 닫던 중복 리스너를 통합했고, 닫힌 native dialog가 공통 flex CSS로 다시 보이는 문제도 수정했다.
- 전체 정적·Node/브라우저 **52개**·스모크 통과. 종합/상세 Del, 실제 선 클릭, 전 지표 제거 후 캔들 유지, 복원/실행 취소, 기간 변경 후 숨김 유지, 텍스트 삭제 보호, 모달 뒤 지표 보호, Esc 한 겹 닫기를 실제 키/포인터 입력으로 검사했다. Windows Electron/NSIS의 새 단축키 확인은 **pending**이다.

## 2026-10-27 차트 유형·개별 지표 표시

**유형**에서 기본 캔들·빈 캔들·볼륨캔들·매물대를 선택한다. 종합/상세 모두 지원하고 마지막 선택을 이 PC에 저장한다. 봉 주기·기간·이평 조건·OHLCV 원자료와 그린 개체의 날짜/가격 기준은 유지한다.

- 빈 캔들은 양봉·음봉 모두 몸통을 비우고 기존 상승/하락 색의 테두리를 표시한다.
- 볼륨캔들은 표시 봉의 거래량에 비례한 가로 폭을 사용한다. 거래량이 0이거나 매우 적은 봉도 선택할 수 있도록 화면 내 최대 거래량의 1%에 해당하는 최소 폭을 적용한다. 미래 BB 공간은 평균 슬롯 폭으로 남기며 실제 거래량이나 가격으로 만들지 않는다. 십자선·날짜·이평/구름·그림·거래량 중심 좌표를 같은 가변 폭에 맞춘다.
- 매물대는 캔들 위에 가격대별 가로 막대를 겹친다. **현재 표시 날짜 범위의 실제 수신 일봉**에서 각 일봉 거래량을 저가~고가와 겹치는 가격 구간 길이에 비례해 12구간에 배분한 추정값이다. 주/월/연봉에서도 합산 봉 전체에 균등 배분하지 않고 원 일봉을 사용한다. 단일 가격 봉은 그 가격 구간에 배분한다. 거래량 합은 보존하되 실제 가격별 체결량·현재 보유량·매물 소유자를 뜻하지 않는다. 원식이 미확인인 월봉 피보나치와도 별개다. [화면](detail-profile.png).

**지표 표시**에는 지운 지표도 체크 해제 상태로 남아 있어 각각 다시 켤 수 있다. 모두 지운 뒤에도 목록을 사용할 수 있다. 표시 상태는 종목·주기별로 이 PC에 저장한다. 자료가 없는 투자자 순매수는 비활성으로 표시하며, 거래량·매매세는 한 묶음으로 전환한다. 기존 Del·지표 복원·실행 취소도 유지한다. 지표/그림 위의 커서는 손바닥(`grab`), 그림을 끌어 옮기는 동안은 쥔 손(`grabbing`)이다.

## 2026-10-27 차트 설정 초기화

종합의 **차트 도구**와 상세 도구줄에 **차트 설정 초기화**를 추가했다. 현재 봉 주기의 이평 기간·산/우물 구름·BB 조건, 지표 표시, 차트 유형, 기준선/이동 전 BB 비교, 확대·이동·도구 모드를 기본값으로 돌린다. 현재 종목·봉 주기·조회 기간·따라가기/고정은 유지하고 마지막 수신 봉으로 돌아온다. 종합 일봉은 기존 4개, 상세 일봉은 8개 기본 이평을 유지한다.

이 주기의 저장한 조건을 제거하고 현재 종목/주기의 표시 상태 및 기본 캔들 유형을 저장하므로 기간 변경·재실행 후 예전 설정이 다시 적용되지 않는다. 다른 주기의 지표 조건, 다른 종목의 표시 설정, 직접 그린 선·메모와 저장 자료, 계좌/장부·시세 자료는 지우지 않는다. 초기화 때문에 외부 차트를 다시 요청하지 않는다. 설정 모달 안의 기존 **주기 기본값**은 입력값만 기본값으로 채우며 **적용** 전에는 차트를 바꾸지 않는 동작을 유지한다.

## 2026-10-27 빈 캔들·이동/축척 분리 수정

빈 캔들을 양봉만 비우던 처리를 수정해 **양봉·음봉 모두 비운다**. 꼬리선도 몸통의 위·아래 구간에만 그려 빈 몸통 안을 관통하지 않는다. 원 OHLC·거래량은 유지한다.

차트의 일반 드래그는 확대/축소로 통일하고 이동 드래그 모드를 제거했다. 그리기와 개체 이동·편집은 유지한다. **휠·트랙패드 스크롤·이동 막대는 가로 이동만**, **드래그·축척 막대·+/−는 확대/축소만** 한다. 두 손가락 핀치와 드래그 중 Space 축소도 유지한다. 드래그/핀치 도중 휠은 무시해 두 조작을 겹치지 않는다.

이동 막대의 범위는 0~1000으로 고정해 축척을 바꿔도 이동 위치 비율을 유지한다. 가로 이동은 표시 봉 수와 축척 막대 값을 바꾸지 않는다. 전체 이력을 표시하면 이동 막대만 비활성화하고 저장한 위치 비율은 유지하므로 다시 확대해도 위치가 튀지 않는다. 최신 위치에서 확대/축소하면 마지막 수신 봉을 유지한다. 최신/처음 보기/설정 초기화는 해당 버튼의 동작에 따라 위치를 바꾼다.
