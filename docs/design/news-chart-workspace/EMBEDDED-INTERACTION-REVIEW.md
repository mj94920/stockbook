# 종합 화면 십자선·봉 정보·도구 연결

2026-10-27 KST. 기준 #92 `f415d8eaa4dbae7e1ef0be00b13a6daabe37ae40`. 다른 작업방의 로딩 대기 제한·재시도·자료 재사용 개선을 보존해 통합했다.

사용자가 종합 화면에서 십자선·봉별 정보·도구가 반영되지 않았다고 지적했다. 기존 client는 상세 모드에서만 tools=true로 장착했고, 종합 축소 SVG의 날짜·가격 글자는 숨김/잘림 상태였다. 이번 변경은 별도 상세 창에 있던 도구를 종합에서도 사용할 수 있도록 연결한다.

- 종합 차트 위에 선택 봉의 날짜·시가·고가·저가·종가·거래량을 한 줄로 표시한다. 처음에는 마지막 표시 봉을 보여주고 마우스/터치 시 해당 봉으로 갱신한다. 정보가 길면 가로로 스크롤한다.
- 가격·거래량에 십자선을 연결하고, 종합 십자선의 가격·날짜는 SVG 세로 축소와 무관하게 12px 글자로 표시한다. 주/월/연봉은 해당 집계봉 정보다. 미래 표시 공간에 실제 가격을 만들지 않는다.
- **차트 도구**를 열어 기존 추세선·수평/수직선·분할선·봉중심선·도형·펜·텍스트, 저장/불러오기, 확대·이동·축척 도구를 사용한다. 도구를 선택하면 목록이 접혀 그리기 공간을 돌려준다. 목록은 차트 높이 안에서 스크롤하며, 차트 아래 작업 영역을 밀어내지 않는다.
- 주기/종목 변경 시 기존 이벤트·도구 DOM을 정리하고 한 세트만 다시 장착한다. 상세 창의 기존 조작은 유지한다. 가격과 거래량 SVG는 같은 가로 좌표계를 써서 십자선과 봉 중심을 맞춘다.

## 검증

정적 검사, 43개 Node/브라우저 검사, 전체 스모크 통과. Node 22.23.3 / Playwright 1.56.0 / Chromium 154. 종합 앱 HTML에서 봉 정보·십자선 2영역·읽을 수 있는 축 글자·접힘/펼침·목록의 영역 내 스크롤·수평선 그리기·텍스트 주석·확대·월봉 전환 후 위젯 정리를 검사했다. 기존 상세 창 조작·뉴스 선택 우선 검사도 통과했다.

[종합 십자선·봉 정보](embedded-crosshair.png), [종합 도구](embedded-tools.png)는 삼성전자 보존 자료와 모의 IPC 화면이다. 실시간 시세·실계좌·Windows 검증 자료가 아니다. Windows Electron/NSIS 실기는 미실행이며 설치된 main 앱에 자동 반영됐다고 주장하지 않는다. 소스 브랜치 업데이트 후 재실행 또는 최신 HTML 미리보기로 확인해야 한다. 병합·배포하지 않았다.
