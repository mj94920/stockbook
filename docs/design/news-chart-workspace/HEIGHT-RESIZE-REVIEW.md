# 높이의 유동적 조절

2026-10-27 KST. 기준 #92 `fefac7a794c1ff877c42d0549a806b8e56cc7367`. 사용자는 지표 구간과 차트/하단 패널 높이를 직접 바꾸고 싶다고 요청했다.

## 조작

- 종합 화면의 차트와 아래 작업 패널 사이 경계선을 위아래로 끌어 높이를 나눈다. 아래 패널의 높이 제한은 수동 조절 시 풀고 최소 작업 공간을 확보한다. 잔고·매매·계산기·투자일지 등 작업 탭별로 비율을 따로 기억한다.
- 종합 차트의 가격/거래량 경계를 끌면 같은 차트 높이 안에서 가격과 거래량이 공간을 나눈다. 상세 창에서는 가격·거래량·현재 표시되는 수급 SVG 각각의 아래 경계를 끌어 높이를 조정한다. 현재 수급은 보존 5일 누적 순매수이며 실제 보유량을 구현한 것이 아니다.
- **높이는 비율로 저장**한다. 창을 키우거나 줄이면 같은 비율로 재계산하되, 작은 창에서는 최소 높이와 최대 범위를 적용한다. 종목을 바꿔도 같은 봉 주기/화면의 높이 취향을 유지한다. 상세/종합 및 봉 주기의 설정은 구분한다.
- 조절선을 더블클릭하거나 포커스 후 Enter를 누르면 그 구간의 기본값으로 돌아간다. ↑/↓로 16px씩, Home/End로 허용 범위 끝까지 조절할 수 있다. 터치 드래그도 지원한다.
- 차트 설정 초기화는 해당 차트 내부 높이도 초기화한다. 바깥 작업 분할은 해당 경계선에서 별도로 초기화한다. 폭 900px 이하의 세로 배치에서는 바깥 조절선을 숨기고 원래 배치를 사용하며, 다시 넓히면 저장 비율을 복원한다.
- 날짜 범위·확대·이동과 도형 데이터는 높이를 바꿔도 유지한다. 없는 거래대금·보유량·MACD 구간을 이번 변경에서 추가하지 않는다.

## 구현과 검증

`src/chart/resize.js`에서 접근 가능한 separator·포인터/키보드 처리·비율 저장·크기 변경 관찰을 처리한다. 클라이언트가 차트 재장착/제거 때 정리하며, 새 모듈은 기존 src/chart/** 패키징과 렌더러 준비 경로에 포함된다. 계좌·네트워크 IPC·버전·워크플로·기존 검사 스크립트는 변경하지 않았다.

전체 npm test: 정적 검사, **55개 Node/브라우저 검사**, 기존 전체 스모크 통과. 다음을 실제 브라우저/모의 IPC에서 검증했다.

- 가격·거래량 독립 드래그, 창 높이 변경 시 비율 유지, 페이지 재진입 후 복원, 키보드 조절/초기화.
- 종합 차트/작업 분할의 탭별 복원, 1600×1000→1600×1200의 비율 유지와 1024×768의 최소 크기, 뉴스 화면에서 조절선 숨김.
- 종합 가격·거래량 구간 분할 뒤 봉 중심 정렬, 표시 종목·봉 수 유지, 중복 조절선 제거.
- 실제 터치 포인터로 가격 높이 변경 시 차트 확대/이동과 충돌하지 않음.

[높이 조절 화면](height-resize.png)은 삼성전자 보존 자료/모의 IPC이며 실제 계좌나 실시간 데이터가 아니다. Windows Electron/NSIS 실기는 미실행이다. 병합·배포하지 않는다. 기존 PR의 tests-approved 검토·#85 선행 검증과 별도 병합 승인 조건은 유지한다.

## 하단 기본 비중 보정 · 2026-10-27

디자인룸의 `03fc095` 높이 조절 기능을 그대로 사용한다. 가격·거래량 기본 비중을 **70:30**으로 조정하며 기존 저장 비율은 우선 적용한다. 상세의 각 구간 독립 조절과 종합/작업 패널 경계선, 탭별 저장은 유지한다. 별도 조절선이나 저장 키를 추가하지 않는다.

거래량·추정 매매세 SVG의 세로 좌표를 실제 패널 높이에 맞춰 계산한다. 하단만 조절해도 즉시 갱신하고, 글자 높이와 봉 중심을 유지하며 막대가 영역 아래로 잘리지 않도록 한다. 높이를 바꿔도 확대·이동 위치와 그린 선은 보존한다. 더블클릭/Enter 또는 차트 설정 초기화로 기본 비중을 복원할 수 있다.
