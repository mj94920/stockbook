# 오른쪽 원문 웹페이지 검토

기사를 선택하면 뉴스 오른쪽에 언론사 웹페이지를 여는 구현을 추가했다. 기존 글 추출 화면은 **본문만 보기**로 남긴다. 미병합 PR [#92](https://github.com/mj94920/stockbook/pull/92), 브랜치 `codex/news-reader-chart-workspace`.

## 시험 실행

Windows에서 StockBook 저장소 폴더를 터미널로 연다. 설치된 출시 EXE나 `preview.html`은 이번 변경의 실행 경로가 아니다.

```powershell
git switch codex/news-reader-chart-workspace
git pull --ff-only origin codex/news-reader-chart-workspace
npm start
```

의존성을 설치하지 않은 새 복제본은 먼저 `npm ci`가 필요하다. 실행 뒤 **뉴스 → 기사 선택 → 언론사 원문**에서 사진과 페이지가 나타나는지 확인한다. **네이버 기사**와 **본문만 보기**로 전환하고, 설정창 열기·닫기 및 창 크기 변경도 확인한다. 블로터 탭은 블로터 기사 페이지를 직접 연다.

## 동작과 제한

- `src/news/page.cjs`: Electron 31의 `WebContentsView`. 앱과 다른 메모리 세션, Node 비활성, contextIsolation·sandbox·webSecurity 활성, 앱 preload 없음. 원문 JavaScript는 웹 샌드박스에서 실행한다. 쿠키와 앱 데이터는 공유하지 않는다.
- `src/news/service.cjs`: 검증된 네이버/블로터 기사 URL만 입력으로 받는다. 언론사 주소는 메인이 네이버 원문 링크에서 얻으며, 임의 URL 중계 API를 추가하지 않는다. 텍스트 조회와 원문 주소 확인은 진행 중 요청을 공유하고 최대 8개·60초 캐시를 사용한다. 텍스트 재조회는 완료된 캐시를 갱신한다.
- 원문 링크가 HTTP면 HTTPS로 시도한다. 링크가 없으면 네이버 기사 페이지를 연다. 다른 출처로 이동하는 리디렉션·링크 및 새 창은 허용하지 않는다. 상단 외부 브라우저 버튼은 별도다.
- 공개 HTTPS 리소스만 로드하며 로컬 주소·파일·사용자정보가 든 URL·비표준 포트는 차단한다. 권한 요청과 다운로드도 차단한다. 원문 서버의 CSP·인증서·로그인·구독 제한을 변경하지 않는다.
- `src/news/page-client.js`: 읽기 칸의 크기와 위치를 네이티브 영역에 전달한다. 모달·패널 전환·겹침·화면 밖에서는 숨긴다. 기사/보기 전환은 이전 웹 콘텐츠를 닫고, 늦게 끝난 요청을 무시한다. 메인 창 닫기·새로고침도 정리한다.
- 웹페이지는 자체 스크롤을 사용한다. 원문 사이트의 반응형 구성에 따라 첨부 이미지와 배치는 달라질 수 있다. 네트워크·로그인 문제 등으로 열리지 않으면 보기 전환을 사용한다.

## 검증 결과

원문 영역 도입 당시 `npm test`의 19개 검사와 기존 정적·스모크 검사가 통과했다. 이후 주봉·월봉 반영까지 포함한 현재 전체 검사는 42개다. 새 검사는 모의 Electron의 보안/수명 주기 검사 5개, 모의 preload를 사용하는 브라우저 상호작용 검사 1개다. 기존 본문·차트 검사도 유지했다. 목록 미리보기 검사는 별도로 통과했다.

**사용자 제공 Windows 앱 화면에서 서울경제 원문 웹페이지와 사진의 오른쪽 표시를 확인했다.** 보기 전환·모달 겹침·차트 창은 이 한 장의 화면으로 검증된 것으로 간주하지 않는다. 설치한 Linux Electron은 호스트의 SUID 샌드박스 설정 오류로 시작하지 못했다. 보안 옵션을 끄지 않았으며 제가 직접 수행한 Windows 실행·NSIS 설치 검사는 없으며 사용자 화면 확인과 구분한다. 실제 뉴스 수신 기록 `live-reader-result.json`은 Node 서비스 + 모의 preload의 텍스트 조회 검증으로, 원문 네이티브 표시 검증이 아니다.

클라우드에서 언론사 페이지를 시험하려면 해당 언론사와 실제 이미지·스타일 리소스 도메인의 네트워크 허용이 별도로 필요할 수 있다. 네이버·블로터의 이전 HTTP 200 결과만으로 전체 언론사 사이트의 허용을 주장하지 않는다. Windows에서는 해당 PC의 네트워크 정책이 적용된다. 원문 페이지 변경 당시 차트 설정은 수정하지 않았다. 이후 주봉·월봉 변경은 [CHART-REVIEW.md](CHART-REVIEW.md)에 별도로 기록했다.
