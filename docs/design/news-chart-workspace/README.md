## 클라우드 후속 검토

- 상세 창을 닫고 다시 열었을 때, 이전 창의 늦은 loadFile 실패/closed 이벤트가 새 창을 닫거나 참조를 지우지 않도록 창 인스턴스별로 처리했다. 실패 순서를 재현하는 회귀 검사를 추가했다.
- #85 커밋 `debb8b9`의 `src/desktop/renderer-files.cjs`와 현재 파일은 동일하다. 중복 기능이므로 #85 병합 시 main.js의 창 준비/종료 처리까지 함께 비교해야 한다. #85 전체가 포함되었다는 뜻은 아니다.
- 기존 KIS 경로는 현재가(`fetchKisPrice`)와 호가이며, main.js/preload.js에 일봉 조회 IPC는 없다. 현재가 메시지를 일봉 이력으로 간주하지 않는다. 라이브 차트 연결은 별도 일봉 공급 경로, 수신 범위/수정주가/마지막 봉 확정 여부 계약을 정한 뒤 진행해야 한다.
- 뉴스 본문은 허용된 네이버 기사 주소만 조회하고 텍스트로 추출하며, 실제 서버 응답 확인은 남아 있다. 현재 클라우드 네트워크 허용 목록에 뉴스 도메인이 없으므로 합성 기사 검증을 실수신 검증으로 기록하지 않는다.
- Windows Electron/NSIS 검증은 데스크톱 사용 가능 시까지 보류한다. 현재 결과는 정적 검토·모의 IPC·브라우저 검사 범위다.

상세 차트 밀도 조정: 캔들 SVG의 높이·좌표는 유지했다. 거래량 56px / A/D 60px / 투자자별 수급 84px로 보조 영역을 줄이고, 설명·일별 표는 접힌 자료 안내에 배치했다. 보조 SVG는 세로 좌표만 재배치하고 문자 크기는 유지한다. 낮은 창에서는 전체 내용을 보기 위한 스크롤이 남는다. 계산식·원자료·종합 화면의 축소 차트 비율은 변경하지 않았다.

후속 화면 조정: 요청에 따라 상세 캔들 영역의 최대 높이를 520px에서 420px로 줄였다. 보조 지표 높이와 계산식은 유지한다.

사용자 후속 검토: A/D 누적 추정선 영역과 계산을 제거했다. 중단·중장기 거래량 터닝포인트의 명시된 수식은 현재 인계 수식 문서에서 확인되지 않아 임의의 60/120/200일 거래량 평균은 추가하지 않았다.
