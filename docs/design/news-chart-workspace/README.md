## 뉴스: 현재 동작

- 시장 뉴스는 실제 응답이 확인된 `/api/news/list?category=mainnews`를 사용한다. 시장 목록의 `tit/ohnm/subcontent`와 종목 목록의 `title/officeName/body` 차이를 처리한다.
- 제목·실제 언론사·발행 시각(KST, 제공된 초 포함)·네이버 기사 URL·수신 요약을 유지한다. 목록의 body/subcontent를 기사 전체로 표시하지 않는다.
- 목록과 본문 요청은 메인 프로세스에서 처리하고 기존 preload IPC를 사용한다. 메인 화면 송신자를 검사하며 목록 주소는 코드로 고정한다. 본문은 아래 두 출처의 허용된 HTTPS 기사 경로만 읽는다. 임의 URL을 대신 조회하지 않는다.
- **Electron 앱에서 기사를 선택하면 오른쪽에 언론사 웹페이지를 연다.** 사진·표·사이트 구성은 원문 페이지가 제공하는 그대로 표시한다. 상단에서 언론사 원문 / 네이버 기사 / 본문만 보기를 전환한다. 페이지 수신 실패·로그인 제한 등은 네이버 기사 또는 본문만 보기로 전환한다. 실제 Windows 표시는 아래 미검증 항목을 확인한다.
- 원문 페이지는 `WebContentsView`의 별도 메모리 세션에서 실행하며 앱 preload·계좌 IPC를 제공하지 않는다. Node 비활성·contextIsolation·sandbox·webSecurity를 유지한다. 원문 영역은 읽기 칸 위치와 크기에 맞추고 모달·패널 전환 시 숨긴다. 팝업·권한 요청·다운로드·로컬 주소·다른 사이트 탐색을 차단한다. CSP·인증서 검사를 완화하지 않는다.
- 본문만 보기는 기존의 안전한 텍스트 표시다. 빈 본문·수신 실패는 **수신 요약**과 원문 링크로 안내한다. 웹 브라우저의 목록 미리보기에는 Electron 원문 영역이 없다.
- 긴 본문은 읽기 영역 안에서 스크롤한다. 다른 기사를 선택하면 읽기 위치를 맨 위로 돌린다. 이전 기사·종목의 늦은 응답은 현재 선택을 덮지 않는다.
- 목록 수신 중 경제지표·공시 탭으로 옮겨도 새로고침 버튼이 비활성으로 남지 않는다.
- **블로터 탭**에서 블로터의 실제 공개 목록을 받고 선택한 기사 본문을 앱 안에서 읽는다. 목록은 연도를 제공하지 않으므로 표시 문자열만 유지하고, 기사를 열면 본문의 발행 시각 메타데이터로 연도를 확인한다. 종목뉴스는 기존 네이버 종목 경로를 유지한다.
- 언론사 목적지는 메인 프로세스가 검증된 네이버 기사 안의 원문 링크에서 결정한다. 렌더러가 임의 목적지를 넘길 수 없다. 블로터는 검증된 기사 주소를 직접 연다. 원문 링크가 없으면 네이버 기사를 연다. 원문 링크의 HTTP는 앱 안에서 HTTPS로 올려 시도하며, 지원하지 않는 사이트는 네이버 기사로 전환한다. 별도 외부 브라우저 버튼은 제공된 링크를 유지한다.
- 텍스트 조회 대상은 HTTPS 네이버 기사 경로와 HTTPS `www.bloter.net/news/articleView.html?idxno=숫자`뿐이다. 블로터의 다른 경로·중복 idxno·유사 도메인은 허용하지 않는다.

## 차트: 일·주·월·연 전환

- 종합의 차트/호가/기업정보 탭과 별도 상세 창, 선택 종목·기간 따라가기/고정을 유지한다.
- 상세 캔들 최대 420px / 거래량·추정 매매세 80px / 투자자별 순매수 84px. 작은 창에서는 스크롤을 허용한다.
- A/D 누적 추정선은 제거된 상태를 유지한다. 음양음·새 거래량 평균·MACD 대체식은 추가하지 않는다.
- Windows Electron에서는 관심 등록 없이 전종목 행·상단 검색·보유종목에서 선택한 국내 6자리 코드의 네이버 일봉을 조회한다. 일·주·월은 조회 시 일봉 최대 1,000개, 연봉은 최대 3,000개를 받아 집계하며 시세 WebSocket으로 일봉을 합성하지 않는다. 60초 메모리 캐시를 쓰고 자동 갱신은 하지 않는다.
- 기존 삼성전자 일봉 1,000개·투자자별 5거래일 순매수는 보존/오프라인 검토 자료로 유지한다. 실제 일봉 조회 실패 때 보존 자료로 자동 대체하지 않는다. 다른 종목에 삼성전자 가격이나 수급을 재사용하지 않는다.
- 종합 차트에서 **봉 주기: 일봉/주봉/월봉/연봉**과 **조회 범위: 1/3/6개월·1년/전체**를 따로 선택한다. 상세 창 따라가기·고정도 이 문맥을 유지한다. 상세 창에서 주기·조회 범위와 이평/구름/BB 기간을 직접 변경한다. 수동 보기 변경은 해당 창을 고정하며 따라가기를 다시 선택하면 종합 문맥으로 복귀한다. 이동·확대·가로 스크롤·축척·가격/거래량 십자선·봉 정보·그리기 도구를 연결했다. 같은 종목의 자료를 60초간 재사용하며 수신 시간 초과·실패 때 차트 안에서 다시 시도한다. 장중 일봉 자동 갱신은 미연결이다.

## 재개 조건

뉴스 도메인 추가 뒤 네이버 뉴스·블로터 접속이 HTTP 200으로 확인돼 이전 프록시 403 차단은 해소되었다. 실제 응답의 본문 영역·목록 구조·발행 시각·원 언론사 링크를 확인해 연결했다. [실수신 검증](live-reader-result.json)은 세션 프록시를 사용하는 Node 서비스와 모의 preload 브라우저의 결과이며 Windows Electron/NSIS 검증을 대신하지 않는다.

추가 뉴스 출처는 해당 서버의 실제 응답을 확인한 뒤 연결한다. 사진·표를 포함한 원문 웹페이지는 Electron 앱용이며 사용자 제공 Windows 화면에서 서울경제 원문·사진 표시가 확인됐다. 보기 전환·모달 겹침·차트 창은 별도 확인이 남았다. 클라우드에서 원 언론사·이미지·스타일 서버까지 허용됐다고 간주하지 않는다. 차트 대조·라이브 일봉 연결은 앞의 원본 확인 절차를 유지한다.

#85의 렌더러 파일은 현재 원격 `debb8b9` 기준 동일한 blob(`7e3c1f0`)이다. main.js의 준비 실패 시 스플래시 닫기·오류 안내·종료, 실행별 임시 폴더 등록, will-quit에서 자기 폴더만 정리하는 흐름도 유지한다. #92에는 별도 차트 창 닫기가 더해져 있다. 통합 시 이를 비교하며 #85 전체가 포함됐다고 간주하지 않는다.

## 2026-10-27 종목뉴스 선택 우선

종목뉴스의 기본 범위를 보유종목에서 선택 종목으로 변경했다. 현재 종합/검색 선택을 최초 대상으로 사용하고, 뉴스에서 명시적으로 검색한 종목은 새로고침·뉴스 탭 전환 시 유지한다. 종합에서 종목을 다시 고르면 같은 코드의 재선택도 새 선택으로 반영하며, 뉴스 화면 재진입 때 이전 기사 대신 그 종목을 조회한다. 뉴스 화면의 상단 검색도 이름·코드가 정확히 일치하면 해당 종목을 조회한다. 보유·관심 모아보기는 사용자가 범위 버튼을 눌렀을 때만 적용한다.

브라우저 회귀 검사에서 보유 삼성전자와 별개의 LS에코에너지 선택, SK하이닉스 검색, 보유 모아보기 명시 선택, 고려아연 상단 검색, LS 재선택 후 복귀, 이전 종목 지연 응답 무시를 확인했다. 정적 검사·38개 Node/브라우저 검사·전체 스모크 통과. 다른 작업방의 최신 차트 커밋 816ebd6을 보존해 통합한 뒤 재검증했다. 이 검사는 모의 뉴스 IPC를 사용하며 실제 기사 수신/Windows 검증과 구분한다.
