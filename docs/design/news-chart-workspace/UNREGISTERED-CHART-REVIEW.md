# 관심 등록 없이 종목 선택과 차트 조회

2026-10-26 KST. PR #92의 실제 시험 중 사용자가 “관심종목만 차트가 나오는” 문제를 지적했다. 이 요청에 따라 선택 제한과 삼성전자만 받던 앱 차트 조회를 수정했다. 병합·배포하지 않는다.

## 변경

- 전종목 행·상단 종목명/코드 검색·보유종목 선택이 공통 현재 종목을 갱신한다. 관심목록에 등록하거나 보유 내역을 추가하지 않는다. 주기적 화면 갱신이나 관심 해제로 현재 선택이 강제로 다른 관심종목으로 바뀌지 않는다.
- `src/desktop/stock-selection.js`는 화면에서 사용하는 임시 선택만 관리한다. 보유 평균단가를 현재가로 대체하지 않는다. 현재 선택도 기존 KIS 실시간 시세 반영·종목 구독 우선순위에 포함된다.
- 앱과 상세 창은 `get-chart-data` IPC로 선택 코드의 네이버 일·주·월은 일봉 최대 1,000개, 연봉은 최대 3,000개를 받는다. 국내 6자리 코드만 허용하며 URL·호스트·요청 수는 코드로 고정한다. 주기는 일·주·월·연만 허용한다. 앱 메인 프레임과 열린 상세 창만 호출할 수 있다.
- `src/chart/provider.cjs`는 종목·주기·날짜·OHLCV를 검사하고 60초·최대 20종목 캐시와 진행 중 요청 공유를 사용한다. 결과는 일·주·월에 같은 주기별 설정으로 표시한다. 새 DB·영구 저장·자동 수집·자동 갱신은 추가하지 않는다.
- 다른 종목에 삼성전자 보존 가격/투자자 자료를 붙이지 않는다. 실제 일봉 수신 실패는 오류로 표시하며 이전 종목 차트를 남기지 않는다. 늦게 끝난 이전 요청도 현재 차트를 덮지 않는다.
- 기존 `get-chart-snapshot`과 오프라인 미리보기는 보존 검토용으로 남긴다. Windows 앱에 새 조회 API가 있으면 실제 조회를 우선하며 실패 때 보존 자료로 자동 대체하지 않는다.

## 데이터 한계

네이버가 제공하는 조회 시점의 일봉이며 KIS WebSocket 가격과 동시 갱신되는 차트가 아니다. 기준 거래일·조회 시각·자동 갱신 아님·마지막 봉 완성 미확인을 표시한다. 수정주가/기업행사 조정 기준도 미확인으로 남긴다. 공급자가 OHLC 없이 종가와 거래량 0만 제공한 행은 제외하고 수를 표시한다. 짧은 상장 이력은 이평선 계산 이력이 부족할 수 있다. 실제 거래대금·투자자별 순매수·보유량은 이 경로에서 제공하지 않는다.

월봉 피보나치 기준 종가선은 여전히 미확인이다. 일봉 BB·주봉 1/4 산·우물·월봉 이평 1/5/19/6/9 설정을 유지한다. 바코드와 A/D를 추가하지 않는다.
