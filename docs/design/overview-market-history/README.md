## 화면

- 요약 차트는 하단 작업 패널과 같은 열만 사용한다.
- 우측 AI 분석은 차트 옆부터 작업 패널 하단까지 이어진다. 내용은 내부 스크롤한다.
- 기존 규칙 신호 상세는 sbSignalCheck ID를 유지해 종목명 근처의 짧은 요약으로 옮겼다.
  현재 연결된 요약은 진입 수식의 표시 구간 마지막 봉 기준이며 날짜를 함께 표시한다.
  DI 등 미구현 신호를 임의로 생성하지 않는다. 종목 변경·조회 실패 때 이전 상태를 지운다.
- 좁은 요약 차트는 최소 플롯 공간을 확보하고 넘치는 내용은 해당 패널 안에서 스크롤한다.
- 사용자의 계좌·거래·차트 높이 저장값을 삭제하거나 마이그레이션하지 않는다.

## 시장 지표

S&P500/DOW를 목록·조회 대상에서 제외하고 다음을 기본 표시 대상으로 추가했다.

- 필라델피아 반도체: ^SOX
- 나스닥100 선물: NQ=F (나스닥 종합 현물 ^IXIC와 별도)
- 미국 10년물 수익률: ^TNX (Yahoo에서 제공하는 CBOE 수익률 지표)

기존 KOSPI/KOSDAQ/USD-KRW/NASDAQ은 유지한다.
사용자 선택 목록은 한 번 변환하며 이후 숨김 선택을 다시 강제하지 않는다.
Yahoo v7 quote의 일괄 조회 및 NASDAQ 선행 성공 의존성을 없애고
각 심볼의 v8 chart를 독립 조회한다. query1/query2 재시도, 5초 제한,
최대 3개 동시 요청, 1분 공유 캐시. 심볼·수치·수익률 단위 검증.
채권 가격/선물 가격을 미국 10년물 수익률 대신 사용하지 않는다.
수익률은 %로, 전일 대비 차이는 bp와 %p로 표시한다.
조회 실패는 미수신으로 바꾸고 이전 값을 현재 값처럼 남기지 않는다.
출처·심볼·기준 시각(한국 시간)·실시간 보장 아님을 툴팁에 표시한다.

## 과거 거래대금·수급

사용자의 후속 지시에 따라 기간 제한을 설명하는 데서 멈추지 않고 연결 방식을 변경했다.

- 거래대금: inquire-daily-itemchartprice / FHKST03010100.
  각 응답의 가장 오래된 날짜 직전일을 다음 종료일로 삼아 날짜 구간을 나눠 조회한다.
- 수급: 최근 조회형 inquire-investor 대신 날짜 지정형
  investor-trade-by-stock-daily / FHPTJ04160001의 output2를 사용한다.
  개인·기관·외국인 세 그룹의 실제 순매수 수량만 읽는다.
- 조회 범위에 따라 1개월 22 / 3개월 66 / 6개월 132 / 1년 260 / 전체 1000개를 요청한다.
- 반환 상한 1000개, 작업당 최대 40페이지, 전체 대기 최대 60초.
  두 데이터 공급자가 요청 큐를 공유하고 요청 시작 간격을 최소 100ms로 제한한다.
  추가 페이지 사이에도 간격을 둔다. 가격 표시를 기다리게 하지 않는다.
- 날짜 중복·범위 초과·진행 없는 반복 응답·금액/수량 오류를 거부한다.
  금액은 원, 수량은 주를 유지한다. 종목·날짜·거래량이 맞는 실제 대금만 차트에 연결한다.
- 도중 실패 시 정상 수신한 페이지를 보존하고 일부 수신·추가조회 중단을 표시한다.
  없는 날짜·금액을 0 또는 C*V로 만들지 않는다.
- 동일 종목·요청 개수의 진행 중 요청은 공유하고 정상 결과는 1분 캐시한다.
  추가 조회 중단/다중 페이지 미완료는 정상 완주 캐시로 고정하지 않는다.
- KIS 조회가 실패해 네이버 최근 수급으로 대체하면 네이버 출처와 기간 미달을 명시한다.
- 수급은 순매수이며 실제 보유량·세력 보유율이 아니다.
  거래량 내부의 매매 압력 추정치는 기존 OHLCV 추정으로 별도 유지한다.

## 검증

- npm test: 124개 검사, 정적 검사, 스모크 모두 통과.
- 1,000일 대금 수집, 132일 수급 페이지 이동, 중간 오류·반복 응답 보존,
  잘못된 IPC/건수 거부, 실제 그룹 보존, 캐시·취소/타임아웃·오류 비노출 검사.
- 브라우저: 1년→전체→1개월 요청이 260→1000→22개로 바뀌며 100/30개를 넘어 표시.
- 1600/1400/1024px에서 차트/작업 폭 일치와 우측 AI 전체 높이 검증.
- 좁은 창에서 대금·수급을 동시에 열어도 가격 영역이 사라지지 않음.
- 스모크 서버에 누락된 CSS MIME을 추가해 실제 스타일이 적용된 상태로 검사한다.
  기존 검사를 생략하지 않고 새 배치의 정렬·내부 스크롤·신호 위치를 검증하도록 변경했다.
  저장소 지침상 PR에서 검사 변경을 검토한 뒤 tests-approved 라벨이 필요하다.
- 첨부 overview-browser-mock.png의 지수 수치는 검증용 가상 값이다.

## 미검증·제한

이 클라우드는 query1/query2.finance.yahoo.com이 허용 목록에 없고 KIS 인증도 없어
실제 지수 응답 및 KIS 과거 데이터의 수신을 검증하지 못했다.
위 검사는 공식 명세와 가상 응답에 대한 검증이며, 실제 수신 성공을 뜻하지 않는다.
Windows에서 두 API의 날짜 이동, 휴장일, 빈 응답, 일별 수량 단위와 수신 기간을 확인해야 한다.
응답 부족·시간 초과·공급자 제한이 있으면 요청량 전부를 보장하지 않고 일부 수신으로 남긴다.
Windows 실행·원격 push·병합·EXE 생성·배포는 하지 않았다.
