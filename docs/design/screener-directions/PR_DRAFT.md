# fix(screener): 하향 조건과 BB 하단선 검색을 보완

Head: `codex/screener-downward-conditions`

조건검색의 일목 판정이 양운에만 한정되고 거래량·거래대금이 '이상'만 제공되던 문제를 수정합니다. 음운 진입·하향 돌파·음운 상태와 '이하' 비교를 추가하고, BB는 상·하단 기준선을 각각 선택해 양방향 돌파를 검색하도록 보완합니다. 이평·RSI의 기존 양방향 판정과 BB 기본 상단선 판정은 유지합니다.

검증: 전체 151개 검사·스모크·서식 검사 통과. 기존 조건식 비교 3,796개 일치. 모의 IPC 브라우저 검사에서 6개 지표의 하향·이하 검색과 방향 설명을 확인했습니다. Windows 및 실제 증권사 자료 검증은 미실행입니다.

코드 정리 커밋 `7e0b8f1e325d284d9e9b7f282b0657eac6483304` 이후 변경입니다. 선행 브랜치 반영 상태와 진행 중인 작업 충돌을 확인한 후 검토합니다. 병합·배포 승인은 별도이며 자동 병합 라벨을 붙이지 않습니다.
