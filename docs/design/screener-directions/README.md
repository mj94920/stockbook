# 조건검색 양방향 판정

기준 커밋: `7e0b8f1e325d284d9e9b7f282b0657eac6483304`

이 변경은 조건검색의 계산·입력 선택지를 보완한다. AI 분석이나 자동 매매 기능이 아니다. 기존 코드 정리 브랜치를 기반으로 하므로 main에 반영하기 전에 선행 변경과 충돌을 확인한다. 병합·배포는 별도 승인 대상이다.

## 화면 사용

전종목 검색창 옆 **조건검색** → 지표 선택 → **판정**에서 상향·하향 선택 → 기간·기준값 설정 → **검색 실행**. 결과 설명에도 선택한 방향과 BB 기준선을 표시한다.

| 지표 | 상향·큰 값 | 하향·작은 값 |
|---|---|---|
| 단순이평 | 단기선의 장기선 상향 돌파 / 현재 위 | 하향 돌파 / 현재 아래 |
| RSI (Wilder) | 지정 기준선 상향 돌파 / 현재 위 | 하향 돌파 / 현재 아래 |
| BB | 상단 또는 하단 기준선의 상향 돌파 / 현재 위 | 상단 또는 하단 기준선의 하향 돌파 / 현재 아래 |
| 일목균형표 | 아래→양운 내부 진입 / 양운 상단 상향 돌파 / 현재 양운 | 위→음운 내부 진입 / 음운 하단 하향 돌파 / 현재 음운 |
| 봉 거래량 | N주 이상 | N주 이하 |
| 봉 거래대금 | 실제 N원 이상 | 실제 N원 이하 |

이평·RSI의 하향 판정은 기존에 존재했다. 이번에는 누락된 일목 음운 조건, BB 하단선, 거래량·대금 이하 비교를 추가했다. DI·MACD·우물/산은 기존과 같이 수식 확정 대기이며 실행 지원으로 표시하지 않는다.

## 판정 경계

- 일반 상향 돌파: 직전 값 ≤ 직전 기준선, 현재 값 > 현재 기준선.
- 일반 하향 돌파: 직전 값 ≥ 직전 기준선, 현재 값 < 현재 기준선. 이미 아래인 상태를 반복 돌파로 세지 않는다.
- BB 상단/하단: 종가 평균 ± 배수 × 모집단 표준편차. 같은 기간·배수·표시 이동을 사용한다. `band` 생략은 기존과 같은 상단선이다. 상단선 하향 돌파와 하단선 하향 이탈은 다른 조건이다. BB는 일봉만 지원한다.
- 일목 음운: 현재 표시된 선행스팬 A < B. A = B이면 양운·음운 모두 미충족이다. 선행 이동은 지정 봉수를 유지한다.
- 음운 진입: 직전 종가가 직전 구름 상단보다 크고, 현재 종가가 현재 음운 내부에 위치한다. 내부에는 상·하단 경계가 포함된다. 구름을 한 번에 하향 통과하면 내부 진입으로 세지 않는다.
- 음운 하향 돌파: 직전 종가 ≥ 직전 구름 하단, 현재 종가 < 현재 음운 하단. 현재 하단과 같으면 아직 돌파가 아니다.
- 이상/이하는 등호를 포함한다. 거래량·대금의 '이하'는 전봉 대비 감소를 뜻하지 않는다.
- 미수신·이력 부족·거래대금 일자/거래량 불일치는 판정 불가다. 하향은 상향의 NOT이 아니며 NOT(판정 불가)도 판정 불가다.

기존 조건식의 기본값·판정 결과는 유지한다. 키움 카탈로그 행의 추가 실행 지원이나 현행 HTS 계산 동등성 검증 완료를 뜻하지 않는다.

## 검증

새 단위 사례는 이평·RSI의 직전/현재 등호, BB 상·하단 혼동 및 캐시 분리, 일목 음운 경계·이력 부족·중립 구름, 실제 거래대금의 등호·누락, NOT·봉전·횟수 조건 연결을 확인한다.

브라우저에서는 지표 6종 모두 하향·이하를 선택하고 모의 IPC 자료로 실제 검색·충족 결과·방향 설명을 확인한다. 1024px에서 가로 넘침과 페이지 초기화 오류도 확인한다. 실제 증권사 연결이나 Windows 실기 검증을 대체하지 않는다.

```bash
npm run format:check
npm test
```
