# 기간 내 충족 횟수와 최근 연속 충족

선행 기준은 `6e6b48adce210cd9edee0be4866b5ee1cef7cd78`의 구조 이관이다. 이전 엔진 `f435fbc48767cbb87fa08161027655979d16fe78`과 같은 입력에서 같은 결과를 내는 3,796개 차등 비교를 유지하면서 기간 판정을 추가했다. 지표의 계산식·기존 돌파 경계는 바꾸지 않았다.

## 두 연산의 구분

- **기간 내 충족 횟수:** 선택 평가 봉을 포함한 최근 N개 수신 집계 봉에서 해당 조건이 충족한 봉의 수를 센다. M회 이상/이하/같음을 선택한다. 구간 1~1,200봉, 횟수 0~N이다.
- **최근 연속 충족:** 선택 평가 봉에서 끝나는 최근 N개 봉이 모두 충족해야 한다. 구간 어딘가의 과거 연속 구간을 찾거나, 서로 다른 조건을 시간순으로 찾는 순차검색이 아니다.
- 횟수는 **충족한 봉의 수**다. ‘현재 위’ 상태가 3봉 유지되면 3회로 센다. 돌파 사건만 세려면 해당 지표의 돌파 판정을 선택해야 한다. 연속 N봉 충족은 ‘N회 상승 변화’를 계산하는 새로운 추세 지표와도 구분한다. 각 봉의 판정에 필요한 직전 값은 기존 지표·돌파 규칙대로 계산한다.

예를 들어 `[충족, 미충족, 충족]`은 3봉 중 2회 이상에 충족하지만, 최근 3봉 연속 충족에는 미충족이다.

## 시간과 누락 처리

조건별 주기·완성/최신·봉전으로 평가 기준봉을 먼저 정하고, 그 봉을 포함해 뒤로 N개를 검사한다. 일봉 기준 완성 0봉전과 최신 1봉전의 관계 등 기존 기준봉 정의를 유지한다. 주·월·연봉은 원본 일봉을 먼저 집계하고, N은 선택한 집계 봉의 개수다. 기간 창 끝점이나 봉전의 의미를 키움과 같다고 확인한 것은 아니다.

판정 불가 봉을 0회나 미충족으로 채우지 않는다. 알려진 충족 수가 L이고 판정 불가가 U면 실제 가능한 충족 횟수는 `[L, L+U]`다.

| 비교 | 충족 확정 | 미충족 확정 | 나머지 |
|---|---|---|---|
| M회 이상 | L ≥ M | L+U < M | 판정 불가 |
| M회 이하 | L+U ≤ M | L > M | 판정 불가 |
| M회 같음 | L = L+U = M | M이 가능한 범위 밖 | 판정 불가 |

0회 이상이나 N회 이하는 범위상 항상 참일 수 있다. 이것은 미수신 봉의 실제 충족 횟수를 0이라고 확정하는 것이 아니다. 화면에는 알려진 충족/미충족/판정 불가 수와 가능한 횟수 범위를 함께 표시한다. `0회 같음`은 자료가 빠져 있으면 판정 불가일 수 있으며 NOT을 해도 판정 불가다.

연속 조건은 알려진 미충족이 하나라도 있으면 미충족, 모든 봉이 충족이면 충족, 그 외에는 판정 불가다. 이력 부족·지표 준비 구간·미수신 실제 거래대금도 기존 개별 판정의 판정 불가를 유지한다.

**자료 범위:** N은 수신된 시계열/집계 봉의 인덱스 기준이다. 날짜 사이가 휴장인지 공급자 결손인지 판단할 거래 달력 계약은 아직 없다. 미관측 거래일을 새로 생성하거나 휴일을 봉으로 채우지 않는다. 달력 기반 결손 탐지·원본 시세 완전성·키움 시간축 일치는 별도 검증 대상이다.

## 구조와 화면

버전 2 조건 레코드에 선택적인 `window`를 추가한다.

```json
{"kind":"count","span":5,"operator":"gte","threshold":3}
```

연속은 `{"kind":"streak","span":5}`다. 창 설정을 넣지 않은 기존 문서는 종전의 단일 봉 판정이며 이관할 때 자동으로 기간 창을 붙이지 않는다. 기존 평면 호환 어댑터는 기간 설정을 조용히 무시하지 않고 거부하며, 새 문서 실행기로 처리한다.

조건마다 ‘선택 봉 하나 / 기간 내 충족 횟수 / 최근 연속 충족’을 선택한다. 결과에는 전체 기간 판정과 기준봉 자체 판정을 구분하고, 충족/미충족/판정 불가 수·가능 범위·봉별 근거를 보여준다. 일부 참조를 NOT로 감싸거나 주기를 섞는 기존 구조와 함께 사용할 수 있다.

한 번 받은 원본 자료에서 모든 평가 봉을 계산한다. 봉마다 공급자를 다시 조회하지 않는다. 같은 준비 맥락의 지표 배열도 재사용하며, 숫자 계산식은 기존 차트 공용 함수 그대로다. 결과의 개별 봉 근거는 첫/마지막 각 16봉, 최대 32봉만 보관·지연 표시한다. **계산은 전체 N봉에서 수행**하며 표시를 생략한 봉의 수를 명시한다.

## 검증과 예시

- `npm test`: 정적 검사·**136개 단위/브라우저 검사·스모크 통과**. 기존 127개에 기간 판정 8개와 화면 연결 1개를 추가했다. 검사 스크립트·워크플로·버전 번호는 바꾸지 않았다.
- 이전 엔진과의 **3,796개 입력 조합 동등성**을 계속 통과한다. 기본 기간 판정 ‘선택 봉 하나’는 기존 동작을 유지한다.
- 1~4봉에서 모든 충족/미충족/판정 불가 배열을 만들고, 미확인 값을 모두 가능한 참/거짓으로 채운 결과와 횟수·연속 판정을 비교했다. 0회·창 길이와 같은 경계도 포함한다.
- 기준봉·창 양 끝 포함, 완성/최신과 봉전, 이력 부족, 실제 거래대금 미수신, `NOT(판정 불가)`, 1봉 창의 기존 판정 일치를 검사했다.
- 이동평균·RSI·BB·일목의 과거 봉별 판정을 고정된 이전 엔진과 대조했다. 지표 자체를 새 수식으로 해석하지 않았다.
- 1,200봉 계산의 가장 오래된 봉이 미충족인 사례로 표시 32봉 제한이 계산을 자르지 않는지 검사했다.
- 화면에서 중간 미충족이 있어도 횟수는 충족할 수 있고 연속은 미충족임을 확인했다. 실제 거래대금이 없을 때 `0회 같음`과 NOT는 판정 불가다. 3봉 검사도 자료 조회 1회이며 잘못된 횟수 설정은 조회 전에 거부한다.
- 독립 미리보기의 라이트/다크·1024px에서 페이지 오류 0·자동 외부 요청 0·가로 넘침 없음.

## 미완료

이 계약은 StockBook의 명시적인 기간 판정이며 키움의 같은 이름 옵션과 동등함을 주장하지 않는다. 현행 영웅문4 전체 목록·계산·창 경계 실측, Windows/NSIS, 실제 KIS·대규모 조회 검수는 미완료다. 구간 안의 최장 연속 길이 검색, 조건 간 순차검색, 달력 기반 결손 탐지, 시장 단위 순위는 추가하지 않았다. 623행 카탈로그를 실행 지원으로 등록하지 않았으며, 미확정 지표·데이터를 추정하지 않는다.

별도 브랜치 `codex/screener-temporal-conditions`에 보존한다. 선행 이관·조건검색·AI/리서치 변경이 아직 main에 병합됐다는 뜻은 아니다. 병합·배포는 수행하지 않았다.
