# 업종 탐색 화면

업종군과 원본 업종을 두 개의 선택 상자로 한 줄에 배치하고 현재 경로와 종목 수를 표시한다. 선택한 업종의 종목만 기존 표에 표시한다.

최신 분류 데이터·범위·검증은 [시장 업종 연결](../industry-classification/README.md)을 따른다. 과거의 종목명 키워드·일부 반도체 코드 중심 임시 분류는 원본의 2,876종목·78개 업종 연결로 대체했다.

- 상위 업종군은 앱의 탐색용 묶음, 하위는 네이버 원본 업종이다.
- ETF·ETN·ELS 등 금융상품을 분류에 섞지 않는다.
- 종목명/코드/업종명 검색, 상위 전체 보기, 페이지 이동, 기존 종목 선택 동작을 제공한다.
- 분류 기준일과 출처를 표시하며 시세가 없는 종목도 목록에 포함하고 수치는 `-`로 표시한다.
- 계좌·거래 기록·저장 형식은 유지한다.

`dark.png` / `light.png`는 공개 업종 원본과 합성 시세로 확인한 브라우저 화면이며 실제 계좌·장중 실기 검증은 아니다. Windows 실검수 및 배포는 아직이다.
