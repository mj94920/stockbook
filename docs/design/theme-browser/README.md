# 큰 테마 → 세부 테마 → 종목

사용자 승인에 따라 섹터별의 전체 종목 일렬 나열을 큰 테마 선택 그리드와 세부 필터로 변경한다. 상위 테마 전체 및 개별 세부 테마에서 종목을 조회하며, 같은 종목은 여러 경로에 포함될 수 있다. 표 안에서는 코드로 중복을 제거한다.

- `src/desktop/themes.js`: 관리 테마·종목 코드 분류·수신 업종 키워드·기존 분류 호환. 공식 산업분류라고 주장하지 않는다.
- `src/desktop/theme-browser.js`: 선택 상태·테마/종목 검색·건수·DOM 안전한 탐색 UI.
- `src/desktop/themes.css`: 토큰 기반 2~3열 선택 영역. 기존 종목 표·페이지 이동·관심 추가·기업분석·뉴스 선택 동작을 재사용한다.
- 반도체: 제조, 설계/IP, 장비, 소재, 검사/패키징. 가온칩스·넥스트칩·오픈엣지·HPSP 등 코드별 경로 보완.
- ETF/ETN 상품은 반도체 기업으로 집계하지 않는다. 수신 상품 유형 또는 알려진 상품명 접두어로 별도 구분한다.
- 분류 근거가 없으면 ‘분류 확인 필요’, 상위 추정만 가능하면 ‘세부분류 확인 필요’. 기타에 숨기지 않는다.

## 한계

아직 전 상장종목의 공식 업종 원본을 수집·검증하는 공급원이 연결된 것은 아니다. 코드 관리 목록 밖에서는 수신 업종 키워드와 기존 종목명 추정의 상위 테마를 사용한다. 분류와 커버리지는 지속 검증이 필요하다. 현재 시장 목록은 기존 수집 범위(시총 1,000억원 이상, 시장별 최대 30페이지)를 유지한다. UI는 수신 종목 기준임을 표시한다. 빈 테마는 표시하지 않으며 임의로 테마 수를 늘리지 않는다.

사용자 계좌·관심종목 분류·거래 기록·기존 데이터 형식과 버전은 변경하지 않는다. 추가 외부 API나 AI 호출 없음. Windows 실기 확인 및 배포는 별도.

## 검증

- `npm test`: 정적 검사, 전체 95개 단위·브라우저 검사, 기존 스모크 통과.
- 실제 클릭으로 큰 테마/세부 테마/상위 전체, 종목명·테마명 검색, ETF 분리, 복수 테마 중복 제거, 시장 탭 복귀, 뉴스 화면 유지 확인.
- 새 모듈·CSS가 Electron 임시 렌더러 디렉터리에 복사되고 빌드 포함 목록에 있는지 검사.
- `dark.png` / `light.png`: 합성 종목 목록으로 확인한 브라우저 화면. 실제 시세·실제 계좌 검증 자료가 아님.
