# refactor: 런타임·검사 코드와 배포 자산 구성을 정리

Base: `main`
Head: `codex/project-code-cleanup`

조건검색 파일이 EXE 배포 목록에서 빠져 배포된 종합 화면이 초기화되지 않을 수 있는 문제를 수정합니다. 배포 파일 목록으로 구성한 렌더러에서 조건검색과 거래대금 조건 추가를 확인하며, 로컬 JS·CSS·아이콘 누락을 감지합니다.

수작업 런타임·테스트 코드의 서식을 통일하고 브라우저 테스트의 공통 서버 및 오프라인 미리보기 자산 처리를 통합합니다. index.html에서는 return 뒤의 실행 불가 코드만 제거합니다. 기존 assert와 고정 데이터·승인 산출물은 보존합니다.

검증: 전체 145개 검사와 스모크·서식 검사 통과. 기존 조건식 판정 비교 3,796개 일치. Windows/NSIS 및 실제 증권·모델 연결은 미검증입니다. 현재 CI가 전체 npm test를 실행하는 것은 아닙니다.

[정리 범위와 후속 작업](../maintenance/README.md)을 확인해 주세요. 구조 개편 전체의 완료를 뜻하지 않습니다. 진행 중인 Claude 큐·main과 충돌 확인 및 사용자 병합 승인은 별도입니다. 자동 병합 라벨은 부여하지 않습니다.
